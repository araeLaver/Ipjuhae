# 사용자 활성화 개선 — 2026-10-07

목표: 가입 없이 보증금 점검을 완료한 사용자가 관련 안내 글·커뮤니티 질문·계약 전 대화로 이어지도록 한다.

## 변경

- 관련 안내 글 링크가 검색을 처리하지 않는 홈으로 돌아가던 문제를 수정했다. 고정 회차 주소에서 공개·운영자 작성·숨김/삭제되지 않은 실제 글로 이동한다. 조회 실패와 없는 글에는 복구 동선을 제공한다.
- 결과 화면에 커뮤니티 질문과 계약 전 대화 링크를 추가했다. 입력 금액을 다른 화면에 전달하지 않는다.
- 입력값을 변경하면 이전 계산 결과를 제거해 다시 계산하도록 한다.
- `check_started`는 화면당 첫 입력 1회, `check_next_action_clicked`는 ask/contract_talk/guide 중 하나만 익명으로 기록한다. 서버에서 계정·세션·금액과 임의 action 값을 제거한다.
- 관리자 메뉴에 사용자 활성화를 추가하고 30일 일별 입력 시작·결과 조회·다음 행동 클릭 횟수를 보여준다. 조회 실패는 데이터 없음과 구분한다. 고유 사용자 전환율·재방문율로 해석하면 안 된다.

- typecheck 성공.
- 전체 test:ci: 970 passed, 13 skipped, 97 passed files, 3 skipped files. 실제 Postgres 테스트는 DB 설정 없이 실행하지 않았다.
- 그 이후 추가한 안내 글 resolver 테스트 4개 통과. 익명 계측·컴포넌트 관련 테스트 35개 통과.
- Next.js 프로덕션 빌드 성공. 기존 다른 화면의 lint 경고는 남아 있다.
- Playwright 로컬 프로덕션 브라우저: 첫 입력 1회, 계산 결과, 실제 guide URL, 수정 후 결과 제거, 재계산 후 `/community#ask` 이동 및 질문 영역 표시 확인. analytics 요청을 가로채 검증했고 금액 40000/30000이 포함되지 않았다. 실제 DB 저장이나 운영 통계 검증을 의미하지 않는다.
- 운영 공개 posts API에서 안내 글 1~12편이 실제 존재함을 확인했다. 신규 resolver의 운영 DB 호출은 배포 후 검증해야 한다.
