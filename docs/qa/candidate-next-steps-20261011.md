# 저장 후보별 다음 할 일

기존 4개 확인 기록과 저장 형식을 유지하면서 미확인 개수, 다음 할 일, 확인 자료·문의 상대·질문을 제공한다. 후보 비교표에도 남은 확인 개수를 표시한다.
확인 표시를 변경하면 다음 할 일이 바뀌며 재접속 시 기존 브라우저 기록에서 복원한다. 모두 체크한 경우 확인 기록 완료라고 표시하고 변경된 조건은 체크를 해제해 다시 확인하도록 안내한다. 계약 안전이나 보증 가입 확정으로 표시하지 않는다.
미확인 항목 질문은 고정 항목 식별자만 URL fragment로 전달한다. 금액·후보 별칭·저장 ID를 전달하지 않으며 사용자가 직접 질문을 등록해야 게시된다.

타입 검사와 전체 테스트 1,006개 통과 / 13개 건너뜀. 새 테스트에서 다음 할 일 변경·확인 완료·재확인·재접속 복원·항목별 질문·개인 입력값 미전달을 확인했다.
계산식과 DB 스키마는 변경하지 않았다. 실제 사용자 활성화 효과는 이용 데이터로 별도 확인해야 한다.
프로덕션 빌드 성공. 로컬 Playwright에서 남은 개수·다음 할 일 변경·재접속 복원·확인 완료와 재확인·항목별 질문 초안·금액/별칭 미전달·자동 등록 없음 통과. 검증용 분석 이벤트는 차단했다.
