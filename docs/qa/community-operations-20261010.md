# 질문 운영 출시 검증

- 타입 검사 통과, 전체 테스트 1,002개 통과 / 13개 건너뜀. 운영 기능 회귀 테스트 10개 포함.
- 프로덕션 빌드 성공.
- 실제 로컬 PostgreSQL: 임시 테이블과 롤백으로 운영자 공개 댓글만 답변으로 인정하는지, 숨김·삭제 반영, 역할 게시판 접근 필터, 운영 안내 글 제외, 대기/답변 큐를 확인했다. 운영 DB는 수정하지 않았다.
- 로컬 Playwright: 질문 등록 성공 후 링크 보관, 페이지 재접속, 운영자 답변 상태 갱신, 목록 삭제 시 서버 DELETE 없음, 점검 공유 URL에 입력값 없음 확인. 질문/답변 API는 명시적인 로컬 픽스처였다.
- 공개 게시판 기준선: 운영 안내 글 18건, 사용자 질문 0건. 방문자·가입자 수는 별도 지표이며 여기서 확인하지 않았다.
- 운영자 담당 지정, 실제 사용자 모집 메시지 발송, 실제 사용자 질문에 대한 답변 실적은 아직 검증 범위에 포함되지 않는다.
- DB 마이그레이션 없음. 기존 권한 검사를 유지하고 관리자 페이지는 데이터 조회 전에 관리자 인증을 검사한다.
