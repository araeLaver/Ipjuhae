# 보증금 점검 → 확인 행동 → 질문 초안

## 변경

웹 보증금 점검 결과에 확인할 자료, 문의 상대, 질문 문장을 표시한다. 계산상 여유가 서류 확인 완료를 뜻하지 않으며 빈 선순위 금액은 0원 계산임을 안내한다.
질문하기는 고정 위험 구분만 URL fragment로 전달한다. 금액·주소·후보 이름을 전달하지 않는다. 서버에 자동 질문 등록 요청을 보내지 않는다.
커뮤니티에서는 편집 가능한 초안을 채우고 사용자가 직접 등록한다. 이미 작성 중인 내용을 덮어쓰지 않는다. 초안은 전체 게시판으로 시작한다.
공유 계산 로직과 모바일 계산기는 변경하지 않았다. 후보별 남은 확인 사항 확대는 별도 후속 작업이다.

## 안내 근거

HUG 공식 제출서류: https://m.khug.or.kr/hug/web/ig/dr/igdr000002.jsp?tabMenu=Y
HUG 공식 상품 안내: https://m.khug.or.kr/hug/web/ig/dr/igdr000001.jsp?tabMenu=Y
주택 유형별 필요 자료가 다르며 다가구 선순위 확인에는 임대인·중개사 협조가 필요하다. 특정 보증의 가입 가능 여부나 계약 안전을 확정하지 않는다.

## 검증

결과별 초안, 알 수 없는 fragment 거부, 자동 POST 없음, 편집 유지 회귀 테스트를 추가했다.
타입 검사·프로덕션 빌드 성공. 전체 테스트 1,004개 통과 / 13개 건너뜀(동시 실행 2개).
초기 공유 의존성 환경의 모바일 임시 파일 경로 오류는 독립 의존성 설치로 해결했다. 이후 병렬 실행 시간 초과는 단독 통과 확인 후 실행 수를 줄인 전체 검사에서 통과했다.
로컬 Playwright: 점검 → 질문 화면 이동, 편집 가능한 초안, 금액 미포함, 자동 POST 없음, 작성 중 질문 유지, 입력 변경 후 이전 결과 제거를 확인했다.
