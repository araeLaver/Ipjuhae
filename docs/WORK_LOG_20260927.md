# 워크로그 2026-09-27 — 전세 비교, 정책 소음 제거, 테스터 부탁 한 장

## 1. 매매가를 고르면 같은 단지 전세가 따라 나온다

매매 시세만으로는 내 보증금이 과한지 감이 안 온다. "이 단지 59㎡ 전세는
보통 11억"이 있어야 판단이 선다.

`/check`에서 거래를 고르면 그 단지·그 면적의 전월세를 이어서 조회한다.

```
래미안블레스티지 59.888㎡ 전세 실거래
최근 6개월 11건 · 마지막 거래 2026-09-07
가운데값  11억 200만원
범위      9억원 ~ 12억원
```

### 숫자를 다루며 조심한 것

**전세와 월세를 섞지 않는다.** 28건 중 전세 11, 월세 10이었다. 월세 낀 계약은
보증금이 낮으니 같이 평균 내면 "이 단지 전세는 이 정도"가 실제보다 낮게 나온다.

**평균 대신 중앙값과 범위.** 거래가 대여섯 건뿐인 단지에서 특이한 한 건이
평균을 통째로 끌고 간다.

**건수를 밝히고 5건 미만이면 판정을 눅인다.** 3건짜리 통계를 5건짜리처럼
보여주면 그 숫자를 믿고 계약한다.

### 계산에는 넣지 않았다

넣는 순간 "전세 시세보다 싸니까 안전합니다"로 읽힌다. 그건 거짓말이다.
안전 여부는 근저당과 시세가 정한다. 이 비교가 말해주는 건 **협상 여지**와
**왜 이 금액인지 물어볼 근거**다. 문장에서 그 구분을 지켰다.

## 2. 정책 소식에서 임대차와 무관한 기사를 걷어냈다

첫 화면에 이런 게 올라와 있었다.

```
✗ "잠재력에 투자"…25조 늘어난 내년 청년 예산
✗ 구 부총리 "경제 회복세 뚜렷…1인당 GNI 4만 달러"
✗ 내년 청년정책에 43조 투입
✗ 8월 호우 피해 이재민에 추석 전 주거 안정 지원
```

넷 다 **제목에는 임대차가 없고 부제에 '공공임대'가 한 번 스쳤을 뿐**이었다.

낱말을 두 갈래로 나눴다.

| | |
| --- | --- |
| STRONG | 전세·월세·임대차·보증금·임차인·전세사기… 제목이든 부제든 걸리면 통과 |
| WEAK | 공공임대·임대주택·주거안정… 넓은 정책 용어라 **제목에 있을 때만** 통과 |

기사의 주제는 제목에 적힌다. 재난 지원도 제외했다 — 이재민 월세 지원은
임대차 정책이 아니라 재해 복구이고, 계약을 앞둔 사람이 찾는 정보가 아니다.

실제 API 응답 기준 **11건 → 6건.** 남은 6건은 전부 임대차 기사다.

### 테스트를 되돌려 실패를 확인했다

회귀 테스트를 붙이고, 판정 로직을 옛 방식으로 되돌려 **3건이 실패하는 것까지**
확인한 뒤 복구했다. 통과만으로는 그 테스트가 일한다는 증거가 못 된다.
예시 제목은 전부 실제 API에서 받아온 것이다.

## 3. 테스터 — 막힌 건 이메일이 아니었다

```
목록에 등록된 사람        6명
실제로 참여를 선택한 사람   1명
```

**5명이 링크를 누르지 않았다.** 새 사람을 찾기 전에 이미 등록된 분들께
보내는 게 빠르다.

### 부탁이 생각보다 가볍다

Play Console 문구는 `12명 이상의 테스터가 비공개 테스트 **참여를 선택**` 이다.
**카운터가 세는 건 설치가 아니라 옵트인이다.** 링크를 열고 「테스터 되기」를
누르면 그 순간 숫자가 올라간다.

설치와 실사용은 승인 심사에서 따로 본다. 다만 **부탁할 때는 "버튼 한 번"으로
말해야 한다.** "설치하고 2주 써주세요"라고 하면 그 무게 때문에 첫 버튼마저
안 누른다. 앞서 그렇게 안내한 것이 오히려 진입을 막고 있었다.

### /tester — 주소 하나

테스터 링크가 홈 배너와 `/check` 결과 아래에 묻혀 있었다. 사람에게 보낼 때
"홈 들어가서 아래로 내리면 배너가…"는 안 된다.

한 장에 앱이 뭘 하는지, 왜 필요한지, 버튼, 4단계, 궁금할 것들을 담았다.
색인은 막았다 — 12명이 차면 사라질 페이지라 검색에 남으면 사람만 헷갈린다.
기존 세 곳의 링크도 여기로 모아서 문구를 고칠 때 한 곳만 고치면 된다.

복붙 문구 4종은 `docs/TESTER_ASK.md`. **D를 제일 먼저 보낸다** — 이미 목록에
있는 5명용이다.
