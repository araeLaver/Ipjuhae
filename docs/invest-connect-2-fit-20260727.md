## 1. 결론

Rentme의 제품과 IR 소재는 투자사 밋업 신청에 활용할 수 있다. 동의 기반 임대 프로필, 임대인-임차인 역방향 매칭, 개인정보 최소화형 확인 리포트는 `AI·기타(신산업)` 및 PropTech 성장 스토리로 설명 가능하고, MVP 기능과 개인정보 없는 제품 증거도 내부에 존재한다.

마감은 **2026-07-29 15:00 KST**다. 보드가 아래 확인값과 외부 제출 승인을 2026-07-28 12:00까지 제공하면 투자사 밋업 단독 신청으로 좁혀 조건부 Go 전환이 가능하다. 대·중견기업 밋업은 기업별 3페이지 협업 제안서가 추가로 필요하고 Rentme와 세 참여사의 직접 협업성이 약하므로 이번 긴급 제출 범위에서는 제외를 권장한다.

## 5. Rentme 제출 포지션

### 한 줄 소개

Rentme는 세입자가 동의 기반 임대 프로필을 만들고, 집주인·임대관리자가 조건에 맞는 세입자와 대화를 시작하도록 돕는 역방향 임대 매칭 플랫폼이다.

### 문제와 해결

- 기존 임대 플랫폼은 매물 검색 중심이라 세입자의 희망 조건과 신뢰 정보를 반복 제출하게 하고, 임대인은 계약 전 확인 항목을 구조적으로 관리하기 어렵다.
- Rentme는 희망 지역, 예산, 입주 가능일, 생활 조건, 사용자가 선택한 재직·소득 관련 확인 상태, 이전 임대인 레퍼런스를 하나의 동의 기반 프로필로 정리한다.
- 원본 증빙을 외부에 그대로 노출하는 대신 확인 여부, 유효기간, 공개 범위를 분리하고 열람 동의와 철회 흐름을 둔다.
- 프로필 요약과 매칭 신호는 신용평가, 금융 심사, 법적 자격 판정이나 자동 합격·탈락 도구가 아니라 대화를 돕는 참고 정보로 한정한다.

### 제품 증거

- MVP 범위: 세입자 프로필, 집주인용 세입자 검색, 매물 등록, 매칭, 메시지, 레퍼런스 요청, 확인 상태 및 리포트 흐름
- 공개 가능한 근거 후보: 개인정보 없는 mock 계정으로 만든 프로필, 검색, 동의 화면, 확인 리포트 화면
- 내부 근거: `docs/pitch-deck-202603.md`, `docs/product-quality-evidence-20260726.md`, `docs/mydata-expert-consultation-draft-20260723.md`
- 제출 금지: 실제 사용자 이름, 연락처, 주소, 생년월일, 회사명, 소득, 신용정보, 원본 증빙, 운영 DB, credential, 내부 관리자 식별자

### 투자·성장 문안 경계

- 실제 사용자, 매출, 파일럿, 제휴, 투자, 수상 수치는 대표가 증빙 가능한 값만 사용한다.
- 확인되지 않은 시장 규모, MAU, 계약 건수, MRR, 투자금 및 기업가치를 사실처럼 기재하지 않는다.
- 현재 단계는 “MVP 구현 및 베타 준비”로 표현하고, 공개 가능한 실제 운영 성과가 확인될 때만 traction으로 전환한다.

- 투자 목적과 행사 참석 의사 확정
- 대표 서명 가능한 동의서·서약서 확보
- IR PDF와 개인정보 없는 제품 화면 3~5장 확보
- 경기스타트업플랫폼 계정 및 최종 제출 담당자 확정
- 보드의 외부 제출 승인

하나라도 충족되지 않으면 **최종 No-Go**로 유지한다. 외부 신청, 파일 업로드, 문의 연락은 별도 보드 승인 없이 실행하지 않는다.
