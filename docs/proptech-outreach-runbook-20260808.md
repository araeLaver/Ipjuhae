## 실행 범위

이번 회차의 접촉 대상은 아래 3곳으로 제한한다.

| 우선순위 | 대상 | 현장 대화 목표 | 허용 후속 자료 |
| --- | --- | --- | --- |
| 1 | 한국프롭테크포럼 | 초기팀 밋업·멘토링 또는 적절한 실무 창구 확인 | 개인정보 없는 1페이지 소개 |
| 2 | 자취백과지도 | 확인 상태 표시에 관한 20분 discovery 동의 확인 | 1페이지 소개, synthetic mock 화면 3장 |
| 3 | 삼삼엠투 | 단기임대의 최소 정보 범위에 관한 20분 discovery 동의 확인 | 1페이지 소개, synthetic mock 화면 3장 |

데브디(집업페이)와 케이알지그룹(Guaranteez)은 이번 회차에서 접촉하지 않는다. 현장 우연 접촉이 생겨도 제품 설명과 연락처 요청을 진행하지 않고 일반적인 인사로 끝낸다.

## 현장 30초 대화문

### 한국프롭테크포럼

안녕하세요. 동의 기반 임대 프로필과 대화 시작 과정을 만드는 초기팀 Rentme입니다. 아직 제휴 제안 단계는 아니고, 개인정보·임대차 정보 경계를 지키며 discovery를 진행하려 합니다. 초기팀이 참여할 수 있는 밋업이나 멘토링, 적절한 실무 창구가 있을까요? 괜찮으시다면 실제 개인정보 없는 1페이지 소개를 행사 후 공식 이메일로 보내도 될까요?

### 자취백과지도

발표에서 사용자가 방의 실제 정보를 확인하는 과정이 인상 깊었습니다. 저희는 임차인이 동의한 정보와 확인 상태를 정리하는 초기 서비스 Rentme입니다. 데이터 제휴나 영업 제안이 아니라, 사용자가 어떤 표시를 믿거나 오해하는지 synthetic mock 화면 3장으로 20분 정도 의견을 듣고 싶습니다. 괜찮으시다면 행사 후 공식 채널로 질문지를 보내도 될까요?

### 삼삼엠투

단기임대에서는 서로 알아볼 시간이 짧아 어떤 정보를 먼저 확인하는지가 중요할 것 같습니다. Rentme는 동의 기반 프로필과 확인 상태를 정리하는 초기 서비스입니다. 영업이나 데이터 요청 없이 synthetic mock workflow로 공개 정보가 적절해지는 경계를 배우고 싶습니다. 20분 discovery가 가능하시다면 행사 후 질문지를 보내도 될까요?

## 후속 동의 확인 문구

상대가 긍정적으로 답한 경우에도 아래처럼 발송 범위를 한 번 더 확인한다.

> 감사합니다. 실제 개인정보가 없는 1페이지 소개와 synthetic mock 화면 최대 3장, 질문 5개만 보내겠습니다. 어느 업무용 이메일 또는 공식 채널로 보내는 것이 좋을까요? 후속 연락은 이번 discovery 조율 목적으로만 사용하겠습니다.

`네`, `보내 주세요`, 구체적인 공식 채널 안내처럼 의사가 명확할 때만 동의로 기록한다. 명함을 건네거나 `나중에 보죠`라고 답한 것만으로 후속 발송 동의로 해석하지 않는다.

## 최소 연락처 기록 양식

G2 전에는 아래 표에 어떤 개인정보도 입력하지 않는다. G2 충족 후 CMO가 업무 목적에 필요한 최소 항목만 회사 관리 공간에 기록한다.

| 필드 | 기록 기준 |
| --- | --- |
| 대상 조직 | 승인 대상 3곳 중 하나 |
| 담당자 | 상대가 업무상 공개·제공한 이름과 역할만 기록 |
| 업무용 채널 | 상대가 직접 지정한 이메일·공식 DM 등 한 개만 기록 |
| 수집 목적 | `20분 discovery 조율` 또는 `프로그램·담당 창구 안내 요청` |
| 최초 접촉일 | 현장 대화일 |
| 후속 동의 | `동의` / `미동의`; 동의한 채널과 자료 범위를 메모 |
| 마지막 진행일 | 답변·일정 합의 등 실질 진행이 발생한 날짜 |
| 30일 검토일 | 최초 접촉일 + 30일 |
| 처리 | `진행 중` / `삭제 검토 보고` / `삭제 완료` |

## 후속 발송 전 체크

- [ ] 대상이 승인된 3곳 중 하나다.
- [ ] 보드가 행사 참석자와 실행 담당자를 확정했다.
- [ ] 현장에서 상대가 후속 연락에 명시적으로 동의했다.
- [ ] 수신 채널을 상대가 직접 지정했다.
- [ ] 첨부물은 개인정보 없는 1페이지 소개와 synthetic mock 화면 최대 3장뿐이다.
- [ ] 실제 고객 정보, 원본 증빙, 운영 DB, credential, 내부 산식, 미확인 성과 수치가 없다.
- [ ] 제휴·데이터 연동·비용·계약·로고 사용을 약속하지 않는다.
- [ ] 발송 후 최초 접촉일 기준 30일 검토일을 기록한다.
