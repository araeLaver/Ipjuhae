# 워크로그 2026-09-20 — 확인서 조달 리드타임 고정 (DOW-1094)

## 한 줄

공고를 본 자리에서 "마감 D-N이면 창업기업 확인서 확보가 물리적으로 가능한가"를 추가 조사 없이 답하도록, 두 확인서의 리드타임을 기관 페이지에서 확인해 프로필에 상시 고정값으로 박았다.

## 왜

프로필 5장 `열린 데드라인`은 **지금 마감이 걸린 값**만 추적한다. 4번(창업기업 확인서)의 위험은 모양이 반대다 — 걸린 기회가 없을 뿐, 걸리는 순간 발급 자체에 며칠이 든다. D-5짜리 공고 앞에서 그때부터 리드타임을 찾기 시작하면 8~9월에 3건을 잃은 실패가 반복된다. 값이 아니라 **조달 시간**이 병목인 유일한 항목이다.

## 확인한 사실 (기관 페이지 기준, 2026-09-20)

### 4번 창업기업 확인서 — 병목 맞음

| 항목 | 값 |
|---|---|
| 발급기관 | 중소벤처기업부·창업진흥원, 심사는 **지방중소벤처기업청** |
| 경로 | 온라인 100% (cert.k-startup.go.kr), 방문 접수 없음 |
| 처리기간 | **서류 제출 완료일부터 10일(토·공휴일 제외) 이내 = 10영업일** |
| 연장 | 부득이한 사유 시 10일 이내 **1회 연장** → 최악 20영업일 |
| 기산 함정 | 보완 요청 시 **서류가 모두 갖춰진 시점부터 재기산**. 신청 클릭일 아님 |
| 유효기간 | **확인일로부터 3년** (업력 7년 초과 시 그 날이 만료) |
| 필수서류 | 사업자등록증명·사실증명(3개월 이내), 법인은 등기부(3개월 이내)+주주명부(7일 이내 작성본) |

### 5번 중소기업 확인서 — 병목 아님

- SMINFO **온라인 자동 발급**이 원칙. 기관이 별도 심사기간을 표기하지 않음
- **직전·당해 사업연도 창업기업은 자료제출 없이 신청서 작성만으로 발급**(유형1)
- 오프라인 예외(우편·지방중기청)는 기관 표현 그대로 "수일 소요"
- 유효기간 현 회차 **2026-04-01 ~ 2027-03-31**. 신규 신청은 직전 사업연도 말일+3개월 경과 후(개인기업 대체자료 3/1~)
- 온라인 자료제출 중단: 2026-09-24~09-27 추석연휴

### 확인 불가로 남긴 것

- 중소기업확인서 온라인 경로의 **구체적 소요 영업일 수치** — 기관 미표기. "자동 발급"이라는 기관 표현만 적고 추정치를 숫자로 쓰지 않았다
- 오프라인 예외 경로 일수 — "수일"이 기관 표기의 전부

## 프로필에 박은 역산 규칙

```
필요일수 = 서류 준비 2영업일 + 심사 10영업일 = 12영업일 (달력 약 17일)
안전 기준(보완·연장 1회 흡수) = 20영업일 (달력 약 28일)
```

- D-20영업일 이상 → 바로 착수
- D-12~19영업일 → 가능하나 무여유, 당일 착수 + 대안 트랙 병행
- **D-12영업일 미만 → 그 자리에서 No-Go**, 추가 조사 없이 대안으로

## 가장 중요한 발견

**값 1이 `예비창업자`인 동안 4번은 발급 자체가 불가하다.** 필수서류가 사업자등록증명이라 사업자등록 전에는 어떤 역산도 성립하지 않는다. 창업기업확인서를 필수로 요구하는 공고는 리드타임 문제가 아니라 **자격 문제**로 전부 No-Go다. 1·2번 회신이 4번의 선행값이라는 뜻이고, 이 함의를 DOW-1090에 보드용으로 남겼다.
