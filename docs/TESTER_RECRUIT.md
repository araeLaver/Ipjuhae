# 비공개 테스터 12명 모집

프로덕션 공개를 막고 있는 건 기능이 아니라 이 숫자다.

채널 배분·일별 목표·72시간 판정·유료 백스톱 기준은 `docs/TESTER_RECRUIT_PLAN.md`에 있다.
이 파일은 **문안 원본**이고, 저 파일은 **실행 계획 원본**이다.

## 구글이 요구하는 것

콘솔에 적힌 그대로다.

```
✔ 비공개 테스트 버전 게시
□ 12명 이상의 테스터가 비공개 테스트 참여를 선택   ← 현재 1명
□ 12명 이상을 대상으로 14일 이상 비공개 테스트 실행
```

**옵트인만으로는 부족하다.** 참여 선택 + 설치 + 14일 유지까지다.
중간에 지우거나 탈퇴하면 카운트가 빠지고 시계가 끊긴다.
12번째 사람이 들어온 날부터 14일이 시작된다.

**에뮬레이터는 안 된다.** Play Integrity에 걸린다. 실제 안드로이드 폰이어야 한다.
아이폰만 쓰는 사람은 참여 자체가 안 된다.

## 참여 링크

```
https://play.google.com/apps/testing/com.ipjuhae.app
```

이게 비공개 테스트(Alpha) 링크다. 내부 테스트 링크
(`play.google.com/apps/internaltest/...`)와 **다르다.**
내부 테스트 참여자는 12명에 들어가지 않는다. 헷갈리면 14일을 통째로 날린다.

```
비공개 테스트 참여 링크
https://play.google.com/apps/testing/com.ipjuhae.app

저도 똑같이 깔아드립니다. 링크 남겨주시면 오늘 안에 설치하고
14일 유지합니다. 중간에 지우지 않습니다.

부탁드릴 것
1. 위 링크에서 테스터 되기
2. 플레이스토어에서 설치
3. 14일 동안 삭제하지 않기 (가끔 열어주시면 더 좋습니다)

설치 확인되면 댓글이나 쪽지 주세요. 바로 맞테스트 들어갑니다.
```

## 모집글 B. 일반 사용자용

부동산·전세 카페, 오픈채팅방, 자취·1인가구 커뮤니티에 쓴다.
**상호 테스트가 아니라 진짜로 쓸 사람을 부르는 글이다.** 구글이 프로덕션 신청 때
"테스터를 어떻게 모았고 어떤 피드백을 받았나"를 서술형으로 묻는다.
그 답을 만들 수 있는 건 이쪽이다.

```
전세 계약 전에 보증금 안전한지 확인하는 앱 만들었습니다. 써보실 분 찾습니다

등기부 을구에 근저당이 얼마 잡혀 있는지, 시세 대비 내 보증금이
어디쯤인지 계산해 줍니다. 집이 경매로 넘어가면 얼마가 남는지까지 나옵니다.

시세를 저희가 추정하지 않습니다. 직접 확인하신 숫자를 넣으시면
그 숫자로만 계산합니다.

웹에서 먼저 보셔도 됩니다
https://www.ipjuhae.com/check

앱은 지금 테스트 중이라 링크로만 설치됩니다
https://play.google.com/apps/testing/com.ipjuhae.app

구글 정책상 12명이 14일간 깔고 있어야 정식 출시가 됩니다.
도와주시면 계속 쓰실 수 있게 만들겠습니다.
불편한 점은 앱 안에서 바로 알려주시면 고치겠습니다.

- 안드로이드 폰, 구글 계정 필요합니다
- 개인정보는 받지 않습니다. 넣으신 숫자는 저장하지 않습니다
```
