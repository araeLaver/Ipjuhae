## 한 일

### 1. 프로필 문서 갱신 (DOW-1090 profile)

- 갱신 담당 줄에 `2026-09-20 인수 완료` 표기
- 8번 행에 게이트일 `2026-10-08` 추가
- 2장에 8번이 DOW-780의 **단독 게이트**라는 근거 추가
- **`5. 열린 데드라인` 절 신설** — 미확인 값 중 날짜 걸린 것만 모으고, 게이트일이 지나면 자동 No-Go 처리

### 2. DOW-780 재판정 — 조건부 Go

**8번만 단독 게이트다.** 이 공고는 예비창업자와 창업 3년 미만을 모두 받아 보통 다른 사업을 막던 1·2번(기업형태·설립일)이 걸리지 않고, 3~7번은 자격에도 제출서류에도 없다. 제출물은 상담신청서·개인정보 동의서 2종뿐이다.

| 8번 값 | 판정 |
|---|---|
| 거주 / 사업장 / 재학 / 재직 | Go |
| 없음 | No-Go → 지역요건 없는 창구로 전환 |

역산 데드라인 (실질 마감 2026-11-19 목 = D-0, **상담을 받는 것**까지 목표):

`D-42 (10-08) 8번 확정 게이트` → `D-34 (10-16) 증빙·플랫폼 가입` → `D-27 (10-23) 서류 서명본` → `D-24 (10-26) CEO 승인` → `D-21 (10-29) 접수 실행` → `D-7 (11-12) 상담 실시 목표` → `D-0 (11-19) 절대 마감`

접수 후 전문가 매칭·일정 조율에 영업일 10일을 확보했다. 접수만 하고 상담을 못 받으면 의미가 없다.

### 3. 루틴 수정 — 말이 아니라 구조로

일일 발굴 루틴(`입주해 전방위 사업기회·사업아이템 일일 발굴`) 설명을 고쳤다.

- 기존 `보드 확인이 필요한 후보는 확인값만 별도 이슈화` 줄이 **정확히 금지된 행동**이라 삭제 → 조건부 판정 + 역산 데드라인으로 교체
- `조건부 판정 규칙` 6개 조항 추가 (프로필 먼저 읽기, 재질문 이슈 금지, 단독 게이트 명시, D-N 표 필수, 선행값 미확인만으로 blocked 금지, No-Go 대안 병기)
- `열린 데드라인 점검` 추가 — 매 실행 프로필 5장 확인, D-14 이내면 CEO 알림, 게이트일 경과 시 기다리지 않고 No-Go 확정

게이트가 사람 기억이 아니라 매일 도는 루틴에 걸리게 했다.
