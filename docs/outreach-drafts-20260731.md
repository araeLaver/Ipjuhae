## 공통 제품 소개와 안전선

Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하고, 임대인·임대관리자가 필요한 정보를 확인한 뒤 대화를 시작하도록 돕는 초기 주거 정보 서비스다. 매물 중개, 계약 대리, 임차인 신용평가, 자동 선별, 보증 또는 법률 조언은 제공하지 않는다.

- 실제 사용자 개인정보, 원본 증빙, 운영 DB, credential, 확인되지 않은 수치를 공유하지 않는다.
- 외부 자료는 mock 계정과 synthetic data만 사용한다.
- `좋은 세입자`, `신뢰점수`, `등급`, `신용 검증`, `안전 보장`, `기관 추천·인증` 표현을 사용하지 않는다.
- 첫 접촉에서는 담당 창구와 검토 가능 여부만 확인한다. 비용, 계약, 데이터 공유, 이용자 모집, 기관명·로고 사용은 별도 승인 대상으로 둔다.

## 1. 서울광역청년센터

### 목적과 제안

17개 서울청년센터를 지원하는 광역센터에 청년 주거 탐색·계약 준비 과정의 문제를 확인할 수 있는 제품 공개 전 사용자 조사 절차가 있는지 묻는다. 기관으로부터 센터 이용자 연락처 제공을 요청하지 않고, 센터가 적절하다고 판단할 때만 공개 모집문 게시 또는 실무자 인터뷰 가능 여부를 검토해 달라고 제안한다.

### 필요한 자료

- 1페이지 제품 소개서
- 실제 정보가 없는 mock 화면 3장 이하
- 20분 인터뷰 질문 5개
- 기관으로부터 이용자 연락처를 제공받지 않고, 인터뷰 중 불필요한 개인정보를 수집·기록하지 않으며, 녹음 없이 익명 요약 원칙 적용
- 공개 모집문 초안과 참여 철회 안내

### 예상 리스크

- 센터가 제품을 추천하거나 공동사업을 진행하는 것으로 오인될 수 있다.
- 청년 대상 모집은 기관의 사전 심사·절차가 필요할 수 있다.
- 사례비, 모집 규모, 현장 대관은 비용·계약 이슈이므로 첫 문의에서 약속하지 않는다.

### 이메일 초안

제목: 청년 1인가구 주거 준비 과정 discovery 협조 절차 문의

안녕하세요. Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하는 초기 주거 정보 서비스입니다. 매물 중개, 계약 대리, 신용평가 또는 자동 선별은 제공하지 않습니다.

제품 공개 전에 청년 1인가구가 집을 찾고 계약을 준비하면서 반복해서 어려워하는 정보·서류·공식 지원 연결 지점을 확인하고자 합니다. 센터 이용자 정보 제공을 요청드리는 것은 아니며, 기관이 허용하는 방식으로 실무자 1명 인터뷰 또는 청년 5명 이하의 공개 모집 안내가 가능한 절차가 있는지 문의드립니다.

인터뷰는 20분 이내로 진행하며, 기관으로부터 이용자 연락처를 제공받지 않고 인터뷰 중 불필요한 개인정보를 수집·기록하지 않겠습니다. 녹음은 진행하지 않고 결과는 익명으로 제품 개선에만 사용하겠습니다. 실제 개인정보가 없는 mock 화면 3장과 질문지를 사전 검토용으로 전달할 수 있습니다. 적절한 담당 부서와 검토 절차를 안내해 주시면 내부 승인 후 자료를 보내겠습니다. 감사합니다.

## 2. 서울시 1인가구지원과

### 목적과 제안

서울시가 안내하는 25개 자치구 1인가구지원센터와 전월세 안심계약 도움서비스의 운영 경험을 바탕으로, 임차인이 계약 전 스스로 준비해야 할 정보와 민간 서비스가 넘지 말아야 할 경계를 듣는다. 특정 이용자 소개가 아니라 적절한 실무 부서 또는 자치구 센터 한 곳의 연결 절차만 요청한다.

### 필요한 자료

- 제품 범위와 비중개·비법률조언 경계 1페이지
- 계약 전 준비 checklist mock
- 질문 3개: 반복 누락 정보, 공식 채널 연결, 오인 위험 문구
- 개인정보·피해 사례 미수집 원칙

### 예상 리스크

- 공공 상담을 민간 제품 검수나 공식 승인으로 확대 해석하면 안 된다.
- 실제 계약·피해 사례가 나오면 기록하지 않고 공식 상담 절차로 돌려야 한다.
- 서울시·센터 명칭과 답변을 마케팅 보증으로 사용할 수 없다.

### 콜 스크립트

안녕하세요. 청년과 1인가구의 계약 전 정보 준비를 돕는 초기 서비스 Rentme 팀입니다. 서울시 1인가구지원센터 이용자나 개인정보를 요청드리는 것은 아니고, 전월세 안심계약 도움서비스 또는 자치구 센터 실무자에게 계약 전 반복 누락 정보와 공식 채널 연결 문구를 20분 정도 여쭙고 싶습니다. 실제 개인정보 없는 mock 화면만 사용하고, 서울시 추천이나 제휴로 표시하지 않겠습니다. 이런 무상 사전 사용자 조사 문의를 검토할 담당 부서나 센터 연결 절차가 있을까요?

## 3. 대한주택관리사협회

### 목적과 제안

공동주택 관리 현장에서 임차인 입주 전후 반복 확인하는 정보, 관리사무소가 받아서는 안 되는 민감정보, 임대인·임차인·중개사·관리사무소의 책임 경계를 확인한다. 회원 대상 배포나 제휴를 바로 제안하지 않고, 교육·정책 또는 회원지원 담당자 1명의 mock workflow 검토 가능 여부만 묻는다.

### 필요한 자료

- 관리사무소 기능이 아니라는 점을 명시한 제품 소개서
- synthetic profile과 공개 범위 설정 화면
- 입주 전 확인 workflow 1장
- 30분 피드백 질문지

### 예상 리스크

- 공동주택 관리와 개별 임대차 중개·심사의 역할을 혼동할 수 있다.
- 협회 회원 모집, 교육 과정 편성, 데이터 연동, 비용은 별도 승인과 계약 검토가 필요하다.
- 협회 명칭·로고와 피드백을 제품 인증처럼 사용할 수 없다.

### 전화 후속 이메일 초안

제목: 공동주택 관리 현장의 임대·입주 정보 workflow 피드백 가능 여부 문의

안녕하세요. Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하고 임대인·임대관리자와 필요한 범위에서 대화를 시작하도록 돕는 초기 서비스입니다. 매물 중개, 계약 대리, 신용평가 또는 자동 선별은 제공하지 않습니다.

제품 공개 전 공동주택 관리 현장에서 입주 전후 반복 확인하는 정보, 관리사무소가 받지 않아야 할 민감정보, 임대인·임차인·중개사·관리사무소의 책임 경계를 점검하려 합니다. 실제 개인정보가 없는 mock workflow를 기준으로 교육·정책 또는 회원지원 담당자 한 분께 30분 이내 의견을 받을 수 있는 절차가 있는지 문의드립니다.

현 단계에서는 회원 모집, 데이터 제공, 비용, 협회 명칭·로고 사용 또는 공식 제휴를 요청드리지 않습니다. 사전 검토가 가능한 자료 범위를 안내해 주시면 내부 승인 후 전달하겠습니다. 감사합니다.

## 4. 마이홈포털 안내 / LH 콜센터

### 목적과 제안

Rentme 화면에서 공공 임대·주거복지 정보를 직접 복제하지 않고 마이홈 공식 검색과 상담 채널로 연결할 때 권장되는 표기와 재확인 문구를 묻는다. 제휴나 데이터 제공을 요청하지 않고 일반 공개 안내의 정확성만 확인한다.

### 필요한 자료

- 공식 URL 연결 위치가 표시된 mock 화면 2장
- `자격·모집 일정은 공식 공고에서 재확인` 문구
- 복제하지 않을 정보와 갱신 정책 요약

### 예상 리스크

- 콜센터는 제품 검토 담당 부서가 아니므로 담당 창구 안내만 받고 통화를 짧게 끝낸다.
- 상담 답변을 법률 의견, 자격 판정 또는 공식 승인으로 간주하지 않는다.
- LH 문의와 중복될 가능성이 있어 우선순위를 가장 낮게 둔다.

### 콜 스크립트

안녕하세요. 임차인이 주거 정보를 정리할 때 마이홈의 공식 주거복지 검색과 상담 채널로 연결하는 초기 서비스 Rentme 팀입니다. 저희가 자격이나 신청 가능 여부를 판단하지 않고, 사용자가 공식 공고를 다시 확인하도록 안내하려 합니다. 민간 제품 화면에서 마이홈 URL과 콜센터를 표시할 때 권장 표기, 반드시 포함할 재확인 문구, 별도로 문의해야 할 담당 부서가 있는지 세 가지만 여쭙고 싶습니다.
