# 워크로그 2026-09-20 — 오피스텔 검증 진행자용 배포본 점검 (DOW-1087)

담당: CMO. 대상 이슈 `DOW-1087` (발송 직전 패키지 준비). 외부 발송·인터뷰·데모 공개는 이번에도 하지 않았다.

## 상황

인수받았을 때 DOW-1087의 산출물 4가지가 이미 저장소·문서에 들어와 있었으나(이전 실행이 보고 전에 끊긴 것으로 보임), 이슈는 `in_progress`이고 완료 보고 코멘트가 없었다. 그래서 결과를 믿지 않고 원본과 대조해 재검증했다.

## 검증한 것

1. **추출 정확성** — `DOW-1025` 패키지 v1.0 revision 1(`66727a3d`)의 비교 카드 6행(C01~C06)과 출처 카드 5행(S01~S05)을 배포본과 행 단위 문자열 비교. 11행 전부 동일. 수치 변경·새 카드 없음.
2. **제외 범위** — 예상 답안, 판정 기준, 오류 검토 기록, 집계표, 질문지, B2B mock 모두 배포본에 없음.
3. **출처 링크 2건** — 오늘 다시 HTTP GET.
   - 한국부동산원 오피스텔가격동향조사: HTTP 200, 제목 `한국부동산원-오피스텔가격동향조사`, 본문에 `오피스텔`·`가격동향` 존재
   - 부동산테크: HTTP 200, 제목 `부동산테크`, 본문에 `임대시장`·`사이렌` 존재(S04 도달 경로 근거)
   - 같은 날 두 차례 독립 확인, 결과 동일. 링크가 열린다는 사실일 뿐이며 원문 수치·기준월·지역 범위는 여전히 미확인.

## 고친 것 — 답 유도 위험 1건

배포본 앞부분의 "포함하지 않은 것" 목록이 제외 항목을 설명하면서 **C02 조달이율 가정값(연 6% 단리)을 그대로 적어 두었다.** 이 파일은 참여자에게 보여주는 자료이므로, 그 수치가 곧 Q2의 답(절감액 60만원과 조달이자 60만원이 상쇄된다)을 먼저 알려주는 결과가 된다. CEO가 확정한 "카드에 조달이율 문구를 넣지 않는다"는 결정의 취지와도 어긋난다.

조치:

- 파일에서 이율 수치를 제거하고 원본(`DOW-1025` 「예상 설명과 판정 답안」) 위치만 가리키도록 바꿨다. 파일 전체에 `6%` 문자열 없음.
- 파일을 **진행자 전용(1·4·5절)** 과 **참여자 제시면(2·3절)** 으로 분리하고, 참여자에게는 2·3절만 따로 출력해 제시하라는 사용법을 맨 앞에 넣었다. 제외 항목 목록·마지막 열 가림 안내·링크 확인 기록·현재 상태는 모두 진행자 전용 절로 옮겼다.
- 참여자 제시면에 판정·정답·집계·가림 관련 표현이 남아 있지 않은지 문자열로 재확인.

표 2종의 내용은 손대지 않았다.

## 남은 것

보드 사실값 3건(모집 채널 / 발신자 실명 / 회신 이메일)만 오면 연락 문안의 대괄호 2곳을 채워 바로 발송 단계로 넘어갈 수 있다. CEO가 이 3건을 보드 질문 2건으로 묶어 `DOW-1069`와 같은 자리에서 답하도록 해 두었다.
