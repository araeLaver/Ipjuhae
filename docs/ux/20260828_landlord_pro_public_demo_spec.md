# 임대인 Pro 월 29,900원 공개 데모 플로우 명세

작성일: 2026-08-28
목적: 개인정보를 수집하거나 결제를 실행하지 않고, 소규모 임대인이 `후보 탐색 시간 단축` 가치와 월 29,900원 파일럿 예약 의향을 판단하도록 돕는다.

## 1. 데모 원칙

- 4장, 모바일 우선(권장 캡처 390×844), 각 화면에서 핵심 문장 하나만 강조한다.
- 모든 인물·매물·수치는 합성 예시다. 실제 이름, 사진, 주소, 연락처, 계약·소득·신용 원자료는 쓰지 않는다.
- `확인됨`은 예시 데이터의 상태 표현일 뿐 입주해가 신원·소득·계약 성사를 보증한다는 뜻으로 쓰지 않는다.
- 현재 구현 화면을 바탕으로 하되, 파일럿 전용 가격과 예약 CTA는 `검토 중`으로 명확히 표시한다.
- CTA는 외부 전송이나 개인정보 입력 없이 정적인 보드 검토 상태로 둔다.

## 2. 화면 흐름

### 화면 1 — 문제 인식

**목표:** 임대인의 반복 탐색 문제를 5초 안에 이해시킨다.

- 상단 배지: `임대인 Pro · 파일럿 데모`
- 제목: `문의가 오기만 기다리지 말고, 조건에 맞는 세입자 후보를 먼저 살펴보세요.`
- 보조 문구: `희망 지역·예산·입주 시기와 생활 조건을 기준으로 공개 범위 안의 후보를 모아봅니다.`
- 시각 요소: `조건 정리 → 후보 탐색 → 검토` 3단계 도식
- 하단 고지: `아래 내용은 합성 예시이며 실제 사용자나 매물을 나타내지 않습니다.`
- CTA: `예시 후보 보기`

**구현 참조:** 신규 데모 표지. 기존 제품 기능을 설명하되 자동 추천의 실시간 작동을 암시하지 않는다.

### 화면 2 — 역매칭 후보 목록

**목표:** 임대인이 여러 문의를 수동 정리하는 대신 후보를 비교하는 가치를 보여준다.

- 제목: `이 매물 조건과 가까운 예시 후보 3명`
- 조건 요약 칩: `서울 동남권` `보증금 2천 이하` `월 90만 이하` `10월 입주` `비흡연`
- 카드 1: `후보 A` / `조건 적합 4/5` / `1인 가구` / `비흡연` / `장기 거주 희망`
- 카드 2: `후보 B` / `조건 적합 4/5` / `2인 가구` / `반려동물 없음` / `11월 입주 가능`
- 카드 3: `후보 C` / `조건 적합 3/5` / `1인 가구` / `비흡연` / `예산 협의 필요`
- 상태 표현: 원형 점수 대신 `조건 적합 n/5`를 사용한다. 신뢰도·신용도를 단일 숫자로 서열화하지 않는다.
- 각 카드 고지: `합성 프로필`
- CTA: `후보 A 검토하기`

**구현 참조:** `/landlord/tenants`, `components/landlord/TenantCard.tsx`. 실제 데모에서는 이름·사진·trust score·신용 배지를 제거하고 위 mock content로 대체한다.

### 화면 3 — 임대인 검토 경험

**목표:** 후보의 장점과 확인 필요 사항을 같은 무게로 보여줘 의사결정 보조 제품임을 전달한다.

- 제목: `후보 A를 한눈에 검토하세요`
- `조건과 맞는 점`
  - `희망 지역 범위 일치`
  - `예산 범위 일치`
  - `비흡연 조건 일치`
  - `장기 거주 희망`
- `추가 확인이 필요한 점`
  - `정확한 입주일은 대화로 확인 필요`
  - `재직·소득 관련 상태는 본인 동의 후 별도 확인 필요`
- 상태 라벨 사전
  - `조건 일치`: 입력된 선호 조건끼리 일치
  - `확인 필요`: 정보가 없거나 상대방 확인이 필요한 상태
  - `예시`: 데모용 합성 정보
- 안내문: `입주해는 후보 검토를 돕는 도구입니다. 후보 공급, 정보의 완전성, 계약 체결 또는 임대 성과를 보장하지 않습니다.`
- CTA: `관심 후보로 표시` — 데모에서는 저장 성공 토스트만 보여주거나 정적으로 표시

**구현 참조:** `/landlord/tenants/[id]`. 연락처, 원문 문서, 실제 검증값과 메시지 보내기 기능은 공개 데모에서 숨긴다.

### 화면 4 — 월 29,900원 파일럿 CTA

**목표:** 가격 수용성과 예약 의향만 검증한다.

- 상단 배지: `출시 전 유료 파일럿 검토 중`
- 제목: `임대인 Pro 파일럿 · 월 29,900원`
- 포함 예정:
  - `매물 조건 기반 후보 탐색`
  - `후보 비교 및 관심 후보 정리`
  - `확인 필요 항목을 구분한 검토 화면`
- 가격 보조 문구: `파일럿 기간 제안 가격이며, 정식 출시 가격과 제공 범위는 달라질 수 있습니다.`
- 주 CTA: `파일럿이 열리면 알려주세요`
- CTA 하단: `지금 결제되지 않으며, 이 데모에서는 개인정보를 입력하거나 전송하지 않습니다.`
- 보조 링크: `아직 고민돼요` → 이유 선택 예시(`가격`, `후보 수`, `검증 범위`, `기타`)만 표시하고 저장하지 않음

**구현 구분:** 현재 `lib/plans.ts`의 Pro 가격은 49,900원이고 실제 구독 경로가 존재한다. 이 화면의 29,900원은 보드 승인 전 실제 `/landlord/subscription` 또는 Stripe checkout과 연결하지 않는다.

## 3. 공개 가능 / 수정 필요 체크리스트

### 공개 가능

- [x] 인물은 `후보 A/B/C`로 표기하고 사진을 쓰지 않음
- [x] 지역은 구 단위보다 넓은 `서울 동남권` 합성 표현 사용
- [x] 연락처·정확한 주소·계약·소득·신용·신분증 원자료 없음
- [x] 모든 후보 카드에 `합성 프로필` 표시
- [x] 추천 점수 대신 설명 가능한 `조건 적합 n/5` 사용
- [x] 보증 부인 및 `확인 필요` 문구 포함
- [x] 결제·개인정보 수집이 실행되지 않는 정적 CTA

## 4. 보드 승인값

1. 가격 표기: `월 29,900원`의 부가세 포함 여부
2. 파일럿 조건: 기간, 모집 인원, 중도 해지·환불 기준
3. 제공 범위: 후보 탐색·비교·검토 화면 중 실제 파일럿에 포함할 기능
4. CTA 단계: 정적 데모 유지 / 익명 의향 클릭 집계 / 연락처 예약 수집 중 선택
5. 공개 범위: 보드 내부 검토 / 제한 링크 / 외부 게시 중 선택

## 5. 기술 지원 요청 범위

- 권장 경로: 인증·DB 호출이 없는 `/demo/landlord-pro` 정적 route
- mock data를 route 내부 상수로 고정하고 production DB/API import를 금지
- 화면 상단에 항상 `데모 · 합성 데이터` 워터마크 표시
- 모든 CTA는 보드 승인 전 disabled 또는 로컬 상태 변경만 허용
- 390px 및 1440px에서 레이아웃 확인, 키보드 focus와 4.5:1 텍스트 대비 확인

## 6. QA 인수 기준

- 페이지 소스와 네트워크 요청에 실사용자 식별자·주소·연락처가 없다.
- 로그인 없이 볼 수 있더라도 제품 내부 인증 route로 이동하지 않는다.
- 29,900원 CTA가 Stripe checkout, 예약 API, analytics의 개인정보 payload를 호출하지 않는다.
- 네 화면 모두 `합성 예시`, 비보증 문구, 현재/예정 기능 구분을 찾을 수 있다.
- 모바일에서 주요 CTA와 고지 문구가 접히거나 겹치지 않는다.
