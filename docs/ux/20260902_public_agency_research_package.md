# 공공기관 협력용 사용자 조사 패키지

- 버전: v1.0
- 작성일: 2026-09-02
- 적용 대상: 서울광역청년센터·강동·관악 등 공공기관 협력 사용자 조사
- 문서 상태: 기관 검토용 초안. 기관의 명시적 승인 전 모집·일정 확정·개인정보 수집 금지

## 1. 목적과 운영 원칙

이 패키지는 청년 임차인이 집을 알아보고 계약을 검토할 때 어떤 정보에서 막히는지, 입주해의 안내 구조가 이해와 다음 행동 결정에 도움이 되는지를 확인하기 위한 것이다. 법률 판단, 권리분석, 공인중개, 기관 상담 또는 계약 체결을 대신하지 않는다.

운영 원칙은 다음과 같다.

1. 기관 담당자가 범위·문구·모집 방식·데이터 처리 방식을 서면 승인한 뒤에만 실행한다.
2. 참여 여부는 자율이며, 거절·중단해도 기관 서비스 이용에 불이익이 없다.
3. 이름, 전화번호, 이메일, 주민등록번호, 정확한 주소, 계약서 원본 등 직접 식별정보는 조사 기록에 수집하지 않는다.
4. 실제 계약서·등기 문서·신분증·화면에 개인정보가 있으면 제시하거나 공유하지 않도록 먼저 안내한다.
5. 답변은 연구 목적의 요약·익명 인용에만 사용하며, 개별 참여자를 평가하거나 기관 상담 기록과 결합하지 않는다.
6. 참여자가 법률·중개·긴급 주거 문제를 질문하면 답을 추정하지 않고 해당 기관의 공식 상담 채널 또는 자격 있는 전문가에게 연결한다.

| 종료 후 | 익명 요약, 승인된 보관·파기 | 원자료 무기한 보관, 무단 외부 공유 |

## 3. 20분 인터뷰 안내문

### 모집 안내문 초안

> 입주해는 청년 임차인이 집을 알아보고 계약을 검토하는 과정에서 어떤 정보가 어렵고 어떤 안내가 도움이 되는지 알아보기 위해 약 20분 인터뷰를 준비하고 있습니다. 참여는 자율이며, 참여하지 않거나 도중에 중단해도 기관 서비스 이용에 불이익이 없습니다. 이름·연락처·주민등록번호·정확한 주소·계약서 원본은 요청하지 않습니다. 답변은 개인을 알아볼 수 없게 요약해 서비스 개선 연구에만 사용합니다. 이 인터뷰는 법률 자문, 공인중개 또는 기관 상담을 제공하지 않습니다. 실제 계약에 관한 판단이 필요하면 기관의 공식 상담 채널이나 자격 있는 전문가에게 문의해 주세요. 기관 승인 후에만 모집을 시작합니다.

### 시작 시 진행자 낭독문

> 오늘 대화는 약 20분이며, 집을 알아보거나 계약을 검토할 때의 경험과 안내 자료의 이해도를 알아보기 위한 것입니다. 정답은 없습니다. 답하기 불편한 질문은 건너뛰거나 언제든 중단할 수 있고, 그에 따른 불이익은 없습니다. 이름, 연락처, 정확한 주소, 주민등록번호, 실제 계약서나 신분증은 말씀하거나 보여주지 말아 주세요. 저희는 법률·중개·기관 상담을 대신하지 않으며 개별 계약의 안전 여부를 판단하지 않습니다. 동의하시면 개인을 알아볼 수 없게 메모하겠습니다. 녹음은 별도 선택이며, 동의하지 않아도 참여할 수 있습니다. 질문 있으실까요?

## 4. 20분 인터뷰 질문지

진행자는 질문 순서를 유연하게 조정하되, 특정 답을 유도하거나 실제 계약의 위험도를 판정하지 않는다. 괄호 안 문구는 선택적 후속 질문이다.

| 시간 | 질문 | 확인하려는 것 |
| --- | --- | --- |
| 0–2분 | 안내·동의 확인. 최근 집을 알아본 경험을 특정 주소 없이 간단히 말씀해 주실 수 있나요? | 맥락, 참여 안전 |
| 2–5분 | 집을 알아보기 시작했을 때 가장 먼저 한 일은 무엇이었나요? (어떤 사이트·사람·기관을 찾았나요?) | 탐색 시작점, 채널 |
| 5–8분 | 이해하거나 확인하기 가장 어려웠던 정보는 무엇이었나요? (왜 어려웠나요?) | 핵심 문제, 언어 장벽 |
| 8–11분 | 계약 전에 꼭 확인해야 한다고 생각한 것은 무엇인가요? 실제로 무엇을 확인했나요? | 인식과 행동의 차이 |
| 11–14분 | 혼자 판단하기 어려울 때 누구에게 어떤 도움을 요청했나요? 도움을 요청하지 못했다면 이유는 무엇인가요? | 상담 전환, 접근 장벽 |
| 14–17분 | 아래 체크리스트 샘플을 보고, 먼저 읽는 항목과 이해되지 않는 표현을 말해 주세요. | 정보 위계, 용어 이해 |
| 17–19분 | 이 안내를 본 뒤 실제로 할 다음 행동은 무엇인가요? 빠졌거나 과도하게 안심시키는 내용이 있나요? | 행동 가능성, 오인 위험 |
| 19–20분 | 오늘 꼭 덧붙이고 싶은 점이 있나요? 기록 철회 또는 삭제 요청 방법을 다시 안내드리겠습니다. | 미포착 요구, 종료 확인 |

### 금지 질문·행동

- 이름, 연락처, 주민등록번호, 정확한 주소, 집주인·중개사 실명 요구
- 계약서·등기부·신분증·계좌 정보 업로드 또는 화면 공유 요청
- “이 집은 안전하다/위험하다”, “계약해도 된다” 같은 판정
- 참여자의 취약 상황을 설득·홍보·영업에 활용
- 녹음에 동의하지 않은 참여자의 음성·화면 기록

## 5. 참여자 동의 및 익명화 문구

### 필수 동의 확인

각 항목은 개별적으로 읽고 확인한다. 동의 기록에는 연구용 참여 ID, 동의 항목, 일시, 동의문 버전만 남긴다.

- [ ] 조사 목적과 약 20분의 진행 방식을 이해했습니다.
- [ ] 참여는 자율이며 질문을 건너뛰거나 언제든 중단할 수 있음을 이해했습니다.
- [ ] 이 조사가 법률 자문·공인중개·기관 상담을 대신하지 않음을 이해했습니다.
- [ ] 직접 식별정보와 실제 계약 문서를 제공하지 않도록 안내받았습니다.
- [ ] 답변을 개인을 알아볼 수 없게 요약하여 서비스 개선 연구에 사용하는 데 동의합니다.

필수 항목 중 하나라도 동의하지 않으면 인터뷰를 시작하지 않는다.

### 선택 동의

- [ ] 익명 처리된 짧은 발언을 내부 연구 보고서에 인용하는 데 동의합니다.
- [ ] 음성 녹음에 동의합니다. 동의하지 않아도 메모 방식으로 참여할 수 있습니다.

선택 동의는 기본값을 `동의 안 함`으로 둔다. 외부 발표·홍보·제안서 인용은 위 선택 동의에 포함되지 않으며 별도 승인이 필요하다.

### 익명화 규칙

- 참여자는 `P01`, `P02` 형식의 연구용 ID로만 표기한다.
- 자유 응답에서 사람·기관 세부 부서·동네 이하 위치·희귀 직업·특정 날짜·금액 조합처럼 재식별 가능한 표현을 범주화하거나 삭제한다.
- 인용문은 뜻을 바꾸지 않는 범위에서 식별 단서를 제거하고 `[지역 삭제]`, `[금액 범주화]`로 표시한다.
- 동의 기록, 원메모, 분석본을 분리하고 최소 인원만 접근한다.
- 보관 기간과 파기 방식은 기관 승인 전 확정한다. 확정되지 않으면 수집하지 않는다.
- 철회·삭제 요청 접수 경로와 처리 담당자는 모집문 공개 전에 기재한다.

### 중단·철회 안내문

> 지금 중단하거나 답변하지 않으셔도 불이익이 없습니다. 기록 삭제를 원하시면 기관이 승인한 요청 경로로 연구용 참여 ID와 함께 알려 주세요. 이미 완전히 익명화되어 개인과 연결할 수 없는 집계 결과는 삭제가 어려울 수 있으며, 그 시점과 범위는 동의 전에 안내합니다.

## 6. 30분 미니세션 구성안

목표는 체크리스트의 이해도와 행동 유도성을 짧게 검증하는 것이다. 최대 4명 소그룹 또는 1:1로 진행한다. 그룹에서는 다른 참여자에게 개인 경험 공개를 요구하지 않는다.

| 시간 | 활동 | 진행자 행동 | 산출물 |
| --- | --- | --- | --- |
| 0–3분 | 목적·안전·동의 | 낭독문 사용, 질문·중단권 확인 | 동의 상태 |
| 3–7분 | 개인 맥락 워밍업 | 정확한 주소·계약 정보 없이 탐색 단계만 질문 | 단계 범주 |
| 7–12분 | 첫인상 테스트 | 체크리스트를 30초 보여준 뒤 기억나는 항목 질문 | 주목 항목 |
| 12–18분 | 생각 말하기 | “무엇을 뜻한다고 이해했나요?”, “다음 행동은?”만 질문 | 용어·행동 장애물 |
| 18–23분 | 우선순위 분류 | `지금 확인`, `전문가에게 문의`, `나중에 확인`으로 분류 | 정보 위계 |
| 23–27분 | 경계 문구 검증 | 서비스가 해주는 일·하지 않는 일을 참여자가 재진술 | 오인 지점 |
| 27–30분 | 회고·종료 | 빠진 항목, 불안 조장 표현, 철회 경로 재안내 | 개선 제안 |

진행 성공 기준:

- 참여자가 체크리스트만 보고도 최소 2개의 구체적 다음 행동을 말한다.
- 참여자가 “자동 판정/보증”이 아니라 “확인 보조”라고 설명한다.
- 전문 상담이 필요한 항목과 공식 문의 경로를 구분한다.
- 직접 식별정보나 실제 계약 문서가 세션 기록에 남지 않는다.

## 7. 비자문 체크리스트 샘플

### 계약 전 확인을 돕는 시작 체크리스트

> 이 체크리스트는 확인할 항목을 빠뜨리지 않도록 돕는 일반 정보입니다. 특정 매물의 안전성, 권리관계 또는 계약 가능 여부를 판정하지 않으며 법률 자문·공인중개·기관 상담을 대신하지 않습니다. 서류의 최신성·진위·법적 의미와 실제 계약 판단은 공식 발급처, 담당 기관 또는 자격 있는 전문가에게 확인하세요.

#### 1단계 — 조건을 기록해 두기

- [ ] 보증금, 월세, 관리비와 별도 비용을 서로 구분해 적었다.
- [ ] 계약 기간, 입주 가능일, 수리·옵션 등 합의 내용을 말이 아닌 문서로 확인할 항목에 표시했다.
- [ ] 감당 가능한 총비용과 자금 지급 일정을 다시 확인했다.

#### 2단계 — 사람·매물·서류 확인 준비

- [ ] 계약 상대방과 권한을 어떤 공식 자료로 확인할지 정했다.
- [ ] 주소와 호수 등 서류 사이의 표기가 일치하는지 확인할 계획을 세웠다.
- [ ] 필요한 공적 서류를 어디서 최신본으로 발급·열람할지 확인했다.
- [ ] 이해하지 못한 권리관계·특약·채무 관련 표현은 추측하지 않고 질문 목록에 적었다.

#### 3단계 — 도움 요청과 기록

- [ ] 판단이 필요한 질문을 공식 기관 또는 자격 있는 전문가에게 문의할 목록으로 분리했다.
- [ ] 확인한 날짜, 출처, 답변 주체를 기록한다.
- [ ] 설명을 듣지 못했거나 내용이 일치하지 않으면 서두르지 않고 추가 확인한다.
- [ ] 송금·서명 전 최종 조건과 상대방 정보를 다시 대조한다.

### 체크리스트 상태 라벨 UX

판정처럼 보이는 빨강/초록 또는 `안전/위험` 라벨을 사용하지 않는다. 다음 세 상태만 쓴다.

- `확인 전`: 아직 자료나 답변을 확인하지 않음
- `확인 기록`: 사용자가 출처와 날짜를 기록함. 안전 보증을 뜻하지 않음
- `전문 문의 필요`: 해석·판단을 공식 기관 또는 자격 있는 전문가에게 문의해야 함

모든 완료 상태 옆에는 “확인 기록은 안전성 보증이 아닙니다”를 반복 노출한다.

## 8. 진행자 대응 가이드

## 10. 결과 요약 템플릿

- 세션 수와 방식: 개인을 식별할 수 없는 집계만 기재
- 반복된 문제: 2명 이상에서 관찰된 경우와 단일 관찰을 구분
- 근거: 익명 메모 ID와 관찰 사실
- 해석: 관찰과 팀의 추론을 분리
- 제안: 문구·순서·상담 전환 개선안
- 위험 검토: 과도한 안심, 법률·중개 오인, 개인정보 노출 가능성
- 결정: `반영`, `추가 검증`, `보류`와 이유
- 외부 공유: 기관 승인 전 금지

## 11. 검수 기준

기관 담당자와 내부 검수자는 아래 항목을 모두 확인한다.

- [ ] 20분 안내문과 질문지가 시간 순서대로 바로 실행 가능하다.
- [ ] 자율 참여, 질문 건너뛰기, 중단, 불이익 없음이 명시되어 있다.
- [ ] 필수 동의와 녹음·익명 인용 선택 동의가 분리되어 있다.
- [ ] 직접 식별정보와 실제 계약 문서를 수집하지 않는다고 명시되어 있다.
- [ ] 익명화, 접근 제한, 보관 기간 확정, 철회·삭제 절차가 포함되어 있다.
- [ ] 30분 미니세션에 시간, 활동, 진행자 행동, 산출물이 모두 있다.
- [ ] 체크리스트가 안전·위험 판정 또는 보증처럼 읽히지 않는다.
- [ ] 법률 자문·공인중개·기관 상담을 대체하지 않는다는 경계가 모집·시작·체크리스트에 반복된다.
- [ ] 기관의 명시적 승인 전 모집·연락처 수집·일정 예약을 막는 게이트가 있다.
- [ ] 긴급·전문 상담 전환은 기관이 승인한 공식 경로만 사용하도록 되어 있다.
- [ ] 결과 공유 범위와 외부 공개 금지가 명시되어 있다.
- [ ] 참여자에게 보여 주는 모든 문구가 쉬운 한국어이며 특정 답변을 유도하지 않는다.
