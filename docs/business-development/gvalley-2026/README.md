## 편집 가능 여부와 차단 요인

신청서는 암호화되지 않아 내용 추출이 가능하다. 다만 공식 표 구조를 보존하는 편집·HWP 저장·PDF 출력은 아직 검증할 수 없다.

- `/Applications` 목록에 한컴 편집 앱이 없고, `soffice`, `libreoffice`, `hwp5html`, `hwp5txt`, `pandoc` 명령이 PATH에 없다.
- Microsoft Word는 설치되어 있으나 이 신청서의 HWP 편집·저장 경로는 검증되지 않았다. Word 설치만으로 HWP 편집 가능 판정하지 않는다.
- `olefile`로 구조·본문은 읽었다. 이는 페이지 렌더링이나 HWP 편집 기능이 아니다.
- 지원 필요: HWP를 열고 공식 표를 유지해 저장할 수 있는 편집 환경 또는 해당 환경을 가진 내부 작업 담당자. 접근 방법과 담당자를 9월 30일까지 연결 요청한다. 유료 구매·외부 업로드·계정 로그인은 요청 범위에 포함하지 않는다.
- 완료 조건: 10월 3일 공식 HWP 편집본, 10월 5일 출력 PDF. 서식2 5~15쪽, 도표 2종 가독성, 표 잘림·글꼴·서식 순서를 실제 출력물로 검수한다. 대표자 정보·동의·날인은 미입력으로 둔다.
