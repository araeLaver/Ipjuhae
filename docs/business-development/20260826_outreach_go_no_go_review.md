# 2026-08-26 아웃리치 4건 Go/No-Go 및 발송 준비 검증

검토 기준일: 2026-08-26

실행 상태: 외부 이메일·DM·전화·예약·제출 미실행

## 1. 결론

현재 **즉시 발송 Go는 0건**이다. 민달팽이유니온은 발신자 정보와 보드 승인만 확정하면 첫 이메일을 보낼 수 있는 **조건부 Go**다. 나머지 3건은 공식 접점 확인 또는 모집·동의 자료가 선행되어야 한다.

첫 접촉에는 첨부파일을 넣지 않는다. 회신으로 자료를 요청받은 경우에만 공개 범위가 검수된 1p와 합성 화면을 보내며, 이용자 모집은 모집문·동의문·질문지·사례비 정책이 모두 확정된 뒤 별도로 승인한다.

## 3. 후보별 검증

### 민달팽이유니온

- 공식 사이트 하단에서 단체 이메일 `minsnailunion@gmail.com`, 전화 `070-4145-9120`을 확인했다. 사이트도 전화 연결이 어려울 수 있어 공식 메일을 권한다.
- `minsnailcase@gmail.com`과 상담 폼은 개별 주거상담용이므로 이번 전문가 인터뷰 문의에 사용하지 않는다.
- 본문에서 서비스가 법률 판단·안전 보장을 제공하지 않는다는 경계, 개인정보·사례·단체 로고를 요구하지 않는다는 문구는 유지한다.
- “초기 문구 검수”를 무료 전문 자문처럼 보이게 하지 않도록 `가능한 참여 방식과 비용 정책도 안내 부탁드립니다`를 추가한다. 사례비가 요구되면 보드 재승인 전 확약하지 않는다.

### 한국사회주택협회

- 협회 사이트는 응답하지만 자동 검증 환경에서 문의 주소를 확인하지 못했다. `socialhousing.kr` 도메인만으로 수신처를 추정하지 않는다.
- 첫 문의는 회원사 2~3명 연결을 바로 요청하기보다, `협회 업무 범위에 맞는지와 회원사 대상 문제 인터뷰 안내 절차가 있는지`를 먼저 묻는 2단계 접근이 적절하다.
- 회원사 소개 페이지는 타깃 적합성 근거일 뿐 연락 허가나 제휴 근거가 아니다.

### 성남시 1인가구 힐링스페이스

- 성남시 조직도 기준 `031-729-1756`은 센터 운영 총괄, `1757`은 상담, `1758`은 동아리, `1759`는 병원안심동행 담당이다. 따라서 외부 인터뷰 협조 가능성은 운영 총괄 번호에서 먼저 확인한다.
- 첫 통화에서는 이용자 전달·게시를 요청하지 않고 담당 부서, 공문 필요 여부, 공식 수신 이메일만 확인한다.
- 시 공식 사업·실증·추천으로 오인될 수 있는 표현과 성남시 명칭·로고의 자료 사용은 금지한다.

### 서울글로벌유학생지원센터

- 서울외국인포털의 2026년 게시물에서 센터 전화 `02-362-6754`와 프로그램 문의 이메일 `sgc.istudent@gmail.com`을 확인했다.
- 해당 Gmail이 외부 협업 제안의 공식 수신처인지는 확인되지 않았다. 전화로 담당자와 접수 절차를 먼저 확인한다.
- `익명 인터뷰`라는 표현은 메모·연락처·동의 철회·보관기간 설계가 없는 상태에서는 쓰지 않는다. 대신 `식별정보를 인터뷰 기록에 남기지 않는 방식`을 제안하고 센터 양식과 요구사항을 먼저 받는다.
- 비자 유형을 모집 조건이나 기록 항목으로 사용하지 않으며, 영문 모집문과 동의문이 완성되기 전에는 참여자 연결을 요청하지 않는다.

## 4. 메시지·첨부·개인정보 게이트

### 첫 접촉 공통 수정

- `성남에서 개발 중`은 사실 확인 후 사용한다. 불확실하면 지역 표현을 삭제한다.
- `확인 누락을 줄이는 서비스`는 효능이 입증된 것처럼 보일 수 있어 `확인 항목을 정리하는 초기 서비스`로 낮춘다.
- 인터뷰 인원과 시간은 상한으로 표현한다: `최대 5명, 1인당 약 20분`.
- 녹음은 기본적으로 하지 않는다. 필요해지면 별도 동의를 받는다.
- 실제 계약서, 주소, 연락처, 신분증, 주민·외국인등록번호, 비자정보, 상담기록, 회원·이용자 명단을 요청하거나 수신하지 않는다.

### 첨부자료 상태

저장소에서 아래 발송용 완성본을 확인하지 못했다. 따라서 첫 연락에서 “준비되어 있다” 또는 즉시 제공 가능하다고 단정하지 않는다.

- `입주해_서비스소개_1p.pdf`
- `입주해_합성리포트_1p.pdf`
- `입주해_인터뷰질문지_1p.pdf`
- `입주해_인터뷰동의문.pdf`
- 한국어·영어 모집문

요청을 받은 뒤 제작할 경우에도 현재 구현/계획 기능 구분, 합성 데이터 표시, 법률·감정평가·신용평가·공인중개행위 비대체 고지, 로고·기관명 미사용을 재검수한다.

## 6. 승인 선택지

보드는 아래처럼 후보별로 선택하면 된다.

- [ ] A — 민달팽이유니온 첨부 없는 첫 이메일 승인
- [ ] B — 한국사회주택협회 공식 문의 경로 재확인만 승인
- [ ] C — 성남시 운영 총괄 번호에 공식 수신 채널 확인 전화만 승인
- [ ] D — 서울글로벌유학생지원센터에 공식 접수 절차 확인 전화만 승인
- [ ] E — 전부 보류하고 공개용 자료·동의 체계를 먼저 완성

권고 조합은 **A + B + C + D**다. 단, A는 발신자 정보가 채워진 뒤 실행하고 B~D는 자료 전달·모집 승인이 아닌 채널 확인에만 한정한다.
