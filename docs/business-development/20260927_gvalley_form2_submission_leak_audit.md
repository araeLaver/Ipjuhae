### 분량 영향

같은 계량기(`scripts/stats/gvalley_page_budget.py`)로 제거 전·후를 돌렸다. 제거 전 값이 원고 기재치(5.14 / 4.69 / 5.44 / 5.89)와 소수점까지 일치하므로 대조군이 성립한다. 본문 글자 **4,778자 → 4,197자**(581자 감소, 마크업 포함 1,020자 삭제).

| 경로 | 1500자/쪽 (낙관) | 1300자/쪽 (중립) | 1100자/쪽 (보수) |
|---|---|---|---|
| 이미지, 보정 없음 | 5.14 → **4.75 미달** | 5.63 → 5.18 | 6.29 → 5.77 |
| 표 대체, 보정 없음 | 4.69 미달 → **4.30 미달** | 5.18 → **4.73 미달** | 5.84 → 5.32 |
| 표 대체 + 보정 원고 | 5.44 → **5.06** | 6.05 → 5.60 | 6.88 → 6.35 |
| 이미지 + 보정 원고 | 5.89 → **5.51** | 6.50 → 6.05 | 7.33 → 6.80 |

재현: `python3 scripts/stats/gvalley_internal_leak_audit.py` → `python3 scripts/stats/gvalley_sim_after_leak_removal.py` (뒤 스크립트가 대조군·처리군을 같은 계량기로 연속 실행한다).

**판정.** 기존에 보고된 "보정 원고 이식 시 양 경로 모두 충족"은 삭제해야 할 내부 서술 581자를 포함한 값이었다. 삭제 후 표 대체 경로의 낙관 가정 여유는 0.44쪽에서 **0.06쪽**으로 줄어 사실상 0이다.

**권고.** 도표를 이미지로 넣는 경로를 기본값으로 확정한다(5.51쪽). 표 대체는 이미지 삽입이 불가할 때의 예비 경로로만 남기고, 그 경우 추가 증량 없이는 최소 5쪽을 단정하지 않는다. 이 수치는 여전히 글자수 예산 추정치이며 실제 출력 쪽수 판정을 대체하지 않는다.

## 2. 이식 규칙과 충돌하는 특허 서술 (차단)

L4의 이식 규칙은 "**특허 관련 서술 일체** … 기재 금지"로 적는다. 그런데 같은 원고의 L6·L8이 특허 서술을 담고 있다.

- L6: "임시명세서 단계로 특허청구범위·심사청구·공개신청이 모두 없고 출원번호통지서 원본이 미확보이므로, 출원 사실 자체를 기재할 수 없다."
- L8: "증빙 판정 8번에 따라 특허·상표의 번호와 출원·등록 상태는 증빙 미확보로 전면 제외이며 … 상표는 선행조사 기록상 출원 전 단계다."

두 문장은 우리 권리 확보가 미완이라는 사실을 심사위원에게 **자발적으로** 알리는 자기진술이다. 서식4 서약 3항이 "대회 중 공개된 아이디어를 보호받으려면 공개 이전에 직접 지식재산권을 획득해야 함을 확인"으로 적으므로, 같은 제출물 안에서 권리 미확보를 명시하면 서약 3항의 위험을 스스로 부각한다.

**조치.** 두 문장을 삭제한다. 5장 등록 지식재산권 표는 기재 없이 비워 두고, 비워 둔 이유를 본문에 설명하지 않는다. 2.3 차별성은 설계 구조와 검증 계획만으로 서술한다(현재 본문이 이미 그렇게 되어 있어 삭제만으로 충분하다).

## 3. 수도권 월세 비중 시계열의 출처 위치 오류

8판 1.3: "같은 자료 **12쪽 각주 기준**으로 수도권 월세 비중은 5년 평균 48.9%, 2023년 54.0%, 2024년 56.9%, 2025년 61.8%다."

[출처 대장](/DOW/issues/DOW-1154#document-market-statistics) 4장에 따르면 12쪽 **각주는 전국 기준** 시계열('21 43.5 → '22 52.0 → '23 54.9 → '24 57.6 → '25 63.0)이고, 수도권 값 48.9/54.0/56.9/61.8은 12쪽 **표의 수도권 행**이다. 숫자는 맞고 인용 위치가 틀렸다. 공고 유의사항이 "객관적 자료에 근거, 출처 제시"를 요구하므로 심사에서 원문을 대조하면 각주에 그 숫자가 없다.

**조치.** "12쪽 각주 기준으로" → "12쪽 표의 수도권 행 기준으로"로 고친다. 원문 PDF 재확인은 사업개발의 대조 기록을 따랐고 이번 회차에 PDF를 다시 열지 않았다.

## 4. 7월 누계 값의 배치

같은 문단이 12월 누계 시계열을 서술한 직후 "「'26년 7월 주택통계」의 2026년 1~7월 누계는 수도권 66.9%(비아파트 77.3%)이나 연간 누계가 아니므로 각주 참고값으로만 쓴다"로 이어진다. 출처 대장 4-1의 함정 2가 금지한 배치(12월 누계와 7월 누계를 같은 시계열에 올리는 것)이며, 문장 자체가 집필 지시문 어투다.

**조치.** 편집본에서 이 문장을 본문에서 떼어 실제 각주로 내리고, "…로만 쓴다"를 서술형으로 바꾼다. 각주에는 집계 구간(1~7월 누계)을 명시한다.

## 5. 산출물 수치의 계량 정의 — 3건 재현, 커밋은 시각 종속

2.2 (5)의 네 수치는 "제출 당일 재측정"이 요구되는데 계량 정의가 어디에도 없었다. 정의를 특정해 대조한 결과:

| 원고 기재값 | 재현 정의 | 재측정 결과(2026-09-27) | 판정 |
|---|---|---|---|
| API 엔드포인트 137개 | `app/api` 아래 `route.ts` 파일 수 | 137 | **재현** (핸들러 수로 세면 181로 달라진다) |
| 웹 화면 79개 | `app` 아래 `page.tsx` 파일 수 | 80 | **재현** (09-27 `app/tester/page.tsx` 추가분) |
| 모바일 화면 17개 | `mobile/src/screens` 아래 tsx 파일 수 | 17 | **재현** (mobile 전체 tsx 는 23) |
| 커밋 505건 | 기간 내 커밋 수 | 09-26 12:00 KST 492 / 23:59 KST 516 | 시각 종속, 그날 낮 값으로 정합 |
| 테스트 861건 | vitest 실행 결과 | 미측정 | 제출 당일 실행 로그로 갱신 |

정의를 `scripts/stats/gvalley_output_metrics.py`에 명령 단위로 고정했다. 제출 당일 1회 실행해 기준일 표기와 함께 갱신한다.

측정 중 확인한 함정 하나를 같이 남긴다. **셸 훅이 `git`·`find`를 재작성해 수를 조용히 틀리게 만든다.** 같은 커밋 계수가 훅 경유 10건, `rtk proxy` 경유 501건으로 갈렸고 `find app/api -name route.ts`도 53건과 137건으로 갈렸다. 이 스크립트는 `rtk proxy`를 경유하고, 파일 계수는 `os.walk` 로 독립 재확인했다.
