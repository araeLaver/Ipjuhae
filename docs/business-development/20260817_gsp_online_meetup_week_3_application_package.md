# 경기스타트업플랫폼 온라인 밋업위크 3차 신청 패키지

- 작성일: 2026-08-17
- 신청 마감: 2026-08-18 17:00
- 신청 주체 후보: 김다운 / 입주해
- 상태: **조건부 No-Go — 기업 자격과 플랫폼 등록 상태 확인 필요**
- 공고: https://www.gsp.or.kr/notice/UVND0001.do?noticeSeq=55

## 1. 결론

현재 저장 자료만으로는 신청 자격을 확정할 수 없다. 기존 제출자료는 김다운을 `예비창업자`로 기록하고 기업명·법인번호·사업자등록번호를 공란으로 두고 있다. 반면 확인된 공고 요약의 신청 대상은 경기도 소재, 창업 7년 이내(신산업 10년 이내) 스타트업이다.

따라서 아래 세 가지가 모두 확인될 때만 **Go**로 전환한다.

1. 현재 유효한 사업자등록 또는 법인 설립 사실
2. 사업장 소재지가 경기도임을 보여주는 증빙
3. 경기스타트업플랫폼 기업회원·기업정보·IR 자료 등록 완료

하나라도 충족하지 못하면 이번 3차 신청은 **No-Go**다. 예비창업자 개인 자격을 창업기업으로 임의 해석해 제출하지 않는다.

- 설립일: **[확인 필요]**

### 한 줄 소개

입주해는 임대인·임차인·주택의 확인자료를 바탕으로 계약 전 신뢰 판단을 돕는 주거 신뢰 플랫폼입니다.

### 해결하려는 문제

임대차 시장에서는 상대방과 주택에 관한 정보가 분산되어 있어 계약 전 확인 비용이 높고, 중요한 확인 항목을 놓치기 쉽습니다. 입주해는 필요한 확인 항목을 한곳에서 관리하고, 이용자가 동의한 범위 안에서 판단에 필요한 정보만 전달해 정보 비대칭을 줄입니다.

### 솔루션

입주해는 임차인 프로필, 임대인·주택 확인 항목, 거래 관련 참고정보를 연결해 양측의 탐색과 확인 과정을 단순화합니다. 민감한 원문 자료는 투자자 공개자료에 포함하지 않으며, 서비스의 차별점은 `확인 항목`, `검증 상태`, `동의 기반 제한 열람` 수준으로 설명합니다.

### 현재 단계

- Next.js 기반 MVP 핵심 기능 구현
- 세입자 프로필, 매물, 매칭, 메시지, 신뢰정보 관리 기능 개발
- 특허 출원 진행 및 정규출원 보강 준비
- 초기 사용자·파트너 검증 준비 단계

### 밋업 목표

1. 주거 신뢰 플랫폼의 초기 시장 진입 전략 검증
2. 임대인·임차인 양면시장 확보 방식에 대한 투자자 피드백
3. 개인정보·민감정보를 다루는 SaaS의 신뢰·컴플라이언스 전략 검증
4. MVP 이후 실증, 파트너십, 후속 투자 준비에 대한 조언 확보

### 투자자에게 묻고 싶은 질문

- 초기에는 임차인, 임대인, 중개·관리 파트너 중 어느 쪽을 우선 고객으로 잡는 것이 타당한가?
- 실증 전 단계에서 투자 판단에 필요한 최소 traction은 무엇인가?
- PropTech와 TrustTech 중 어떤 포지셔닝이 투자자 이해와 후속 확장에 유리한가?
- 개인정보 보호를 경쟁력으로 설명할 때 반드시 제시해야 할 운영 지표는 무엇인가?

## 6. 외부 공개 통제

투자자 배포본에서는 다음 내용을 제거한다.

- 미출원 또는 정규출원 보강 대상 기술의 상세 처리 순서
- 내부 상태명, 규칙명, 임계값, 가중치, 점수 산식
- `N1~N5`, `T0~T4`, `S0~S8`, `L0~L2`, `R1~R7` 등 내부 코드
- 원본 개인정보·신용정보·계약문서와 식별 가능한 화면
- 검증되지 않은 매출, 사용자 수, 제휴, 시장점유율 주장
- 출처와 기준일을 재검증하지 않은 시장 수치

공개 표현은 다음 범위로 제한한다.

- `계약 전 확인 항목을 구조화한다`
- `확인 상태와 기준일을 관리한다`
- `이용자 동의 범위 안에서 필요한 정보만 제한적으로 공유한다`
- `임대인·임차인의 탐색 및 확인 비용을 줄인다`
