## 1. 결론

**판정: 조건부 Go**

입주해는 주거 임대차의 정보 비대칭을 줄이는 AI·데이터 기반 서비스로서 `일반/기술트랙`의 기술창업 범위에 적합하다. 저장소에는 1차 모두의 창업 참여 및 1R 지원 이력이 있으나, 재도전 가점 적용 여부는 공식 공고·플랫폼에서 별도 확인이 필요하다. 다만 아래 두 조건을 보드가 확인하기 전에는 제출하면 안 된다.

1. 1차 모두의 창업에서 **2R 통과 후 현재 사업 수행 중이 아님**
2. 1차 지원사항을 제공받은 뒤 **정당한 사유 없이 중도 포기한 이력이 없음**

둘 중 하나라도 해당하면 공고상 신청 제외이므로 **No-Go**다. 둘 다 `아니오`이고 나머지 결격사유도 없으면 **Go**로 전환한다.

## 4. 1페이지 사업 요약 초안

### 서비스명

입주해(Rentme) — 근거 기반 주거 신뢰와 설명 가능한 임대 매칭 서비스

### 문제

전월세 거래에서는 임차인, 임대인, 주택에 관한 확인 정보가 여러 문서와 기관에 흩어져 있다. 임차인은 매물의 위험과 계약 전 확인사항을 스스로 조합해야 하고, 임대인·운영자는 후보자의 조건을 반복적으로 확인한다. 기존 매물 탐색은 가격과 위치 검색에 집중해 `무엇이 확인됐고 무엇이 아직 확인되지 않았는지`를 한 흐름에서 보여주지 못한다. 이 때문에 확인 누락, 반복 문의, 의사결정 지연과 불신이 발생한다.

### 해결책

입주해는 임차인·임대인·주택의 확인 상태를 분리하고, 사용자 동의 아래 제출된 근거의 출처·기준일·상태를 구조화한다. 예산, 입주 시기, 생활 조건과 매물 조건을 비교해 적합 사유와 불충족 조건을 함께 설명하며, 계약 전에는 확인이 필요한 다음 행동을 체크리스트로 안내한다. 단일 점수로 안전이나 신용을 보장하지 않고 `확인됨`, `자료 없음`, `추가 검토 필요`를 근거와 함께 표시한다.

### 차별성

1. 매물 중심 검색을 넘어 임차인 조건을 먼저 구조화하는 역방향 매칭
2. 결과값뿐 아니라 조건별 적합·불충족 사유를 제시하는 설명 가능한 매칭
3. 임차인·임대인·주택의 근거를 거래 단계에 맞춰 최소 공개하는 동의 기반 신뢰 흐름
4. 계약 전 위험을 단정하지 않고 누락된 확인사항과 다음 행동을 안내하는 의사결정 보조
5. 임시명세서 방식 특허 출원 이력 및 구현된 MVP를 바탕으로 아이디어 단계에서 빠르게 실증 가능한 실행력

### 고객과 시장

초기 고객은 최근 전월세 매물을 탐색하거나 계약을 준비하는 청년·1인 가구 임차인과, 반복적인 후보 검토 부담을 가진 개인 임대인·소규모 임대운영자다. 이후 공인중개사, 코리빙·임대주택 운영사, 전월세 금융·보험 상담 채널로 확장한다. 초기에는 서울·성남 생활권의 문제 인터뷰와 예시 데이터 기반 내부 데모로 검증하고, 개인정보 원문이나 자동 의사결정을 요구하지 않는 보조 도구로 진입한다.

### 현재 준비도

- tenant profile, 매물, 설명 가능한 matching, 확인·동의, 계약 전 trust workflow를 포함한 web/mobile MVP 구현
- TypeScript 정합성, Vitest, Next.js production build 검증 이력 보유
- 주거 신뢰 데이터 처리 구조 관련 임시명세서 방식 특허 출원 이력 보유
- 고객군별 문제 인터뷰 및 임대차 리스크 리포트 검증 패키지 준비

### 12주 실행계획

| 기간 | 실행 | 성공 기준 |
|---|---|---|
| 1~4주 | 임차인·임대인·중개/운영자 20명 문제 인터뷰, 핵심 확인항목 재정의 | 반복 문제 3개, 역할별 우선순위 확정 |
| 5~8주 | 합성 데이터 기반 매칭·계약 전 확인 prototype 실험 | 과업 완료율 70% 이상, 핵심 흐름 이탈 원인 확보 |
| 9~12주 | opt-in 사용자 10~20명 제한 pilot, B2B 파트너 3곳 discovery | 확인 누락 감소 또는 검토시간 단축의 정량 신호 1개 이상 |

### 지원금 활용 원칙

1R 창업활동자금과 AI 솔루션은 고객검증, 합성 테스트셋, 사용성 실험, 보안·법률 점검에 우선 사용한다. 개인정보 대량수집, 무허가 중개, 신용평가 또는 `전세사기 없음` 같은 보장 표현에는 사용하지 않는다. 2R 이후에는 검증 결과가 확인된 흐름만 MVP로 고도화한다.

## 5. 온라인 도전신청서 입력 초안

공고상 별도 첨부서류 없이 홈페이지의 `도전하기`에서 직접 입력한다. 실제 필드명·글자 수는 로그인 후 확인해야 하므로 아래 문구는 붙여넣기용 원문이며, 제출 전 폼 제한에 맞춰 축약한다.

### 아이디어 한 줄 소개

임차인·임대인·주택의 확인 근거와 조건을 구조화해 적합 사유와 계약 전 다음 행동을 설명하는 AI 기반 주거 신뢰·임대 매칭 서비스

### 해결하려는 문제

전월세 계약 당사자는 매물, 권리, 상대방, 계약 조건 정보를 서로 다른 문서와 채널에서 반복 확인합니다. 기존 서비스는 매물 노출과 검색에 집중해 확인된 정보와 미확인 정보를 구분하거나, 사용자가 다음에 무엇을 점검해야 하는지 충분히 안내하지 못합니다. 그 결과 정보 비대칭, 확인 누락, 반복 문의와 계약 의사결정 지연이 발생합니다.

### 해결 방법

입주해는 임차인의 예산·지역·입주시기·생활조건을 구조화하고 매물 조건과 비교해 적합 사유와 불충족 조건을 함께 보여줍니다. 임차인·임대인·주택별 확인자료는 동의, 출처, 기준일, 공개단계를 기록하며 계약 전 필요한 다음 행동을 체크리스트로 안내합니다. 서비스는 안전·신용·계약 성사를 보장하지 않고 사용자의 판단을 돕는 보조 도구로 운영합니다.

### 차별성과 기대효과

매물 중심 탐색을 임차인 조건 중심의 역방향 매칭으로 확장하고, 단일 점수 대신 판단 근거와 누락 정보를 함께 제시합니다. 이를 통해 임차인의 확인 누락과 불안을 줄이고, 임대인·운영자의 반복 검토시간을 단축할 수 있습니다. 초기 pilot에서 과업 완료율, 확인항목 완료율, 후보 검토시간, 상담 전환율을 측정해 효과를 검증하겠습니다.

### 실행 가능성

핵심 web/mobile MVP와 설명 가능한 matching, 동의·신뢰 workflow를 구현했고 자동 테스트와 production build 검증 이력이 있습니다. 주거 신뢰 데이터 처리 구조의 임시명세서 방식 특허 출원 이력도 보유하고 있습니다. 12주 동안 20명 문제 인터뷰, 예시 데이터 기반 내부 demo, 10~20명 제한 pilot 순으로 검증해 개인정보와 규제 위험을 통제하면서 사업성을 확인하겠습니다.

### 선택 첨부물 제안

- 이미지 1~3장: 문제 흐름, 설명 가능한 매칭 화면, 계약 전 확인 체크리스트
- 숏폼 30~60초: `조건 입력 → 적합 사유 확인 → 미확인 항목/다음 행동 확인`
- 금지: 실제 주소·계약서·주민번호·소득자료 등 개인정보, 안전·수익·계약 성사 보장 표현

- 채무불이행·환수금·제재·보조금 배제 관련 해당 없음 또는 예외 증빙
- 공동·각자대표가 있으면 대표자 전원 자료
- 1차 모두의 창업 최종 라운드/종료 상태를 보여주는 결과 화면 또는 운영기관 회신
- 2026년 중기부 창업사업화 지원사업 선정·협약 목록

## 7. 보드 확인값

아래 항목은 최종 Go 전 보드가 별도 안전 채널에서 확인한다. 자격 확인값, 증빙 원문, 개인 이메일·전화번호·계정정보 등 민감정보는 Git 문서나 Paperclip 댓글에 기록하지 않고, 본 문서에는 `확인 완료/해당 없음/운영기관 확인 필요` 수준의 비식별 결과만 남긴다.

```text
1. 2026-08-20 기준 대표자 명의 사업자등록: 없음 / 있음
2. 있음인 경우 사업자명, 개인·법인, 개업·설립일, KSIC 5자리:
3. 공동·각자대표: 없음 / 있음(전원 성명 및 자격 확인 필요)
4. 대표자 주소 또는 신청 사업자 본점: 수도권 / 비수도권
5. 1차 모두의 창업 최종 결과: 1R 탈락 / 2R 진출 후 탈락 / 2R 통과 후 수행 중 / 중도포기 / 기타
6. 1차 지원 후 정당한 사유 없는 중도포기: 없음 / 있음 / 운영기관 확인 필요

9. 채무불이행, 세금체납, 환수금, 참여제한, 체불명단, 보조금 배제: 모두 없음 / 해당 항목 기재
```

## 8. 제출 전 실행 순서

1. 보드가 1차 최종 상태와 13개 결격사유를 확인한다.
2. 하나라도 제외사유에 해당하면 제출하지 않고 No-Go로 기록한다.
3. 모두 해당 없음이면 동일한 1차 가입 수단으로 로그인하되, 재도전 가점 적용 여부는 공식 공고·플랫폼에서 별도 확인한다.
4. 멘토기관별 공개 평가지표와 `Pool`을 비교해 일반/기술트랙 기관을 선택한다.
5. 폼 필드와 글자 수에 맞춰 본 문서의 입력 초안을 축약하고 선택 이미지의 개인정보를 점검한다.
6. 마감 2~3일 전인 **2026-09-14~15**에 보드 승인 후 제출한다.
7. 알림톡 수령과 홈페이지 접수 상태를 모두 확인해 접수 완료를 기록한다.
