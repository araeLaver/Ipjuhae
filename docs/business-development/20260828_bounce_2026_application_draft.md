## 2. 파트너 우선순위

파트너별 세부 수요과제는 공고문에 공개되지 않았다. 아래 순위와 제안은 각 사의 일반 사업영역과 입주해 제품 범위를 연결한 **밋업 가설**이며, 폼 또는 주최기관을 통해 수요과제가 확인되면 문구를 조정한다.

| 순위 | 파트너 | 적합성 | 제안 주제 | 초기 PoC 지표 |
|---|---|---|---|---|
| 1 | 현대건설 | 아파트·주거 고객 접점과 입주해의 임차인·임대인·주택 3축 확인 흐름이 직접 연결됨 | 임대주택/주거서비스 대상 계약 전 확인 및 적합 후보 검토 PoC | 후보 검토시간, 확인항목 완료율, 밋업/상담 전환율 |
| 2 | 하나은행 | 전월세 금융 고객의 계약 전 확인·서류 준비 여정과 연결 가능 | 전월세 금융 상담 전 고객 준비도 체크 및 동의 기반 연결 PoC | 상담 준비 누락률, 상담 소요시간, 동의 전환율 |
| 3 | DB손해보험 | 임대차 분쟁·사고 예방 및 주거 위험관리와 연결 가능 | 임대차 계약 전 확인 체크리스트와 위험예방 안내 PoC | 체크리스트 완료율, 추가 확인 권고율, 예방 콘텐츠 반응률 |

차순위는 SK에코플랜트(주거·건설 현장 연계), 한화호텔앤리조트(장기체류·임직원 주거), 네이버클라우드(기술 인프라)다. 현재는 고객 문제와 유통 접점이 더 직접적인 상위 3곳을 우선한다.

## 3. 공통 회사 소개 초안

입주해는 임차인·임대인·주택의 확인 상태를 분리해 보여주고, 계약 전에 필요한 다음 행동을 정리하는 주거 신뢰 플랫폼입니다. 임차인 프로필, 임대인·매물 관리, 동의 기반 확인자료, 계약 전 체크리스트를 하나의 흐름으로 연결합니다. 점수만으로 계약 가능성을 단정하지 않고 확인된 자료·미확인 사유·기준일을 함께 제시해 사용자의 판단을 돕습니다. 현재 MVP는 typecheck, Vitest 전체 테스트, Next.js production build 검증을 통과했으며 공개 화면의 상세주소 노출 축소와 탈퇴 사용자 데이터 보호도 반영했습니다. BOUNCE 2026에서는 파트너의 실제 고객 여정에 맞춘 소규모 PoC 범위와 성공 지표를 합의하고자 합니다.

## 4. 파트너별 협업 제안 초안

### 1순위 — 현대건설

입주해는 임차인·임대인·주택의 확인 상태와 계약 전 다음 행동을 한 화면에서 정리합니다. 현대건설의 임대주택 또는 주거서비스 고객 여정에서, 임대 문의 이후 반복되는 후보 검토와 확인 항목 정리를 줄이는 PoC를 제안합니다. 실제 고객정보를 바로 연동하지 않고 합성 데이터 데모와 참여자 opt-in 방식으로 시작하겠습니다. 4주 내 제한된 사용자군을 대상으로 후보 검토시간, 확인항목 완료율, 상담 전환율을 공동 측정할 수 있습니다. 밋업에서는 적용 가능한 고객 접점, 데이터 최소화 기준, 현업 담당자의 성공 조건을 먼저 확인하고 싶습니다.

### 2순위 — 하나은행

입주해는 전월세 계약 전에 임차인·임대인·주택별 확인 상태와 준비할 행동을 구조화합니다. 하나은행의 전월세 금융 상담 고객이 상담 전에 확인·준비할 항목을 이해하고, 동의한 경우에만 상담 접점으로 연결되는 PoC를 제안합니다. 금융 심사나 신용 판단을 대체하지 않고 고객 준비도와 정보 누락을 줄이는 보조 흐름으로 범위를 제한하겠습니다. 4주 내 합성 데이터 기반 데모 후 상담 준비 누락률, 상담 소요시간, opt-in 전환율을 검증할 수 있습니다. 밋업에서는 금융소비자보호·개인정보 기준을 충족하는 최소 기능과 적합한 파일럿 채널을 논의하고 싶습니다.

### 3순위 — DB손해보험

입주해는 임대차 계약 전 확인해야 할 사람·주택·자료를 나누고 미확인 사유와 다음 행동을 안내합니다. DB손해보험과는 임대차 분쟁 및 주거 위험을 줄이기 위한 계약 전 체크리스트와 예방 안내 PoC를 제안합니다. 보험 가입 심사나 위험 점수 산정이 아니라 사용자가 빠뜨린 확인 항목을 발견하고 적절한 상담으로 연결하는 범위에서 시작하겠습니다. 4주 내 합성 데이터 데모와 제한된 opt-in 사용자 테스트로 체크리스트 완료율, 추가 확인 권고율, 예방 콘텐츠 반응률을 측정할 수 있습니다. 밋업에서는 실제 사고·분쟁 예방에 의미 있는 확인 항목과 규제상 허용되는 연결 방식을 확인하고 싶습니다.
