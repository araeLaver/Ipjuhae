# 2026-08-29 마감 임박 2건 신청 준비 패키지

검토 기준일: 2026-08-29  
실행 상태: 외부 신청·제출 없음

## 결론

두 건 모두 프로그램 내용은 입주해의 현재 고객검증 단계와 잘 맞지만, 대표자·사업자 상태와 경기도 자격 근거, GSP 회원 상태, 참석 가능 일정이 저장소에서 확인되지 않았다. 따라서 현재 판정은 **보드 확인 전 보류, 확인값 충족 시 조건부 Go**다.

- `사업계획서 작성 특강`: 공식 상세페이지와 Google Form의 마감 시각이 각각 12:00와 15:00로 다르므로 **2026-08-31 12:00을 안전 마감**으로 적용한다.
- `스담스담`: GSP 상세페이지는 지원자격을 `개인 예비창업자`로 좁게 표시하지만 포스터는 `예비창업자 및 창업기업 누구나 환영`으로 안내한다. 사업자·법인이라면 제출 전 담당자에게 자격을 확인하고, **2026-09-02 18:00까지** 신청 여부를 확정한다.

## 1. 사업계획서 작성 특강

### 확인된 일정·자격·비용

- 공식명: `모두의 창업 멘토가 알려주는 사업계획서 작성 방법 특강`
- GSP 모집기간: 2026-08-20 00:00~2026-08-31 12:00
- Google Form 신청기간: 2026-08-20~2026-08-31 15:00, 신청 현황에 따라 조기 마감 가능
- 운영: 2026-09-01 14:00~16:30
- 방식: 경기스타트업브릿지 12층 컨퍼런스홀 또는 실시간 온라인 YouTube Live
- 참가 대상: 예비창업자, 창업기업 대표·임직원, 대학(원)생 등
- GSP 표시 자격: 개인 예비창업자 및 업력 7년 미만 스타트업 회원
- 비용: 무료

### 신청 폼 문항

1. 성함
2. 성별
3. 휴대전화
4. 참가 방식: 오프라인 / 온라인
5. 참가자 유형
6. `모두의 창업` 2차 모집 참여 의사
7. 창업기업 대표·재직자·유관기관이면 기업명과 직위
8. 대학(원)생이면 대학명
9. 필수 개인정보 수집·이용 및 제3자 제공 동의
10. 선택 지원사업 안내 수신 동의

### 개인정보 범위

- 수집: 성명, 휴대전화, 이메일, 신청유형, 성별, 소속, 직위 등
- 목적: 접수·선발, 운영·안내, 출석·수료, 만족도, 사후관리·성과조사, 통계
- 보유: 사업 종료일부터 5년
- 제3자: 경기도청, 운영기관 내비온파트너스, 만족도·성과조사 전문기관
- 제공 항목: 위 항목과 사업장 소재지 등, 사업 종료 후 5년까지 보유
- 선택 홍보 동의: 성명·휴대전화·이메일을 2년 또는 철회 시까지 이용하며 거부해도 교육 참여 불이익 없음

### 입력 권고안

- 참가 방식: 대표 일정에 따라 `온라인 참석` 우선 권고. 이동 부담 없이 2시간 30분 전체 참석이 가능할 때 선택한다.
- `모두의 창업` 참여 의사: 실제 지원 계획이 확정되지 않았으므로 `검토 중`.
- 선택 안내 동의: 본 교육 참여와 무관하므로 기본값은 `동의하지 않음`.

## 2. 고객·시장검증 및 성장전략 스담스담

### 확인된 일정·자격·비용

- 공식명: `경기창업혁신공간(남동부) 오픈네트워킹 고객,시장검증 및 성장전략 스담스담`
- GSP 모집기간: 2026-08-25 00:00~2026-09-03 00:00. 실무상 **9월 2일 중 제출**이 안전하다.
- 행사: 2026-09-03 10:00
- 장소: 경기 성남시 분당구 판교로289번길 경기스타트업캠퍼스 3동 1층 경기창업혁신공간 대교육장
- 연사: 빅뱅엔젤스 권혁찬 부대표
- 대상: GSP 표시는 `개인 예비창업자`, 포스터는 `예비창업자 및 창업기업 누구나 환영`
- 비용: 공식 페이지·포스터·신청 폼에 참가비 표기가 없고 결제 문항도 없다. **무료라고 명시되지는 않았으므로 필요 시 담당자 확인**.
- 참고: 신청 폼에는 `2026. 9.3(수)`라고 적혀 있으나 2026-09-03은 목요일이며 포스터도 목요일로 표시한다.

### 신청 폼 문항

1. 참석자 성함
2. 회사 이름(소속) — 선택 문항
3. 인지 경로 — 웹사이트 / 친구·직장동료 / 뉴스레터 / 광고
4. 고객·시장검증 및 성장전략 질문 — 선택 문항

폼에는 별도 개인정보 동의문, 연락처·이메일 입력, 100자 소개 입력 문항이 노출되지 않는다. Google 계정 로그인·자동 수집 여부는 최종 제출 화면에서 다시 확인한다.

### 입력 초안

- 회사 이름(소속): `입주해`
- 인지 경로: `웹사이트`
- 100자 소개(별도 소개 요청 시): `입주해는 세입자 프로필과 주거 선호를 바탕으로 임대인·중개사와의 매칭 효율을 높이는 주거 매칭 서비스입니다.`
- 위 소개는 공백·문장부호 포함 60자로, 100자 제한에 여유가 있다. 다만 현재 Form에는 소개 문항이 없으므로 요청될 때만 사용한다.
- 고객검증 질문: `초기 양면시장 서비스에서 세입자·임대인·중개사 중 어느 고객군을 먼저 검증해야 투자자가 신뢰할 수 있는 수요 증거를 가장 빠르게 만들 수 있을까요?`

## Go/No-Go와 보드 승인 요청안

### 사업계획서 작성 특강

- **Go**: 경기도 참가자 유형 중 하나를 사실대로 선택할 수 있고, 예비창업자이거나 업력 7년 미만 스타트업이며, 9월 1일 14:00~16:30 참석 가능하고 필수 개인정보 제공에 동의할 때
- **No-Go**: 참가자 유형을 증빙할 수 없거나, 업력 요건 불충족, 일정 불가, 필수 개인정보 제공 미동의 중 하나일 때

### 스담스담

- **Go**: 예비창업자이면서 9월 3일 10:00 성남 현장 참석 가능할 때
- **조건부 Go**: 개인사업자·법인·창업기업 재직자는 담당자(031-830-8641, sdg91@gbsa.or.kr)가 신청 가능하다고 확인한 때
- **No-Go**: 자격 확인 불가 또는 현장 일정 불가일 때

### 보드 회신 요청

아래 값만 회신하면 즉시 최종 판정할 수 있다.

1. 현재 지위: 예비창업자 / 개인사업자 / 법인 / 창업기업 재직자
2. 개업·설립일: `YYYY-MM-DD` 또는 해당 없음
3. 경기도 근거: 거주 / 사업장 / 재학 / 재직 / 없음
4. GSP 회원: 개인 예비창업자 / 스타트업 / 미가입
5. 특강 9월 1일 14:00~16:30: 온라인 가능 / 오프라인 가능 / 불가
6. 스담스담 9월 3일 10:00 성남 현장: 가능 / 불가
7. 필수 개인정보 제공: 승인 / 미승인
8. 외부 제출: 승인 / 미승인

외부 제출 승인이 있더라도 실제 성명·연락처·이메일은 대표자가 제출 화면에서 직접 입력하고, 제출 전 화면을 한 번 더 검토한다.
