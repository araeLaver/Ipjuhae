# 영업비밀·기술 보호 컨설팅 적합성 및 신청 준비안

- 작성일: 2026-08-28 (KST)
- 판정: **조건부 Go**
- 추천 유형: **심화컨설팅 1순위**, 선정 또는 일정 제약 시 기초컨설팅 선행
- 외부 신청: 보드 승인 전 미실행

## 1. 의사결정 요약

입주해는 중소기업 자격이 확인되면 지원대상에 해당할 가능성이 높고, 컨설팅 필요성과 활용 실익도 충분하다. 저장소에는 비공개 소스코드, matching·trust score 로직, 데이터 schema와 운영 문서, 제휴·지원사업 자료, 특허 출원 관련 문서가 함께 존재한다. 반면 기술적 접근통제와 개인정보 처리 통제는 일부 구현되어 있으나, 어떤 정보를 영업비밀로 지정할지, 등급별 접근권한·표시·반출·퇴직자 회수·외부자 서약을 어떻게 운영할지에 대한 전사 관리체계는 저장소 근거만으로 확인되지 않는다.

따라서 간이진단과 교육 중심인 기초컨설팅보다, 보호대상 특정·비밀등급 분류·규정과 서약서 검토·비밀자료 분리보관·특허와 영업비밀의 조합 전략을 다루는 **심화컨설팅이 현재 단계에 더 적합**하다. 중소기업은 공식 안내상 3일 방문, 정부지원 90%, 기업부담 10% 현물 방식이다. 현금 부담보다 대표·개발·운영 담당자의 인터뷰와 자료 준비 시간이 주요 내부 비용이다.

다만 사업자등록증명, 중소기업확인서, 신청 담당자, 현장 방문 가능 장소와 기업부담 이행 권한은 보드 확인이 필요하다. 이 네 가지가 확인되면 신청 Go로 전환하고, 온라인 제출 직전 보드 승인을 다시 받는다.

## 2. 공식 조건과 입주해 판정

| 항목 | 2026년 공식 조건 | 입주해 상태 | 판정 |
|---|---|---|---|
| 신청기간 | 연중 상시, 예산 소진 전까지 | 2026-08-28 기준 접수 안내 활성 | 가능하나 조기 신청 권고 |
| 지원대상 | 중소·중견기업, 대학·공공연구기관 | 법적 기업형태·중소기업 증빙 미확인 | 조건부 적격 |
| 심화 범위 | 상세 진단, 등급분류, 규정·서약·분리보관, IP-MIX | 현재 관리 공백과 직접 일치 | 적합도 높음 |
| 지원형태 | 중소기업 등 3일, 정부 90%, 기업 10% 현물 | 담당자 참여시간 확보 미확인 | 보드 확인 필요 |
| 진행방식 | 전문가 방문, 현장실사·인터뷰 | 방문 장소·참석자 미확인 | 보드 확인 필요 |
| 신청방법 | 영업비밀보호센터 회원가입 후 온라인 신청 | 외부 계정·제출 미실행 | 승인 후 가능 |

기초컨설팅은 창업기업·중소기업을 대상으로 사전 설문, 관리수준 5등급 진단, 취약점 제시, 실무 교육을 제공한다. 별도의 상세 관리체계 설계보다 현재 수준을 빠르게 확인하는 데 적합하다. 심화 신청이 선정되지 않거나 내부 자료 정리가 부족하다는 운영기관 의견을 받는 경우에만 기초를 먼저 수행한다.

## 3. 보호대상 정보자산 초안

### A등급 — 핵심 영업비밀 후보

- matching, trust score, verification, consent, fraud·risk 관련 비공개 로직과 가중치
- 미공개 제품 roadmap, 기술구성·데이터 처리절차, 특허 명세서 초안과 변리사 회신
- 운영 DB schema, migration, production architecture, 장애복구·운영 절차
- production secret, API credential, signing key, provider credential과 배포 설정값
- 비공개 제휴 조건, 가격·수익모델, 협상안, 투자·지원사업 제출 전 자료

### B등급 — 제한공유 정보

- 사용자·임대인·매물·계약·검증·접근감사 데이터와 비식별 분석 결과
- 내부 QA 결과, 보안 취약점, incident·운영 log, 출시 전 성능 수치
- 고객·파트너 인터뷰 원문, 담당자 연락처, outreach 이력과 미공개 시장조사

### C등급 — 내부 일반

- 공개 전 마케팅 문안, 내부 회의자료, 업무 절차와 template
- 공개된 공고를 바탕으로 작성한 신청 초안 중 개인정보·비공개 수치가 없는 부분

최종 등급은 컨설턴트와 확정하되, 개인정보와 영업비밀을 같은 개념으로 취급하지 않는다. 개인정보는 법적 처리 근거·목적·보유기간·정보주체 권리 중심으로, 영업비밀은 비공지성·경제적 가치·합리적 비밀관리 조치 중심으로 별도 관리한다.

## 4. 현재 통제수단과 공백

### 확인된 기술·운영 통제

- `.gitignore`가 `.env*.local`, `.vercel`, private key(`*.pem`) 등 로컬 secret·배포 정보를 제외한다.
- `lib/auth.ts`, `lib/jwt.ts`, `middleware.ts`에 JWT 검증, `httpOnly` cookie, production `secure` 설정과 인증 경계가 있다.
- `lib/access-audit.ts`가 접근 주체, 목적, 조회 필드, 대상, request·trace 식별자를 기록한다.
- `lib/consent.ts`, `lib/compliance-gates.ts`에 동의와 공개 전 gate가 있고, 계정삭제·개인정보처리방침 관련 기능과 문서가 존재한다.
- 특허 출원 및 기술구성 증빙이 있어 특허 공개 대상과 영업비밀 유지 대상을 함께 검토할 기반이 있다.

### 심화컨설팅에서 해결할 공백

- 전사 영업비밀 관리규정, 책임자와 자산 owner 지정 근거가 확인되지 않는다.
- 파일·문서별 비밀표시와 A/B/C 등급, 등급별 저장·공유·보유기간 규칙이 확인되지 않는다.
- 임직원·외주·자문·제휴 상대의 NDA, 보안서약, need-to-know 접근 부여·회수 절차가 확인되지 않는다.
- 외부 반출 승인, 개인기기·cloud drive 사용, 출력·촬영, 퇴직·계약종료 시 회수·삭제 절차가 확인되지 않는다.
- Git·Paperclip·Docs·배포·DB 등 시스템별 권한 inventory와 정기 검토 기록이 확인되지 않는다.
- 특허 출원으로 공개할 내용과 계속 비밀로 유지할 know-how의 경계표가 없다.

## 5. 내부 선행조치

신청 전에 완성된 규정을 만들 필요는 없지만, 전문가가 실제 공백을 진단할 수 있도록 아래 최소 자료를 준비한다.

1. 대표를 임시 영업비밀 보호책임자로 지정하고 개발·운영·사업 자료 owner를 정한다.
2. 위 자산 목록을 1차 inventory로 옮기고 저장 위치는 system 단위로만 기록한다. credential 값이나 개인정보 원문은 제출하지 않는다.
3. Git hosting, Vercel, DB, Paperclip, cloud drive, 이메일의 현재 사용자·권한·2FA·회수 가능 여부를 표로 만든다.
4. 임직원·외주·자문 계약서의 비밀유지 조항 유무만 점검하고 원문은 승인된 보관소에서 관리한다.
5. 특허 출원 문서와 제품 핵심 로직을 대조해 `특허 공개`, `영업비밀 유지`, `추가 판단` 세 범주로 임시 분류한다.
6. 방문 인터뷰 참석자로 대표, 개발 책임자, 운영·사업 담당자를 지정하고 3일 일정 수용 가능성을 확인한다.

## 6. 신청 입력 초안

### 신청 목적

입주해는 임차인·임대인·주택 관련 확인정보와 조건을 구조화하여 후보 검토를 지원하는 서비스입니다. 제품 개발 과정에서 소스코드, matching·trust 로직, 데이터 처리절차, 운영정보, 특허 관련 know-how와 제휴 조건이 축적되었으나 보호대상 특정, 비밀등급 분류, 접근권한·반출·외부자 관리, 특허와 영업비밀의 활용 경계를 포괄하는 사내 관리체계는 아직 정립 단계입니다. 심화컨설팅을 통해 실제 정보자산 inventory와 업무흐름을 기준으로 실행 가능한 관리규정과 통제 우선순위를 수립하고자 합니다.

### 희망 컨설팅 범위

- 핵심 소스코드·알고리즘·운영자료·제휴자료의 영업비밀 해당 가능성과 보호대상 특정
- 비밀등급, 표시, 저장, 공유, 반출, 파기 기준 설계
- 임직원·외주·자문·제휴 상대 NDA와 보안서약서 검토
- Git·cloud·DB·배포 환경의 역할별 접근권한과 정기 회수 절차 점검
- 출원 특허와 비공개 know-how 간 IP-MIX 전략 수립
- 30·60·90일 개선 roadmap과 최소 증적 template 제시

### 기대 산출물

- 영업비밀 자산 inventory와 등급분류표
- 관리규정, NDA·보안서약, 반출·권한부여·회수 template의 개선안
- 기술·인적·제도적 통제 gap report
- 특허 공개/영업비밀 유지 경계표
- 우선순위·담당자·기한이 있는 90일 실행계획

## 7. 제출 준비자료와 보드 확인값

### 준비자료

- 최근 사업자등록증명 또는 사업자등록증 사본
- 중소기업확인서 또는 중소기업기본법상 해당 여부를 확인할 자료
- 회사·서비스 소개 1페이지와 조직·담당자 현황
- 보호대상 정보자산 inventory 초안, 시스템별 접근권한 현황
- 현재 사용하는 NDA·근로·용역계약의 비밀유지 조항과 관련 사내 규정
- 특허 출원·보유 현황 목록(명세서 원문은 필요 범위 확인 후 제공)
- 개인정보·credential을 제거한 시스템 구성도와 자료 흐름도

### 보드가 회신할 최소 확인값

- 법적 상호와 기업형태
- 중소기업확인서: 유효 / 발급 필요 / 해당 여부 확인 필요
- 신청 담당자: 성명·직책·연락처(공식 신청 폼에서만 입력)
- 전문가 방문 가능 사업장과 대표·개발·운영 참석 가능 여부
- 기업부담 10% 현물과 3일 참여시간 수용: 가능 / 불가
- 외부 회원가입·신청 및 자료 제공: 승인 / 미승인

사업자번호, 개인 연락처, 상세 주소, credential, 고객 데이터, 계약서 원문은 Git 또는 Paperclip 댓글에 기록하지 않는다.

## 8. Go/No-Go 기준과 다음 행동

**조건부 Go**로 판정한다. 아래 네 게이트가 모두 충족되면 최종 Go다.

- 유효한 중소기업 자격 증빙 확보
- 방문 가능한 사업장과 핵심 담당자 3일 참여 확보
- 전문가에게 제공할 자료 범위와 비식별·비밀표시 원칙 확정
- 보드의 외부 계정 생성·온라인 신청·현물부담 명시 승인

게이트 충족 후 영업비밀보호센터에서 심화컨설팅을 신청한다. 제출 전에는 공식 화면의 비용·참여조건과 예산 잔여 여부를 재확인한다. 심화 부적합 안내를 받으면 기초컨설팅으로 전환하고, 진단 결과를 심화 재신청의 baseline으로 사용한다.
