# 서울창업허브M+ 글로벌 오픈 이노베이션 적합성 검토

작성일: 2026-08-24  
공식 접수기간: 2026-08-13 ~ 2026-09-11  
상태: 보드 확인 전 조건부 Go — 외부 제출 미실행

## 1. 결론

현재 판정은 **조건부 Go**다.

입주해는 tenant profile, 임대인·주택 확인상태, 역방향 matching을 구현한 PropTech software로서 MVP/상용화 단계 요건과 디지털 전환 협업 주제에는 연결할 수 있다. 특히 베트남의 임대주거 운영사·부동산 플랫폼을 대상으로 `민감 원본을 상대방에게 공개하지 않는 임차인 적합성 확인 및 매물 matching` PoC를 제안할 수 있다.

다만 저장소와 기존 기록만으로는 서울 소재, 업력, 영어 핵심인력, 실제 사업지표와 제출 증빙을 확정할 수 없다. 또한 FPT·Sunwah Group의 세부 수요과제 원문과 입주해 제안의 직접 정합성을 확인해야 한다. 따라서 아래 핵심값이 확인되기 전에는 최종 제출하지 않는다.

## 2. 공식 공고 확인값

- 모집대상: 모집 분야 해당 기술을 보유한 **서울 소재, 설립 7년 미만 스타트업**
- 지원내용: 선정 5개사에 기업별 베트남 시장분석 보고서 제공
- 심화지원: 제품설명회 후 3개사를 정해 수요기업 연계 PoC와 기업당 최대 1,000만 원의 현지 PoC 비용 지원
- 신청방법: 서울창업허브M+ 온라인 접수
- 공식 페이지는 협업 수요기업을 본문에서 `FPT 및 Sunwah Group`으로 안내한다. 원문 페이지의 `FTP` 표기는 오기로 보이며, 신청서에는 공고 첨부 원문 기준 명칭만 사용한다.

## 4. 파트너별 협업 가설

### FPT — 조건부 Go

FPT의 software·digital transformation 역량과 연결해 베트남 현지 임대주거 사업자 또는 부동산 플랫폼용 tenant onboarding/matching workflow를 제안한다. 초기 PoC는 실제 신용평가나 중개 자동화가 아니라 합성·비식별 사례를 활용한 자료 완성도, matching 설명 가능성, 운영자 검토시간 검증으로 한정한다.

**PoC 초안**

- 대상: 베트남 임대운영 또는 부동산 플랫폼 현업 2~3명
- 입력: 합성 tenant profile 및 매물 30건
- 출력: 후보 매물 ranking, 적합·부적합 사유, 미확인 항목, 다음 행동
- 지표: 현업 기준과의 일치율, 검토시간, 누락 발견률, 설명 이해도
- 제외: 실제 개인신용정보 연동, 금융·보험 판단, 자동 계약, 법률판단

### Sunwah Group — 탐색형 조건부 Go

Sunwah의 베트남 사업 네트워크를 현지 고객 discovery와 PoC 수요처 연결 채널로 본다. 직접적인 부동산·주거 운영 수요가 세부 수요과제에서 확인될 때만 신청 우선순위를 높인다. 확인되지 않으면 범용 해외진출 제안으로 희석될 가능성이 있어 No-Go가 합리적이다.

**첫 미팅 목표**

- 베트남 임대주거 운영사·부동산 플랫폼의 tenant screening 및 matching 문제 확인
- 현지 개인정보·부동산 중개 규제 검토 주체 확인
- 실제 데이터 없이 진행 가능한 4주 discovery/PoC 범위 합의

## 6. Go/No-Go 게이트와 일정

- **8/25**: 사업자등록증 기준 서울 소재·설립일, 영어 담당자, 제외사유 확인
- **8/26**: 공고 첨부 원문과 FPT·Sunwah 세부 수요과제 확보, 파트너 우선순위 확정
- **8/27~9/2**: 국·영문 기업소개서와 4주 PoC one-pager 작성
- **9/3~9/7**: 지표·표현·개인정보·제출파일 교차검수
- **9/8**: 보드 최종 승인
- **9/9 18:00 이전**: 내부 제출 마감. 공식 마감 이틀 전 완료해 업로드 장애와 보완 요청에 대비

다음 조건을 모두 충족하면 Go다.

1. 서울 소재와 업력 요건이 증빙된다.
2. 영어 핵심인력이 전 일정에 참여할 수 있다.
3. FPT 또는 Sunwah 수요과제 중 하나와 직접 연결되는 현업 문제·PoC 지표를 제시할 수 있다.
4. 국·영문 소개서, 신청서, 사업자등록증을 준비할 수 있다.
5. 보드가 최종 문구와 외부 제출을 승인한다.

서울 소재 또는 업력 요건이 불충족하거나, 파트너 수요과제에 부동산·주거·matching workflow와 연결할 실질 접점이 없으면 No-Go다.

## 7. 보드 확인 요청값

- 기업형태와 개업·법인설립일
- 사업자등록증상 본점/사업장 시·도
- 영어 발표·협업 담당자와 프로그램 일정 참여 가능 여부
- 증빙 가능한 사용자·고객·매출·PoC 지표
- 국세·지방세 체납, 채무불이행, 휴·폐업 등 신청제외 사유 부존재
- FPT 우선 신청 및 합성 데이터 기반 4주 PoC 방향 승인 여부
- 외부 신청 실행 담당자

민감한 상세 주소, 사업자등록번호, 개인 연락처와 증빙 원문은 Git 또는 Paperclip 댓글에 올리지 않고 최종 신청 시스템에서만 취급한다.
