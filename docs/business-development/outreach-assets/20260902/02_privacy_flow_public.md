# 입주해 개인정보 처리 흐름 — 공개용 요약

> 외부 이해관계자 설명용 · 실제 운영 전 최신 개인정보처리방침 및 법률 검토 우선

## 기본 흐름

`사용자 입력·업로드` → `목적과 공개 범위 확인` → `서비스 제공을 위한 저장·처리` → `사용자가 선택한 항목만 표시·공유` → `정정·삭제·탈퇴 요청 반영` → `보유 목적 종료 시 파기 또는 법령상 분리 보관`

| 단계 | 처리 내용 | 공개용 안전 원칙 |
|---|---|---|
| 수집 | 계정, 프로필, 확인 기록, 매물 관련 정보 등 서비스 제공에 필요한 항목 | 목적에 필요한 항목만 요청하고 필수·선택을 구분 |
| 이용 | 회원 관리, 기록 정리, 매칭·확인 기능 제공, 서비스 개선 | 고지한 목적 범위 안에서 사용 |
| 보관 | 접근 권한이 통제된 저장소에 목적별 보관 | 보유기간과 접근 주체를 구분하고 처리 기록을 남김 |
| 표시 | 사용자의 본인 화면 또는 권한이 있는 관리 화면에 표시 | 상세주소·연락처 등 식별정보의 불필요한 노출 방지 |
| 공유 | 사용자가 공개를 선택한 항목을 정해진 대상·목적으로 제공 | 동의 상태, 공개 항목, 대상, 목적, 만료 범위를 확인 |
| 권리 행사 | 열람, 정정, 삭제, 처리정지, 탈퇴 요청 접수 | 요청자 확인 후 관련 처리와 전파 상태를 기록 |
| 종료·파기 | 목적 달성·보유기간 종료 시 삭제 또는 비식별화 | 법령상 보존이 필요한 기록은 근거와 기간을 분리 관리 |

## 아웃리치·인터뷰 단계의 추가 원칙

- 기관 승인 전에는 참여자 모집이나 개인정보 수집을 진행하지 않습니다.
- 초기 인터뷰에서는 실제 계약서, 상세 주소, 연락처, 신분·소득·신용 서류를 요청하지 않습니다.
- 결과는 개인을 식별할 수 없도록 요약하며 원문·녹음·화면 캡처가 필요하면 사전 동의 범위를 별도로 확인합니다.
- 합성 화면은 실제 고객 데이터와 분리하고 `SAMPLE · 합성 데이터`로 표시합니다.

## 이용자 선택과 문의

이용자는 개인정보 열람, 정정, 삭제 및 처리정지를 요청할 수 있습니다. 공개용 문의 창구는 현재 서비스 개인정보처리방침에 기재된 `privacy@ipjuhae.com`이며, 아웃리치 회신 주소로 사용할지는 대표가 별도로 승인해야 합니다.

## 한계

이 문서는 외부 이해를 돕기 위한 요약이며 개인정보처리방침, 이용약관 또는 법률의견을 대체하지 않습니다. 실제 수집 항목, 처리 근거, 보유기간, 제3자 제공·처리위탁과 기술적 보호조치는 기능 출시와 계약 관계에 맞춰 별도 검토합니다.
