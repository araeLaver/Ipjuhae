## 1. 성남산업진흥원 창업성장부

- 목적: 기존 지원 관계를 활용해 부동산·주거복지 전문가 1명과 현장 인터뷰 기회를 요청한다.
- 제안: 30분 온라인 미팅 1회, 입주해 리스크 리포트 샘플 1건 피드백, 필요 시 성남권 공인중개사·주거복지기관 소개.
- 필요한 첨부자료: 1p 서비스 소개서, 화면 3장 이하의 리포트 샘플, 질문지 1p.
- 예상 리스크: 지원사업 신청·선정으로 오해될 수 있음. 비용·공식 협약을 먼저 제안하지 않고 후속 멘토링 요청으로 한정한다.

### 이메일 초안

**제목:** [입주해] 임대차 계약 전 확인 리포트 현장 검증 멘토 연결 요청

안녕하세요. 성남산업진흥원 지원을 통해 주거 신뢰 플랫폼 ‘입주해’를 개발 중인 김다운입니다.

입주해는 임대인·임차인·주택을 각각 분리해 확인하고, 민감한 원본자료를 그대로 공개하지 않으면서 계약 판단에 필요한 확인상태와 다음 행동을 보여주는 서비스입니다.

현재 기능 구현 이후 현장 타당성을 검증하는 단계로, 부동산 중개 또는 주거복지 실무 경험이 있는 전문가에게 아래 두 가지를 30분 정도 자문받고 싶습니다.

1. 계약 전에 실제로 빠지기 쉬운 확인항목
2. 리포트 표현 중 오해나 과도한 판단을 유발할 수 있는 부분

가능하시다면 적합한 멘토 또는 성남권 현장 전문가 연결 방법을 안내 부탁드립니다. 검토용 1p 소개서와 익명 예시 화면을 보내드릴 수 있습니다.

## 2. 한국공인중개사협회 성남권 지회

- 목적: 현직 개업공인중개사 3~5명을 대상으로 20분 문제 인터뷰를 진행해 중개 흐름과 충돌하는 지점을 찾는다.
- 제안: 판매 없는 인터뷰, 익명 피드백, 참여자에게 결과 요약 공유. 개인정보·실제 계약자료는 요청하지 않는다.
- 필요한 첨부자료: 중개사용 리포트 샘플 1p, 인터뷰 질문 8개, 데이터 미수집 안내.
- 예상 리스크: 협회 공식 제휴 요청으로 과대 해석되거나, 중개업을 대체하는 서비스로 오해될 수 있음. “중개 판단 보조·확인 누락 방지”로 포지셔닝하고 법률 판단·중개행위 대체가 아님을 명시한다.

### 콜 스크립트

안녕하세요. 성남에서 임대차 계약 전 확인 누락을 줄이는 서비스 ‘입주해’를 개발 중인 김다운입니다. 협회 공식 제휴나 영업 요청이 아니라, 현직 중개사 3~5분께 익명으로 20분씩 문제 인터뷰를 부탁드릴 수 있는지 문의드리려고 연락드렸습니다.

서비스는 임대인·임차인·주택의 확인상태를 분리해 보여주고, 중개사의 법률 판단이나 중개행위를 대체하지 않습니다. 실제 계약서나 고객 개인정보도 받지 않습니다. 성남권에서 인터뷰 취지를 검토해 주실 담당자 또는 지회 연결이 가능할까요?

### 담당자 연결 후 이메일 초안

**제목:** [현장 인터뷰 요청] 임대차 계약 전 확인 누락 방지 리포트

안녕하세요. 통화드린 입주해 김다운입니다.

입주해는 임대인·임차인·주택의 확인상태와 미확인 사유, 다음 행동을 한 화면에 정리하는 서비스입니다. 제품 판매가 아닌 현장 검증을 위해 성남권 개업공인중개사 3~5분께 각 20분의 인터뷰를 요청드립니다.

- 확인하고 싶은 내용: 계약 전 반복 확인 항목, 고객 설명이 어려운 항목, 리포트 표현의 오해 가능성
- 요청하지 않는 내용: 실제 고객 개인정보, 계약서, 영업기밀
- 제공 자료: 익명 리포트 샘플 1p, 질문지, 인터뷰 결과 요약

가능 여부와 적절한 진행 절차를 알려주시면 일정은 참여자 편의에 맞추겠습니다.

## 3. LH 성남권주거복지지사

- 목적: 공공임대·주거복지 현장 기준에서 입주해의 확인항목과 민감정보 최소화 원칙을 검토받는다.
- 제안: 담당자 1명과 30분 인터뷰 또는 서면 질문 5개 회신. 공공 데이터/API 제공이나 기관 보증은 요청하지 않는다.
- 필요한 첨부자료: 공공임대 적용을 가정하지 않은 서비스 소개 1p, 데이터 흐름 요약, 질문지.
- 예상 리스크: 공식 사업제안·조달·데이터 연계 요청으로 오해될 수 있음. 초기에는 사용자 문제 인터뷰임을 명시하고, 기관명·로고 사용 허락을 요청하지 않는다.

### 공문 수신 부서 문의 콜 스크립트

안녕하세요. 성남에서 임대차 계약 전 확인 서비스를 개발 중인 입주해 김다운입니다. 공공임대 사업 참여나 데이터 제공 요청이 아니라, 주거복지 실무 관점에서 계약 전 확인항목을 30분 정도 자문받을 수 있는 담당 부서가 있는지 문의드립니다.

민감한 원본자료를 노출하지 않고 확인상태만 보여주는 방식과, 임대인·임차인·주택을 분리해 확인하는 방식이 현장에 적절한지 검증하려는 목적입니다. 제안서 또는 질문지를 받을 수 있는 공식 수신 채널을 안내해 주실 수 있을까요?

## 4. 서울시 전월세종합지원센터

- 목적: 공개된 주택임대차 계약 주요 확인사항과 입주해 리포트 항목 간 누락·과장 표현을 검수한다.
- 제안: 센터 상담 인력을 영업 대상으로 삼지 않고, 협업 또는 정책 제안 수신 부서를 문의한 뒤 5개 질문을 전달한다.
- 필요한 첨부자료: 공개 체크리스트 대비표, 리포트 샘플, “법률 판단 아님” 고지문.
- 예상 리스크: 시민상담 대표번호를 영업에 사용한다는 인상을 줄 수 있음. 통화는 담당 부서 확인 1회로 제한하고, 상담 대기 발생 시 즉시 종료한다.

### 담당 부서 문의 스크립트

안녕하세요. 시민 상담 신청이 아니라, 임대차 계약 전 확인 도구를 개발하는 초기기업의 협업 문의입니다. 서울시가 공개한 계약 주요 확인사항을 기준으로 저희 리포트의 누락과 오해 가능성을 검토하고 싶습니다.

상담 인력의 시간을 사용하지 않도록 질문 5개와 1p 자료를 서면으로 보내려 합니다. 정책 제안 또는 민간 협업 자료를 접수하는 담당 부서와 공식 이메일을 안내받을 수 있을까요?

## 5. HUG 전세피해지원센터

- 목적: 피해 발생 후 반복적으로 확인되는 계약 전 위험 신호를 범주 수준에서 학습해 예방 리포트 질문을 개선한다.
- 제안: 피해자 개인정보·사례 원문·내부 통계를 요청하지 않고, 공개 가능한 범주의 예방 체크포인트와 표현 원칙만 문의한다.
- 필요한 첨부자료: 질문지 1p, 리포트 샘플, 개인정보 미수집 서약 문구.
- 예상 리스크: 피해자 상담 채널의 운영을 방해하거나 HUG 인증 서비스처럼 보일 수 있음. 센터 대표번호는 별도 협업 담당을 찾는 데만 사용하고, HUG 명칭·로고·검증 문구를 제품에 쓰지 않는다.
