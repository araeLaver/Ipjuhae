# 임대차 리스크 리포트 1주 고객검증 패키지

작성일: 2026-08-31  
범위: 개인정보·실제 고객 연락·결제 없이 사용하는 내부 검증용 mock  
판단 경계: 이 문서는 법률·권리분석 결과나 보증금 안전을 보장하지 않는다. 모든 주소·인명·금액은 합성 데이터다.

## 1. 이번 주에 검증할 가설

| 대상 | 핵심 가설 | 제안 가치 | 우선 검증할 행동 |
|---|---|---|---|
| B2C 임차인 | 계약 직전 임차인은 원문 자료보다 `지금 확인할 위험 3개`와 중개사·임대인에게 물을 질문을 원한다. | 3분 내 읽는 계약 전 위험요약 | mock을 5초 본 뒤 위험과 다음 행동을 말할 수 있는지 확인 |
| B2B 중개·운영자 | 반복 확인을 표준화하고 고객설명 문구까지 제공하면 매물당 점검 시간을 줄일 수 있다. | 매물 사전점검과 설명 근거를 한 화면에 제공 | 기존 점검 흐름 대비 절감 시간과 도입 의향 확인 |

이번 주에는 정확한 법률 판정이나 자동화 성능을 검증하지 않는다. `이 형식이 의사결정에 유용한가`, `누가 비용을 낼 것인가`, `어떤 근거가 빠졌는가`만 검증한다.

## 2. B2C 1페이지 mock — 계약 전 위험요약

> **입주해 계약 전 위험요약 · SAMPLE-T01**  
> 합성 사례 / 2026-08-31 생성 / 법률 자문 아님

### 한눈에 보기: **추가 확인 필요**

계약을 중단하라는 의미가 아니다. 계약금 지급 전에 아래 3개를 확인해야 한다.

| 신호 | 현재 입력 | 해석 | 다음 행동 |
|---|---|---|---|
| 보증금 수준 | 보증금 18,000만원 / 비교 표본 중앙 16,500만원 | 표본 중앙보다 약 9% 높음 | 동일 면적 최근 계약 3건과 계약일을 요청 |
| 권리자료 | 등기사항 요약 미입력 | 소유자·근저당·압류 여부를 판단할 자료 없음 | 최신 등기사항증명서를 확인하고 계약 상대방과 소유자 일치 확인 |
| 보증 가능성 | 보증기관 사전확인 미실시 | 가입 가능 여부를 아직 판단할 수 없음 | 계약 전 보증기관의 대상주택·금액 요건 확인 |

### 계약 전 그대로 물어볼 3문장

1. “오늘 발급한 등기사항증명서와 임대인 신분 확인 결과를 같이 볼 수 있을까요?”
2. “최근 동일 면적의 실제 계약 금액과 이 보증금의 산정 근거를 알려주세요.”
3. “보증 가입이 불가능하면 계약금 반환이 가능한 특약을 협의할 수 있을까요?”

### 확인에 사용한 입력

- 합성 주소: 서울시 새봄구 안심동 101-1, 안심하우스 84.5㎡
- 거래 조건: 보증금 18,000만원 / 월세 0만원
- 비교 데이터: 합성 동일 단지 5건, 2026-01~2026-07
- 미입력: 등기 원문, 건축물대장, 임대인 정보, 보증기관 조회 결과

### 읽는 법

- **확인됨**: 입력 근거 안에서 명확함
- **추가 확인 필요**: 자료가 없거나 표본이 부족함
- **주의**: 입력값이 비교 표본의 일반 범위를 벗어남
- 결과는 사기·법적 유효성·보증금 회수 가능성을 판정하지 않는다.

## 3. B2B 1페이지 mock — 매물 리스크 사전점검

> **입주해 매물 사전점검 · SAMPLE-B01**  
> 중개·임대운영 내부용 합성 사례 / 고객 제공 전 담당자 확인 필요

### 처리 결과: **조건부 등록 권고**

필수자료 6개 중 4개가 확인되었다. `소유자 일치`와 `보증 가능성` 확인 전에는 “안전 매물” 표현을 사용하지 않는다.

| 점검 항목 | 상태 | 근거/결손 | 담당자 조치 |
|---|---|---|---|
| 주소·단지 매칭 | 확인됨 | 지번·단지명 exact match | 없음 |
| 가격 이상도 | 확인됨 | 동일 면적 8건 중 55 percentile | 고객에게 비교기간 고지 |
| 소유자 일치 | 미확인 | 등기·신분대조 미입력 | 원본 대면/공식 채널 확인 |
| 선순위 권리 | 추가 확인 | 합성 등기 요약에 근저당 표시 | 채권최고액·시세 대비 비율 확인 |
| 건축물 용도 | 확인됨 | 합성 건축물대장상 공동주택 | 발급일 기록 |
| 보증 가능성 | 미확인 | 보증기관 사전조회 없음 | 가입요건 조회 후 결과 기록 |

### 고객설명용 문구

“공개·제출 자료 기준으로 주소와 가격 범위는 확인됐습니다. 다만 소유자 일치와 선순위 권리, 보증 가입 가능성은 별도 확인 전이므로 계약 전에 최신 원본과 기관 기준을 함께 확인하겠습니다.”

### 운영 효과 기록

| 항목 | 기존 방식 | mock 사용 후 목표 |
|---|---:|---:|
| 1건 사전점검 | 25분 | 10분 이하 |
| 누락 재문의 | 평균 2회 | 1회 이하 |
| 고객설명 작성 | 담당자 자유서술 | 근거 포함 표준문구 1개 |

### 금지 표현

`100% 안전`, `전세사기 없음`, `보증금 회수 보장`, `법적 문제 없음`은 사용하지 않는다. 근거 발급일·출처·미확인 항목을 항상 함께 표시한다.

## 4. 인터뷰 가이드와 성공지표

진행 순서는 `최근 경험 질문 → mock 5초 노출 → 이해도 회상 → 가치·지불 질문`으로 고정한다. 기능 설명이나 유도 질문은 피한다.

### A. 임차인 5명

1. 최근 집을 알아보거나 계약할 때 가장 불안했던 순간은 언제였고, 실제로 무엇을 확인했나요?
2. 이 mock을 5초만 본 뒤, 계약 전에 확인해야 할 가장 중요한 항목을 말해 주세요.
3. 이해하기 어렵거나 믿기 어려운 표현, 근거가 부족해 보이는 항목은 무엇인가요?
4. 이 리포트를 언제, 누구에게 보여주거나 어떤 행동에 쓰겠나요?
5. 실제 계약 직전에 같은 형식의 리포트를 받는다면 무료·건당 4,900원·건당 9,900원 중 어디까지 선택하겠으며, 그 이유는 무엇인가요?

성공 기준:

- 5명 중 4명 이상이 5초 노출 후 핵심 위험 2개 이상을 정확히 회상
- 5명 중 3명 이상이 구체적 후속 행동을 1개 이상 선택
- 5명 중 2명 이상이 4,900원 이상의 실제 지불의향과 구매 시점을 함께 제시
- “안전 보장/사기 판정”으로 오해한 응답이 1명 이하

### B. 중개·임대운영 실무자 5명

1. 현재 매물 등록 전 반드시 확인하는 항목과 건당 소요시간은 얼마인가요?
2. 누락이나 고객 재문의가 가장 자주 발생하는 단계는 어디인가요?
3. 이 mock에서 기존 업무를 줄여 주는 부분과 오히려 추가되는 부분은 무엇인가요?
4. 고객에게 보여주기 전에 반드시 필요한 근거·면책·수정 권한은 무엇인가요?
5. 월 30건 기준 좌석당 월 3.9만원, 건당 1,500원, 무료 체크리스트 중 어떤 방식이 현실적이며 내부 도입 결정자는 누구인가요?

성공 기준:

- 5곳 중 3곳 이상이 현재 건당 점검시간과 반복업무를 수치로 확인
- 5곳 중 3곳 이상이 30% 이상의 시간 절감 가능성을 평가
- 5곳 중 2곳 이상이 유료 pilot 조건(가격·건수·결정자)을 구체적으로 제시
- 필수 근거·면책·승인흐름 요구사항 5개 이상 수집

### 공통 기록 양식

| 필드 | 기록 내용 |
|---|---|
| participant_id | `T01~T05`, `B01~B05`만 사용; 이름·전화번호 저장 금지 |
| 최근 행동 | 실제 확인한 자료와 소요시간 |
| 5초 회상 | 정확히 회상한 신호 수 |
| 다음 행동 | 선택한 행동과 이유 |
| 신뢰 결손 | 필요한 출처·근거·면책 |
| 가격 반응 | 선택 가격, 구매 시점, 결정자 |
| 판정 | strong / weak / reject |

## 6. 1주 실행·판정표

외부 인터뷰 실행은 보드 승인 후 별도 진행한다. 승인 전에는 내부 2인 dry-run까지만 허용한다.

| 일차 | 활동 | 산출물 |
|---|---|---|
| D1 | 두 mock과 3개 sample 내부 dry-run | 표현 오류·오해 목록 |
| D2 | 승인된 대상에게 인터뷰 요청 | 임차인 5명, 실무자 5곳 일정 |
| D3~D5 | 20분 인터뷰, 정량 기록 | 비식별 응답표 10건 |
| D6 | 지표 집계와 반대증거 정리 | B2C/B2B scorecard |
| D7 | Go/Pivot/Stop 결정 | 다음 2주 실험안 |

최종 판정:

- **Go**: 해당 대상의 모든 성공 기준 충족
- **Pivot**: 이해·행동 지표는 충족하지만 지불의향 또는 운영 ROI 기준 미달
- **Stop**: 핵심 위험 회상 또는 실제 업무 문제 확인 기준 미달

## 7. 승인 전 체크리스트

- [ ] 실제 주소·등기·계약서·전화번호·이메일을 입력하지 않는다.
- [ ] 인터뷰 참여자 모집과 외부 발송은 보드 승인을 받는다.
- [ ] 녹음하지 않고 participant_id 기반 메모만 남긴다.
- [ ] 가격 질문은 결제를 받지 않는 가설검증임을 고지한다.
- [ ] 법률 자문·사기 판정·안전 보장으로 표현하지 않는다.
- [ ] 공개데이터를 사용할 때 출처·기준일·표본수를 함께 표시한다.

## 8. 다음 결정 요청

보드는 아래 중 하나를 선택한다.

1. **내부 dry-run 승인**: 팀 내부 2인에게 mock 이해도만 확인
2. **외부 인터뷰 승인**: 개인정보 없이 임차인 5명·중개/운영 실무자 5곳 대상 인터뷰 요청
3. **보류**: 근거 데이터·면책 문구·가격안 보완 후 재검토
