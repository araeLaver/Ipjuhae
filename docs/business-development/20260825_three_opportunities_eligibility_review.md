## 1. 2026 위치정보 맞춤형 컨설팅

### 원문 확인 결과

- 제시된 근거는 개별 공고가 아닌 서울창업허브 통합 목록이다.
- 2026-08-25 기준 공개 API 전체 목록을 조회했으나 `위치정보`를 포함한 동일 공고를 찾지 못했다.
- 검색엔진과 KISA·방송미디어통신위원회 공개자료에서도 해당 제목·마감일의 2026 공고를 확인하지 못했다.
- 따라서 운영기관, 대상, 신청기간, 제출서류, 개인정보 수집주체를 검증할 수 없다.

### 판정 및 준비자료

현재는 **No-Go**다. 단순 링크 오류일 수 있으므로 아래 중 하나가 확보되면 재검토한다.

- 공고 고유 URL 또는 공고문 PDF/HWP
- 운영기관명과 담당부서
- 신청 마감 시각과 신청 채널
- 지원대상·제외대상·비용 유무

재검토 시 준비 후보는 서비스 소개서, 위치정보 흐름도, 이용약관, 개인정보처리방침, 위치정보사업 등록·신고 현황이다. 다만 공고 확인 전에는 민감한 회사자료를 업로드하지 않는다.

## 2. 벤처확인 도전기업 1:1 비대면 밋업

### 확인된 성격과 자격

- 운영기관은 `(주)엠비즈플래닛 산하 혁신기술경영인증지원센터`인 민간기관이다.
- 센터는 K-Startup 민간 사업공고 승인기관이라고 밝히고 있으나, 이 프로그램 자체가 정부 보조금·정부 인증을 의미하지는 않는다.
- 센터 공개 페이지의 무료 진단 안내에는 `직원수 2명 이상`과 `직전년도 매출 보유`가 표시돼 있다.
- 대상은 벤처기업확인 최초 신청 또는 재인증을 준비하는 기업이며, 업종·설립 연차·매출·고용·R&D 조직·기술·인증 경험을 상담에서 확인한다.
- 2026년 하반기 모집기간은 2026-08-22~2026-09-18로 공고 집계 페이지에서 확인되지만, 별도 첨부 공고문은 확보하지 못했다.

### 준비자료와 누락값

| 항목 | 현재 상태 | 조치 |
|---|---|---|
| 직원 2명 이상 | 저장소에서 확정 불가 | 4대보험 기준 상시근로자 수 확인 |
| 직전년도 매출 | 저장소에서 확정 불가 | 2025 재무제표 또는 부가세 과세표준증명 확인 |
| 벤처확인 상태 | 저장소에서 확정 불가 | 최초·재인증·검토 중 중 선택 |
| 기술·R&D 근거 | 특허 준비자료와 software 구현자료 존재 | 공개 가능한 1p 요약만 우선 준비 |
| 개인정보·영업연락 동의 | 미승인 | 대표자 승인 후 최소정보만 입력 |

**Go 조건:** 직원·매출 요건을 충족하고 3개월 내 벤처확인 신청 의사가 있으며, 민간 상담기관에 연락처를 제공해도 된다는 보드 승인이 있을 때 신청한다.

**No-Go 조건:** 무매출·1인 기업이거나 벤처확인 신청 계획이 없거나, 유료 서비스 전환 조건이 불명확하면 진행하지 않는다.

## 3. 2026년 GovTech 창업경진대회

### 공식 공고 핵심

- 주관 공고: 정보통신산업진흥원(NIPA)
- 접수: 2026-08-20 10:00~2026-09-21 10:00
- 방식: `k-govtech.kr` 온라인 접수
- 분야: 아이디어 기획, 제품·서비스 개발
- 대상: 예비창업자 또는 공고일 기준 사업개시일부터 3년이 지나지 않은 초기창업기업
- 1차 합격자는 10~11월 OT·교육·멘토링·부트캠프 필참이며, 불참 시 2차 평가에서 제외된다.
- 2차는 대면 발표평가이고 시상식은 12월 초 예정이다.

초기창업기업 회원가입 화면에는 공고일이 2026-08-20으로 명시되어 있고, 다수의 개인·법인 사업자를 보유한 경우 모든 사업자가 업력 3년 이내여야 한다고 안내한다.

### 입주해 권장 트랙

법인/사업자가 존재하고 업력 요건을 충족한다면 **제품·서비스 개발 분야**가 적합하다. 저장소상 MVP, API, launch smoke, test suite 등 구현 근거가 있어 단순 아이디어보다 개발보고서로 설명하기 좋다.

제안 문제는 다음처럼 좁힌다.

> 공공·민간 주거 데이터를 연결해 임차인이 매물 탐색과 계약 전 확인 단계에서 정보 비대칭을 줄이고, 확인 근거와 의사결정 과정을 구조화하는 GovTech 서비스

공공데이터의 실제 사용 여부와 API명은 구현·데이터 출처를 확인한 뒤에만 기재한다. 계획 단계의 연계는 `활용 예정`으로 구분한다.

### 필수 제출서류

초기창업기업의 제품·서비스 개발 분야 기준:

1. 참가신청서
2. 개인정보 수집·이용 동의서
3. 참가자 서약서
4. 개발보고서(HWP)
5. 사업자등록증 사본
6. 창업기업 확인서

### 적격성 표

| 기준 | 현재 판단 | 확정 방법 |
|---|---|---|
| 2026-08-20 기준 업력 3년 이내 | 미확정·핵심 차단 | 사업자등록증 개업일 또는 법인설립일 확인 |
| 보유한 모든 사업자의 업력 3년 이내 | 미확정·핵심 차단 | 대표자 보유 개인·법인 사업자 전체 확인 |
| 창업기업 확인서상 초기창업 기간 | 미확정·핵심 차단 | 유효한 창업기업 확인서 발급·기간 확인 |
| 제품·서비스 구현 | 충족 가능성 높음 | 데모 URL, 화면, test/build 증빙을 개발보고서에 선별 |
| GovTech 문제·기술 정합성 | 충족 가능성 높음 | 공공서비스 혁신 대상과 실제 데이터 출처 확정 |
| 10~11월 필참 프로그램 | 미확정 | 대표자 또는 팀 참여 가능 일정 확인 |
| 11월 대면 발표 | 미확정 | 발표자와 이동 가능 여부 확인 |

### Go/No-Go

다음이 모두 확인되면 **Go**다.

- 2026-08-20 기준 설립·개업 3년 이내이며 보유한 다른 사업자도 모두 업력 요건을 충족한다.
- 유효한 창업기업 확인서를 제출할 수 있다.
- 공공데이터 또는 공공서비스 개선 연결을 사실 기반으로 설명할 수 있다.
- 10~11월 필참 프로그램과 11월 대면평가에 참여할 수 있다.

업력 또는 창업기업 확인서가 불충족하면 초기창업기업 트랙은 **No-Go**다. 사업자가 존재하는 대표자가 사업자를 숨기고 예비창업자로 지원해서는 안 된다.

## 보드 확인 요청값

민감한 상세 주소, 사업자등록번호, 생년월일, 개인 연락처, 증빙 원문은 Git 또는 Paperclip 댓글에 올리지 않는다. 아래 결과값만 회신한다.

- 기업형태: 예비창업자 / 개인사업자 / 법인
- 개업·법인설립일: `YYYY-MM-DD`
- 대표자가 보유한 다른 개인·법인 사업자: 없음 / 있음(모두 3년 이내) / 있음(3년 초과 포함)
- 창업기업 확인서: 유효본 있음 / 발급 가능 / 없음
- 직원수 2명 이상: 확인 / 불충족
- 2025 매출: 있음 / 없음
- 벤처확인 추진: 최초 / 재인증 / 계획 없음
- 2026년 10~11월 필참 및 대면발표: 가능 / 불가 / 일정 확인 필요
- 민간 상담기관 연락처 제공: 승인 / 미승인
