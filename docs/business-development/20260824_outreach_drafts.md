## 2. 후보별 발송 초안

### 2.1 한국프롭테크포럼

- 목적: 초기 프롭테크 기업의 가입·행사 참여 경로와 임대차 확인 workflow를 검토해 줄 회원사 또는 법제도 연구반 연결 가능성 확인.
- 필요한 첨부자료: 공개용 1p 소개서, 합성 데이터 기반 리포트 예시 1장, 20분 인터뷰 질문 5개.
- 예상 리스크: 회원 가입·공식 제휴 요청으로 오해될 수 있다. 첫 접촉에서는 가입 신청이나 데이터 제휴가 아니라 적합한 프로그램·담당자 안내만 요청한다.
- 근거: 포럼은 335개 회원사와 밋업, 위원회, 법제도 연구반을 운영하며 공식 대표 접점을 공개한다.

**제목:** [입주해] 임대차 확인 workflow 고객검증을 위한 프롭테크 전문가 연결 문의

안녕하세요. 성남에서 임대차 계약 전 확인 누락을 줄이는 서비스 ‘입주해’를 개발 중인 김다운입니다.

입주해는 임차인·임대인·주택의 확인상태와 다음 행동을 구분해 보여주는 의사결정 보조 도구입니다. 법률·감정평가·신용평가·공인중개행위를 제공하거나 대체하지 않으며, 현재는 합성 데이터와 익명 화면으로 문제 인터뷰를 준비하고 있습니다.

포럼 회원사 또는 법제도 연구반 가운데 임대차 workflow와 소비자 보호 관점에서 20분 인터뷰가 가능한 전문가 1~2곳을 연결받을 수 있을지 문의드립니다. 공식 제휴나 데이터 제공 요청은 아니며, 적합한 밋업·상담 프로그램이 있다면 안내만 부탁드립니다.

검토에 필요하시면 공개용 1p 소개서와 개인정보가 없는 예시 화면을 보내드리겠습니다. 감사합니다.

### 2.2 서울광역청년센터

- 목적: 서울청년센터 네트워크에서 전·월세 계약 경험이 있는 청년 5명 이하의 익명 문제 인터뷰 안내가 가능한지 확인.
- 필요한 첨부자료: 공개용 모집문 1장, 인터뷰 동의문, 질문지, 개인정보 미수집 원칙.
- 예상 리스크: 센터의 공식 사업 또는 추천 서비스로 오해될 수 있다. 센터 로고 사용·홍보 게시를 전제하지 않고 내부 적합성 검토를 먼저 요청한다. 참여 보상은 승인 전 약속하지 않는다.
- 근거: 서울광역청년센터는 17개 지역센터의 지원 체계와 청년정책 연계망을 운영하며 대표 이메일을 공개한다.

**제목:** [입주해] 청년 임차인 20분 문제 인터뷰 안내 가능 여부 문의

안녕하세요. 임대차 계약 전 확인 누락을 줄이는 서비스 ‘입주해’를 준비 중인 김다운입니다.

전·월세 계약을 직접 경험한 청년이 계약 전에 무엇을 확인하기 어려웠는지 알아보기 위해 20분 비대면 문제 인터뷰를 준비하고 있습니다. 제품 판매나 피해 상담이 아니라 문제를 듣는 단계이며, 계약서·주소·주민번호·보증금 액수 등 개인 식별 정보와 원본 서류는 받지 않습니다.

서울청년센터 네트워크에서 아래 조건의 모집 안내를 검토하거나 적합한 지역센터 담당자를 연결해 주실 수 있을까요?

- 최근 2년 내 전·월세 계약 또는 집보기를 경험한 만 19~39세 청년
- 최대 5명, 1인 20분 비대면 인터뷰
- 익명 메모만 작성하고 발언 인용은 별도 동의 시에만 사용

센터의 공식 추천이나 홍보를 전제하지 않습니다. 가능 여부와 사전 검토에 필요한 양식을 알려주시면 모집문·동의문·질문지를 보내드리겠습니다.

### 2.3 성남시 청년 전·월세 안심계약 도움 서비스

- 목적: 주거안심매니저 1~2명에게 계약 전 확인 누락과 기존 공공지원 workflow에 관한 20분 전문가 인터뷰를 요청할 담당 부서 확인.
- 필요한 첨부자료: 공개용 1p 소개서, 인터뷰 질문지, 기능 경계표.
- 예상 리스크: 성남시와의 실증·납품 또는 서비스 추천 요청으로 오해될 수 있다. 현재 단계에서는 담당 부서 연결과 전문가 인터뷰만 요청한다.
- 근거: 성남시는 청년 전·월세 안심계약 도움 서비스를 운영하며 성남시 거주·거주 예정 청년에게 전화·대면 상담과 집보기 동행을 제공한다고 공식 안내했다.

**콜 스크립트:**

안녕하세요. 성남에서 임대차 계약 전 확인 누락을 줄이는 서비스 ‘입주해’를 개발 중인 김다운입니다. 성남시 청년 전·월세 안심계약 도움 서비스의 주거안심매니저 또는 운영 담당자에게 고객 문제 인터뷰를 정식으로 문의하고 싶어 연락드렸습니다.

판매나 제휴 체결 요청이 아니라, 기존 상담에서 청년들이 반복해서 놓치는 확인 항목과 공공서비스를 침해하지 않는 제품 범위를 20분 정도 여쭙는 목적입니다. 실제 계약서나 상담자 개인정보는 요청하지 않습니다. 담당 부서명과 공식 이메일 또는 공문 접수 경로를 안내받을 수 있을까요?

### 2.4 한국부동산원

- 목적: R-ONE, RTMS, 부동산거래 전자계약 시스템 등 공개 서비스의 스타트업 활용 가능 범위와 별도 API·제휴 문의 창구 확인.
- 필요한 첨부자료: 필요한 데이터 항목 목록, 사용 목적·보관기간 표, 현재 수기/OCR workflow와 향후 연동 구분표.
- 예상 리스크: 공개 데이터의 자동 수집 허용 또는 API 제공을 미리 전제할 수 있다. 첫 통화에서는 이용 가능 여부를 주장하지 않고 담당 부서와 공식 신청 절차만 확인한다.
- 근거: 한국부동산원은 R-ONE, RTMS, 부동산거래 전자계약 시스템을 공식 안내하고 콜센터를 공개한다.

**콜 스크립트:**

안녕하세요. 임대차 계약 전 확인 workflow를 개발 중인 스타트업 ‘입주해’입니다. R-ONE, RTMS, 부동산거래 전자계약 시스템에서 제공하는 공개 정보 가운데 스타트업 서비스가 이용할 수 있는 범위와 별도 Open API 또는 제휴 문의 절차를 확인하려고 합니다.

현재는 자동 수집이나 연동을 하지 않고 있으며, 이용약관·재이용 조건·출처 표시·갱신주기를 먼저 검토하려는 단계입니다. 데이터 담당 부서 또는 공식 문의 게시판을 안내받을 수 있을까요?
