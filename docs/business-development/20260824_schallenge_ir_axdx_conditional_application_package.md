## 4. 붙임1 사업계획서 서술 초안

### 4.1 제품(아이템) 개요

**제품/서비스 명칭**  
입주해(Rentme)

**한 줄 소개**  
임차인·임대인·주택의 확인값을 구조화하고 조건별 적합도와 불일치 사유를 제시해 임대차 후보 검토를 디지털 전환하는 AI 기반 역방향 매칭 플랫폼

### 4.2 기업 현황(사업화 내역, 대표자 및 팀원 역량)

- 입주해는 기존의 매물 우선 검색 흐름을 임차인 프로필과 임대 조건 중심의 후보 검토 흐름으로 전환하는 제품을 개발하고 있다.
- Next.js·TypeScript 기반 MVP에 임차인 프로필, 매물, matching 결과, 임대인 후보 검색, 대화 시작 흐름이 구현돼 있다.
- 대표자와 팀원의 경력·역할·인원은 `[확인 필요]`이며, 공식 양식에는 검증 가능한 경력과 현재 담당 업무만 기재한다.
- 2025년 사업화 실적은 `[확인 필요]`이며 증빙 없는 고객 수, 매출, 투자, 채용 수치는 기재하지 않는다.

### 4.3 아이템의 기술성

- 예산, 입주 가능일, 생활조건, 고용조건 등 복수 조건을 구조화하고 후보별 matching 결과를 계산한다.
- 결과를 단일 점수로만 제시하지 않고 조건별 사유와 치명적 불일치 항목을 분리하여 사용자가 판단 근거를 확인할 수 있게 한다.
- 임차인 프로필, 매물, 임대인 후보 검색과 대화 시작을 하나의 workflow로 연결해 반복적인 후보 탐색·검토를 줄인다.
- 현재 기능은 의사결정 보조이며 신용평가, 자동 계약, 법률 판단 또는 공인중개행위를 수행한다고 표현하지 않는다.

### 4.4 아이템의 시장성 및 사업성

- 기존 임대 플랫폼의 매물 중심 탐색에서는 임차인이 여러 조건을 반복 비교하고 임대인이 적합 후보를 일관된 기준으로 검토하기 어렵다.
- 입주해는 임차인의 조건과 프로필을 먼저 구조화해 임대인이 적합 후보를 찾는 tenant-first reverse matching으로 이 문제를 해결한다.
- 초기 검증은 서울 임대차 시장의 임차인·임대인·중개 실무자를 대상으로 진행하고, 사용 빈도·후보 검토 시간·대화 전환율을 측정하는 방식으로 설계한다.
- 구독·중개 파트너십 등 수익모델은 가설 단계로 구분하며, 현재 확정 매출이나 검증된 전환율로 표현하지 않는다.

### 4.5 가치 및 경쟁제품 비교

| 구분 | 기존 매물 검색형 서비스 | 입주해 |
|---|---|---|
| 탐색 시작점 | 매물 | 임차인 프로필과 양측 조건 |
| 후보 검토 | 사용자가 항목을 반복 비교 | 조건별 적합도·사유·불일치 항목 제시 |
| 임대인 역할 | 매물 등록 후 문의 대응 | 조건에 맞는 임차인 후보 탐색 |
| 의사결정 근거 | 매물 정보 중심 | 양측 확인값과 조건의 구조화된 비교 |

`전국 최초`, `독점`, `허위매물 구조적 제거`, `AI 신뢰 스코어`, `계약 원스톱`은 객관적 근거나 실제 구현 확인 전 삭제한다.

### 4.6 사회적 가치 및 시장 파급력

- 임대차 후보 검토 기준을 구조화하고 불일치 사유를 명시해 정보 확인 누락과 반복 탐색을 줄일 가능성이 있다.
- 임차인과 임대인 양측이 다음 행동을 결정할 근거를 확인할 수 있어 거래 전 커뮤니케이션의 명확성을 높일 수 있다.
- 사회적 효과 수치는 실증 전 목표로만 제시하고, 전세사기 예방이나 분쟁 감소를 보장한다고 표현하지 않는다.

### 4.7 향후 추진 계획 및 전략

1. MVP의 프로필·매물·matching·대화 workflow를 안정화하고 테스트 범위를 유지한다.
2. 서울 지역 사용자 인터뷰와 제한적 pilot으로 문제 적합성, 후보 검토 시간, 대화 전환을 측정한다.
3. 검증값에 출처·기준일·검수상태를 연결해 matching 결과의 설명 가능성과 최신성을 강화한다.
4. 개인정보 최소수집, 동의, 접근통제와 삭제 기준을 제품 운영 정책에 반영한다.
5. 실증 결과를 바탕으로 임대관리사·공인중개사 등 B2B 파트너 연계 가능성을 검토한다.

### 4.8 필요한 지원내용

- IR deck에서 구현 완료 기능, 검증 중 가설, 향후 계획을 명확히 구분하는 구성 자문
- tenant-first reverse matching의 고객 문제와 투자 논리를 15분 발표로 압축하는 피칭 자문
- 서울 지역 pilot 설계, 성과지표 설정, 초기 B2B 파트너 발굴 자문
- 개인정보·부동산 중개 경계와 관련된 사업모델 리스크 점검

## 5. IR deck 보완안(발표 준비·선택 첨부용)

기존 `docs/pitch-deck-202603.md`는 투자용 장문 초안이므로 다음 10장으로 압축한다.

1. **한 줄 정의:** tenant-first reverse matching 기반 임대차 후보 검토 DX
2. **문제:** 조건 반복 비교, 임대인의 후보 검토 기준 부재, 확인 누락
3. **제품 workflow:** 프로필 → 조건 비교 → 사유·dealbreaker → 대화 시작
4. **Demo:** 실제 구현 화면과 API 흐름만 사용
5. **차별성:** 매물 중심 검색 대비 시작점·검토 근거·임대인 행동 비교

- `전세사기 예방`, `허위매물 제거`처럼 인과나 효과를 보장하는 표현
