## 1. 1페이지 의사결정 요약

입주해는 임차인·임대인·주택의 확인값을 구조화하고, 예산·입주일·생활조건 등 복수 기준의 적합도와 불일치 사유를 제시하는 임대차 역방향 매칭 서비스다. 공공기관 보유 데이터의 확보·가공·PoC를 지원하는 이번 사업과 제품 방향의 정합성은 높다.

그러나 공고는 단순한 공공데이터 활용기업 모집이 아니다. 신청기업은 **2026-08-31 이전 `공공데이터포털(data.go.kr)`에서 필요한 데이터의 제공을 신청했고, 보유기관으로부터 `제공 불가` 통보를 받은 이력**이 있어야 한다. 해당 `공공데이터 제공거부 결정 통보서`를 사업계획서에 필수 첨부해야 한다. 개인정보·영업비밀 등 법령상 공개·제공이 금지되거나 제한되는 데이터는 지원 대상에서도 제외된다.

현재 저장소에는 제공거부 결정 통보서, 창업기업 확인서, 사업자등록증명, 회사성립일, 공동대표·다수사업자 현황을 확인할 증빙이 없다. 새 제공 신청을 지금 시작해도 마감 전 거부 통보를 받을지는 통제할 수 없으므로, **기존 유효 통보서가 없다면 이번 회차는 No-Go**가 안전하다. 통보서가 있다면 아래 자격 게이트를 모두 확인하고 신청 초안을 공식 양식으로 옮긴다.

## 2. 추천 데이터 후보와 기관

아래 후보는 **기존 제공거부 통보서의 데이터명·기관과 일치할 때만** 채택한다. 통보서가 없는 데이터를 임의로 신청서에 쓰거나, 개인 식별 가능한 계약 원자료를 요구하지 않는다.

### 1순위: 비식별·집계된 주택 임대차 신고정보

- 예상 보유기관: 국토교통부(실제 통보서의 처리기관 명칭을 그대로 사용)
- 필요한 항목: 시군구·읍면동 수준 지역, 주택 유형, 면적 구간, 계약 체결월, 보증금·월세 구간, 신규·갱신 구분, 계약갱신요구권 사용 여부 등 비식별·집계 필드
- 권장 형식: `API` 또는 `CSV`, 월 1회 이상 갱신, 전국 또는 초기 실증지역
- 대체 제공: 통계데이터 또는 합성데이터 우선. 개인·주소·계약 당사자 식별정보는 요청하지 않음
- 제품 활용: 임차인 예산·희망지역 조건에 대한 시장 구간 설명, 후보 조건의 현실성 안내, 지역별 임대료 분포 기반 matching 사유 보강
- 공공가치: 임대차 시장 정보 비대칭과 반복 탐색을 줄이고, 데이터 근거가 있는 주거 선택을 지원

### 2순위: 비식별·집계된 전세보증 사고·보증 현황

- 예상 보유기관: 주택도시보증공사(HUG, 실제 통보서 기준)
- 필요한 항목: 지역·주택유형·기간별 보증 가입, 보증사고, 대위변제 건수·금액의 집계값
- 권장 형식: `API` 또는 `CSV`, 월·분기 갱신, 시군구 이상 집계
- 대체 제공: 통계데이터만 요청. 개별 임대인·임차인·주소·채권 정보는 제외
- 제품 활용: 사용자가 지역·주택 유형의 집계 위험 맥락을 별도로 확인하도록 제공하되, 개별 주택 안전 판정이나 신용평가로 표현하지 않음
- 공공가치: 위험 정보 접근성을 높이되 낙인·오판을 방지하는 설명 가능한 의사결정 보조

두 후보 중 하나를 선택하는 기준은 제품 선호가 아니라 **실제 제공거부 결정 통보서와의 일치 여부**다. 통보서의 거부 사유가 개인정보 등 법률상 제공 제한이면 원자료 제공을 재요구하지 말고, 집계·익명·합성·진위확인 형태가 허용 가능한지 서울창조경제혁신센터에 먼저 확인한다.

## 3. 공식 사업계획서 이전용 초안

### 과제명

비식별 공공 임대차 데이터를 활용한 설명 가능한 임대차 후보 검토 서비스 고도화

### 문제

임차인은 희망지역, 예산, 입주일, 주택 조건을 반복 비교하지만 개별 매물 정보만으로는 조건의 시장 적합성을 판단하기 어렵다. 임대인과 중개 실무자도 후보별 조건을 일관된 기준으로 검토하기 어렵다. 공개된 단편 통계만으로는 제품 workflow 안에서 최신 지역·유형·가격 구간을 세밀하게 설명하는 데 한계가 있다.

### 해결책

입주해는 임차인 프로필과 임대 조건을 구조화하고 후보별 적합도, 조건별 사유, 치명적 불일치 항목을 분리해 보여준다. 확보한 비식별·집계 공공데이터를 정규화해 지역·주택유형·가격 구간의 맥락을 matching 설명에 결합한다. 결과는 의사결정 보조 정보이며 개별 주택의 법적 안전성, 개인 신용, 계약 적격을 자동 판정하지 않는다.

### 공공가치

- 공공 임대차 데이터의 실제 서비스 활용도를 높인다.
- 임차인의 반복 탐색과 정보 확인 누락을 줄일 가능성을 검증한다.
- 조건 비교 근거와 데이터 기준일을 노출해 설명 가능성을 높인다.
- 개인정보를 사용하지 않는 집계·익명·합성 방식으로 활용 범위를 설계한다.

### 공공기관 협업 요청

- 실제 통보서 대상 데이터의 보유·제공 가능 범위 확인
- 비식별·집계·합성 데이터 또는 진위확인 방식의 대체 제공 협의
- 필드 정의, 갱신 주기, 품질·결측 기준 협의
- 초기 샘플을 활용한 PoC와 결과 검수

### 협약기간 산출물

1. 공공데이터 수집·정규화 pipeline 1식
2. 데이터 출처·기준일·갱신상태 metadata schema 1식
3. 공공데이터 기반 matching 설명 API와 사용자 화면 각 1식
4. 비식별·접근통제·삭제 기준을 포함한 데이터 처리 문서 1부
5. 제한된 사용자 pilot 결과와 후속 고도화 보고서 1부

### 5개월 추진안

| 기간 | 내용 |
|---|---|
| 1개월차 | 기관과 제공 범위·필드·대체 형태 확정, 보안·품질 기준 수립 |
| 2개월차 | 데이터 수집·정규화·검증 pipeline 구현 |
| 3개월차 | matching 설명 API 및 화면 통합, 내부 QA |
| 4개월차 | 제한적 pilot, 정확성·이해도·후보 검토시간 측정 |
| 5개월차 | 결과 분석, 오류·편향 보완, 사업화·확장 계획 확정 |

## 4. 제출자료 공백

### 공고상 필수

- `K-Startup` 온라인 사업신청서
- 공고문 붙임 1 양식의 사업계획서(본문 약 7쪽 권장)
- `공공데이터 제공거부 결정 통보서`(사업계획서에 첨부)
- 신분 확인 서류
- 사업자등록증명
- 창업기업 확인서

공공마이데이터 동의 시 일부 행정정보가 자동 제출될 수 있으나, 연동 오류에 대비해 최신 원본을 준비한다. 사업계획서는 지정 양식 외 형식이면 평가 제외될 수 있다.

### 현재 확인되지 않은 입력값

- 법적 상호, 기업형태, 개업·회사성립일, 대표 구조
- 대표자의 기존·현재 다수 사업자와 창업 여부
- 제공 신청일, 처리기관, 데이터명, 제공거부 사유와 결정 통보서
- 국세·지방세 체납, 채무불이행, 환수금, 참여제한, 휴폐업 여부
- 2023~2025 매출·고용과 협업·투자·특허 등 증빙 가능한 실적
- 대표자 발표 가능 여부와 5개월 수행 인력
- 사업비 세부 산출근거(최대 1억원)

민감한 사업자등록번호, 상세 주소, 생년월일, 연락처와 증빙 원문은 Git 또는 Paperclip 댓글에 기록하지 않고 `K-Startup`과 승인된 제출 패키지에서만 취급한다.
