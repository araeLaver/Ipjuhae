# 2026-08-27 입주해 사업기회/지원사업 일일 발굴

## 결론

오늘의 외부 기회 1순위는 **BOUNCE 2026**이지만, 회사 자격·참석·traction 확인값이 없어 제출은 보류한다. 2순위 **2026년 GovTech 창업경진대회**도 업력과 창업기업 확인서가 핵심 게이트다. 3순위 **2026 위치정보 맞춤형 컨설팅**은 공식 모집요강이 확인됐고 연중 상시 접수지만, 현재 제품이 단말 위치나 이동경로를 처리하지 않아 신청 실익이 낮다.

당일 내부 실행은 지원사업 제출보다 먼저, 이미 확인된 **매물 주소·상세주소 개인정보 고지 갭**을 정비하는 것으로 잡는다. 외부 신청·이메일·전화·로그인·개인정보 제공은 보드 승인 없이 실행하지 않는다.

## 우선순위

- 마감: **2026-09-02 18:00**
- 기대효과: 현대건설·DB손해보험·하나은행 등과 1:1 private meetup 및 PoC 탐색 기회.
- 필요한 자료: 사업자명·설립일·소재지, 국세·지방세 체납 없음, 동일 사업 수혜 이력 없음, 2026-10-07~08 부산 BEXCO 참석자, 근거 있는 사용자·인터뷰·파일럿·매출·MVP 지표.
- 현재 판단: **조건부 Go**. 자격값과 실제 traction을 추정할 수 없고 Google Forms의 파트너별 수요는 로그인 후 대조가 필요하다.
- 다음 행동: 보드가 비민감 결과값을 확정하면 파트너별 실제 수요와 기존 제안안을 대조하고 최대 3개 파트너만 선정한다.
- 공식 공고: https://hub.kaia.re.kr/organSupportHub.do/view?orgKind=ORG_KIND_2&rltdId=118221

### 2. 2026년 GovTech 창업경진대회

- 마감: **2026-09-21 10:00**
- 기대효과: 주거 정보 비대칭과 공공데이터 활용 문제를 GovTech 제품·서비스로 구조화하고 교육·멘토링·대면평가·홍보 기회를 확보.
- 필요한 자료: 참가신청서, 개인정보동의서, 서약서, 개발보고서, 사업자등록증, 창업기업 확인서, 실제 공공데이터 사용·활용 예정 항목의 구분, demo 증적.
- 현재 판단: **보류(자격 충족 시 Go)**. 2026-08-20 기준 업력 3년 이내, 대표자가 보유한 모든 사업자의 업력, 창업기업 확인서, 10~11월 필참 가능 여부가 미확정이다.
- 다음 행동: 보드가 기업형태·설립일·다른 사업자 업력·창업기업 확인서·필참 가능 여부를 결과값으로 회신하면 제품·서비스 개발 분야 최종 적격성을 판정한다.
- 공식 공고: https://nipa.kr/home/2-1/16908

- 마감: **연중 상시 접수**. 과거 문서의 `2026-08-29 마감` 표기는 공식 모집요강과 불일치한다.

- 필요한 자료: 현재/목표 데이터 흐름도, 위치정보 처리 기능, 신고·약관·개인정보처리방침 현황, 컨설팅 질문.
- 현재 판단: **No-Go 유지**. 제품은 고정 부동산 주소 문자열을 처리하고 `geolocation=()`을 차단하며, 단말 위치·이동경로·실시간 위치 기능은 확인되지 않는다.

## 보드 최소 확인값

민감한 증빙 원문, 상세주소, 사업자번호, 연락처는 Git 또는 Paperclip 댓글에 올리지 않는다.

- BOUNCE: 업력 7년 미만 / 체납 없음 / 동일 사업 수혜 없음 / 10월 7~8일 참석 가능 / 공개 가능한 traction 있음 여부
- GovTech: 기업형태 / 개업·법인설립일 / 다른 보유 사업자 업력 / 창업기업 확인서 / 10~11월 필참 가능 여부
- 제품 로드맵: 향후 6개월 안에 단말 현재 위치·이동경로·실시간 위치 기능을 도입할지 `예/아니오`

## 오늘의 내부 후속

`app/privacy/page.tsx`와 실제 주소 데이터 흐름을 대조해 매물 주소·상세주소의 수집 항목, 목적, 보유기간, 공개 범위, 삭제·탈퇴 시 파기 경로를 문서화한다. 이는 위치정보 컨설팅 신청과 무관하게 현재 제품에 필요한 개인정보 고지 정비다.
