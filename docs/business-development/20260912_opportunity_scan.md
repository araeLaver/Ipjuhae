## 판단

이번 신규 실행 후보는 오피스텔 갱신 비교, 임대시장 원문 안내, 지역 주거상담 업무 검증, AI 파트너 탐색, IP 교육 기반 공개범위 정리의 5개다. 지원금 모집이 확인된 것으로 해석하지 않는다. 기존 9월 2일 문서의 모두의 창업 신청 우선순위는 별도이며, 이 보고서는 이를 대체하지 않는다.

조사일: 2026-09-12. 공식 페이지의 제공 기능과 사업개발 가설을 구분했다. 관련 주제를 기존에 다뤘을 가능성은 있으나, 이번 후보는 아래 고객·산출물·검증 행동 조합으로 구체화했다. 오피스텔·임대시장 사이렌·IP CAMPUS 키워드는 기존 business-development 문서 검색에서 일치하지 않았다. 전사 이력 전체의 최초 발굴을 보장하지는 않는다.

## 바로 쓸 내부 검증 초안

갱신 비교 카드 필드: 비교기간, 보증금, 월세, 관리비 포함·제외 항목, 일회성 비용, 출처, 확인일, 미확인 값. 보증금 원금과 기간 지출을 합산해 총비용으로 표시하지 않는다. 보증금 조달비용을 비교할 경우 사용자가 정한 가정과 별도 항목으로 표시한다.

출처 확인 카드 질문: 자료 기준일은 언제인가? 지역·주택유형은 비교 대상과 같은가? 자료가 설명하지 못하는 개별 조건은 무엇인가? 추가로 누구에게 무엇을 확인해야 하는가?

상담 인계 인터뷰 질문: 반복 질문은 무엇인가? 상담 전 꼭 필요한 항목은 무엇인가? 없어도 되는 정보는 무엇인가? 기존 양식이 있는가? 준비 시간이 얼마나 드는가? 도입 결정과 구매는 누가 담당하는가?

## 실행 경계와 다음 담당

사업개발 담당은 합성 데이터 기반 비교·출처 카드 검증 패키지를 작성한다. Down에게는 외부 테스트 진행 여부, 대상 유형, 공개 가능한 데모 범위, 무보상 인터뷰 여부에 대한 비식별 확인값만 요청한다. 대표자 연락처·실제 계약서·개인정보 원문은 요청하지 않는다. 승인 대기와 무관하게 내부 초안은 진행 가능하다.

법무/IP·개인정보·신용정보·위치정보는 이번에 법률 결론을 내리지 않았다. 실제 신뢰 프로필·계약 분석을 외부 제공할 때에는 기존 검토 자료와 추가 전문 검토가 필요하다. 현장 행사·IR·지원금 신규 모집은 이번 조사에서 현재 신청 가능성을 확정한 후보가 없으므로 선정 목록에 포함하지 않았다.
