# 2026-09-02 9월 초 1순위 사업기회 및 실행 초안

작성 기준일: 2026-09-02  
용도: 보드 의사결정 및 승인 후 실행 준비  
경계: 외부 제출, 본인인증, 개인정보 입력, 이메일 발송은 수행하지 않는다.

## 결론

**1순위는 `2026년 모두의 창업 프로젝트 2차` 일반/기술트랙 신청 준비다.**

공식 공고상 신청기간은 2026-08-20~09-17이며, 기존 신청 초안과 MVP 근거가 이미 있어 새 산출물을 처음부터 만드는 비용이 작다. 고객 인터뷰와 파트너 아웃리치는 기한이 없고 신청서의 고객검증 근거로도 이어서 활용할 수 있으므로, 먼저 적격성을 판정하고 9월 14~15일 제출 가능한 상태로 전환하는 편이 시간가치가 높다.

단, 이 추천은 **조건부 Go**다. 1차 모두의 창업 수행 상태 또는 다른 제외사유가 확인되면 즉시 No-Go로 바꾸고, 같은 주의 실행 우선순위를 한국프롭테크포럼 인터뷰 연결 요청으로 전환한다.

## 선택 근거

1. **마감 회수 가능성:** 세 후보 중 유일하게 놓치면 회수할 수 없는 기한이 있다.
2. **준비비용:** `docs/business-development/20260901_modoo_startup_2nd_application_package.md`에 제출 문안과 체크리스트가 이미 있다.
3. **자원 레버리지:** 선정 시 고객검증, 합성 테스트셋, 보안·법률 점검을 위한 외부 자원을 확보할 수 있다.
4. **학습과의 결합:** 신청서의 12주 계획이 현재 고객검증 패키지 및 아웃리치 초안과 직접 연결된다.
5. **손실 통제:** 적격성 핵심 질문에서 탈락하면 제출 작업을 즉시 멈추고 준비된 아웃리치로 전환할 수 있다.

## 보드가 지금 답할 최소 질문

민감한 원문이나 상세 개인정보는 Paperclip 또는 Git에 남기지 않고 아래 결과만 공유한다.

1. 1차 모두의 창업 최종 상태가 `2R 통과 후 수행 중` 또는 `정당한 사유 없는 중도포기`에 해당하는가? (`아니오 / 예 / 운영기관 확인 필요`)
2. 2026-08-20 기준 대표자 명의 사업자등록 상태는 무엇인가? (`없음 / 있음`)
3. 2026년 중기부 창업사업화 지원사업을 현재 수행 중인가? (`아니오 / 예`)
4. 채무불이행, 세금체납, 환수금, 참여제한, 체불명단, 보조금 배제, 사업비 계좌 개설 불가 중 해당 항목이 있는가? (`모두 없음 / 있음`)

위 네 질문이 모두 제출 가능 방향이면 나머지 대표 구성·지역·멘토기관·특허 공개범위를 제출 전 체크리스트에서 확정한다. 1번이 `운영기관 확인 필요`이면 제출 준비는 유지하되 공식 회신 전 제출하지 않는다.

## 승인 후 즉시 실행 초안

- 서비스명: `입주해(Rentme) — 근거 기반 주거 신뢰와 설명 가능한 임대 매칭 서비스`
- 신청 트랙: `일반/기술트랙`
- 신청자 유형: 2026-08-20 기준 사업자 상태 확인 후 `예비창업자` 또는 `기창업자` 선택

### 붙여넣기용 핵심 문안

**아이디어 한 줄 소개**

> 임차인·임대인·주택의 확인 근거와 조건을 구조화해 적합 사유와 계약 전 다음 행동을 설명하는 AI 기반 주거 신뢰·임대 매칭 서비스

**문제와 해결 요약**

> 전월세 거래의 확인 정보는 여러 문서와 기관에 흩어져 있어 확인 누락, 반복 문의, 의사결정 지연이 발생합니다. 입주해는 임차인의 조건과 매물 조건을 비교해 적합·불충족 사유를 설명하고, 당사자와 주택별 자료의 출처·기준일·공개단계를 기록해 계약 전 다음 행동을 안내합니다. 안전·신용·계약 성사를 보장하지 않고 확인된 정보와 미확인 정보를 분리해 사용자의 판단을 돕습니다.

전체 폼 입력 원문, 1페이지 사업 요약, 12주 계획, 증빙 목록은 `docs/business-development/20260901_modoo_startup_2nd_application_package.md`를 사용한다.

- 1차 `2R 통과 후 수행 중` 또는 정당한 사유 없는 중도포기가 확인되면 신청하지 않는다.
- 다른 제외사유가 마감 전에 해소되지 않으면 신청하지 않는다.
- No-Go 당일 `docs/outreach/20260831_outreach_draft.md`의 한국프롭테크포럼 이메일을 1순위 실행안으로 전환한다.
