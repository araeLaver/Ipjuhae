## 1. 적격성 판정

공고의 핵심 신청 자격은 단순한 예비창업자·초기기업·업력 조건이 아니라 **2023~2026년 초기창업패키지 선정기업**이다. 선정확인서는 K-Startup에서 발급해야 하며, 소속 주관기관이 최종 협약기업으로 확인하지 않으면 제외될 수 있다. 저장소와 기존 내부 자료에는 입주해 또는 대표자의 해당 기간 초기창업패키지 선정·협약 증명이 없다. 따라서 현재 상태에서 신청서를 준비하거나 제출해서는 안 된다.

| 확인 항목 | 공고 기준 | 입주해 현재값 | 판정 |
|---|---|---|---|
| 예비창업자 | 예비창업자라는 지위만으로는 신청 불가 | 사업자 상태 미확인 | 판정에 영향 없음 |
| 사업자등록 | 사업자등록증 필수 제출 | 법적 사업자명·등록증 미확인 | 미충족 |
| 업력 | 별도 일반 업력만으로 대체 불가 | 개업·설립일 미확인 | 보조 확인값 |
| 초기창업패키지 | 2023~2026년 선정기업, 선정확인서 및 주관기관 확인 필요 | 선정·협약 증명 없음 | **핵심 미충족** |
| 중복수혜 | 공고문에 일반적인 중복수혜 금지 조항은 별도 명시되지 않음 | 해당 없음 | 제한 근거 없음. 다만 기존 협약 의무는 별도 확인 |
| 제외 업종 | 유흥·사행 등 `중소기업창업 지원법 시행령`상 제외 업종 불가 | 입주해는 주거 정보·매칭 SaaS | 해당 가능성 낮음 |
| 채무·체납 | 금융 채무불이행 규제, 국세·지방세 체납 시 원칙적 제외 | 미확인 | 확인 필요 |

## 2. 협업 제안 요약 — 초기창업패키지 자격 확인 시 사용

### 입주해 × NAVER Cloud: 임대차 자료의 확인 상태와 다음 행동을 설명하는 AI 보조 흐름

전월세 탐색과 계약 전 단계에서는 임차인·임대인·주택 자료가 여러 문서와 채널에 흩어져 반복 확인과 누락이 발생한다. 입주해는 자료의 출처·기준일·공개 범위와 `확인됨 / 자료 없음 / 추가 검토 필요` 상태를 구조화하고, 매칭 조건의 적합·불충족 사유와 다음 행동을 설명하는 주거 의사결정 보조 서비스다. 안전·신용·계약 성사를 보장하거나 공인중개행위를 대체하지 않는다.

NAVER Cloud와는 **사용자 동의를 받은 합성·비식별 자료를 대상으로 한 문서 이해 및 확인 항목 추천 PoC**를 제안한다. `CLOVA OCR`로 허용된 문서의 텍스트를 추출하고, `CLOVA Studio`로 누락 항목과 다음 질문의 초안을 생성한다. 원본과 추출 결과는 분리하고, 결과마다 근거 위치·모델 생성 여부·사람의 확인 상태를 표시한다. 초기에는 실제 계약서, 신분증, 주민등록번호, 계좌·신용정보를 받지 않는다.

### 8주 PoC 범위

| 주차 | 실행 범위 | 완료 기준 |
|---|---|---|
| 1 | 현업 인터뷰와 문서·필드 범위 확정, 금지정보 정의 | 2개 사용자군, 3개 문서유형 이하, 데이터 처리표 승인 |
| 2 | 합성 문서 50건 및 정답셋 작성 | 필드별 정답·누락·모호 케이스 라벨 완료 |
| 3~4 | `CLOVA OCR` 추출, 근거 좌표와 상태 저장 | 핵심 필드 추출 정확도 측정 가능 |
| 5 | `CLOVA Studio` 기반 누락·다음 질문 초안 | 생성 문구에 근거·면책·사람 검토 상태 표시 |
| 6 | 입주해 확인 대시보드에 제한 연동 | 합성 데이터 end-to-end demo 통과 |
| 7 | 임차인·중개 실무자 5~10명 opt-in 사용성 검증 | 과업 완료시간·오류·신뢰도 기록 |
| 8 | 결과 분석과 Go/No-Go, 개인정보 영향 재검토 | 지표 보고서와 상용화 전 보완목록 제출 |

### 성공 지표와 경계

- 핵심 필드 OCR 정확도 90% 이상, 누락 탐지 재현율 85% 이상을 탐색 목표로 둔다.
- 수기 확인 대비 문서 분류·확인시간 30% 단축, 사용성 테스트 과업 완료율 80% 이상을 목표로 한다.
- AI 결과는 자동 승인·신용평가·위험보증에 사용하지 않으며 사람 검토 전 `초안`으로 표시한다.
- PoC 중 실제 개인정보 연동, 외부 자동조회, 계약 체결·중개, 고객 대상 자동 발송은 범위에서 제외한다.
