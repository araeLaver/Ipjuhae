## 2. 기업 및 제품 소개

### 한 줄 소개

입주해(Rentme)는 임차인이 예산, 선호 지역, 입주 시기와 생활 조건을 프로필로 만들고, 임대 매물과의 적합도를 설명 가능한 기준으로 비교하는 역방향 임대 매칭 제품이다.

### 해결하려는 문제

기존 임대 플랫폼에서는 임차인이 여러 매물을 반복 검색하고, 임대 운영자는 후보자의 조건을 일관된 기준으로 검토하기 어렵다. 특히 국가와 운영사마다 입력 양식과 검토 절차가 다르면 누락 확인과 후보 정렬에 시간이 들고, 과도한 개인정보 공유 위험도 커진다.

### 현재 구현 범위

- 임차인 프로필 생성·수정: 예산, 선호 지역, 입주일, 반려동물 여부, 직장 정보
- 임대 매물 등록과 후보 매칭
- 예산, 신용/신뢰 입력값, 입주일, 생활조건, 고용 조건별 점수와 사유 표시
- 조건 불충족 항목을 `dealbreakers`로 분리
- 임대인 후보 검색과 매칭 이후 대화 시작 흐름

제품은 Next.js와 TypeScript 기반 MVP다. 저장소의 자동화 테스트와 smoke 시나리오는 구현 동작의 근거로 사용할 수 있으나, 실제 사용자·고객·매출 성과를 의미하지 않는다.

## 3. 베트남 협업 제안

### 우선 수요기업: FPT

**제안명**  
Privacy-conscious tenant profile and explainable reverse matching workflow for Vietnamese rental operators

**협업 가설**  
베트남 임대운영사 또는 부동산 플랫폼이 사용하는 후보 검토 절차에 입주해의 구조화된 tenant profile과 설명 가능한 matching 결과를 결합하면, 민감한 원본자료를 수요기업에 직접 전달하지 않고도 초기 검토의 누락과 소요시간을 줄일 수 있다.

공식 공고는 수요기업을 FPT 및 Sunwah Group으로 안내하지만 세부 수요과제는 공개 본문에서 확인되지 않았다. 따라서 FPT가 부동산·임대 운영 workflow 또는 관련 고객 접점을 확인해 주는 것을 PoC 착수 조건으로 둔다.

### 4주 PoC 범위

| 주차 | 활동 | 산출물 |
|---|---|---|
| 1주차 | 현업 인터뷰, 현재 검토 흐름·필수 필드·금지 데이터 정의 | 현행 workflow 및 data boundary |
| 2주차 | 합성 tenant profile·매물 각 30건 현지화, 평가 기준 합의 | 합성 테스트셋과 기준표 |
| 3주차 | matching 실행, 운영자 검토, 오류·누락 사례 분류 | 결과 dashboard 또는 CSV, issue log |
| 4주차 | 기준선 비교, 규제·제품화 gap 정리, 후속 Go/No-Go | 결과보고서와 다음 단계 제안 |

### 검증 지표

- 운영자 1인이 후보 1건을 검토하는 중앙값 시간: 기존 절차 대비 변화
- 운영자 판단과 제안 순위의 Top-N 일치율
- 필수 입력 누락 탐지율
- 결과 사유를 이해하고 재검토할 수 있다고 답한 운영자 비율
- 개인정보·현지 규제 검토에서 발견된 차단 이슈 수와 해소 가능 여부

목표치는 FPT 현업의 기준선 확인 후 공동 합의한다. 현재 단계에서는 개선률을 약속하지 않는다.

### 데이터 및 규제 경계

- 합성·비식별 데이터만 사용한다.
- 실제 신용정보, 주민·여권번호, 계좌·결제정보를 수집하거나 연동하지 않는다.
- 자동 계약, 신용평가, 금융·보험 판단, 법률판단을 수행하지 않는다.
- 베트남 개인정보·부동산 중개 규제는 현지 전문가 또는 파트너 검토 후 확장한다.
- matching 결과는 운영자의 검토 보조이며 최종 의사결정을 대체하지 않는다.

## 4. 기대효과

## 7. 신청 동기와 프로그램 활용계획

입주해는 현재 구현된 tenant profile과 matching MVP를 국내 소비자용 서비스 서사에만 두지 않고, 베트남 임대운영 현업의 반복 검토 절차에 적용할 수 있는지 검증하려 한다. 서울창업허브M+의 시장분석과 수요기업 연계를 활용해 고객 문제, 현지 필수 데이터, 규제 경계, 구매 주체를 먼저 확인하고, 합성 데이터 기반 4주 PoC로 후속 사업화 여부를 판단한다. 선정 지원금은 허용 범위 안에서 현지화, 합성 테스트셋 구성, 통역·현업 검증, 결과 정리에 우선 사용한다.
