# 2026년 2차 Pre-TIPS 입주해 자격 갭 분석

- 기준일: 2026-08-02
- 신청기간: 2026-07-10 ~ 2026-08-10
- 판정: **이번 차수 No-Go**
- 외부 신청: 보드의 명시적 승인 전 보류

## 결론

입주해(Rentme)는 기술·사업 아이템 측면에서는 Pre-TIPS 사업화 자금의 활용처를 설명할 수 있다. 그러나 신청의 전제인 기업 실체, 비수도권 소재, 창업 3년 이내, 최근 2년 내 인정 투자기관의 1천만원 이상 투자 유치가 현재 저장소 자료로 입증되지 않는다.

특히 투자 요건은 단순 이전이나 주소 변경으로 보완할 수 없는 선행 요건이다. 2026-08-10 마감 전에 투자계약, 신주 인수, 입금, 등기까지 사실과 증빙이 이미 갖춰져 있지 않다면 이번 차수 신청은 불가능하다. 따라서 확인되지 않은 값을 추정해 신청서를 만드는 대신 이번 차수는 No-Go로 판정하고 다음 차수 준비 트랙으로 전환한다.

## 공식 공고 핵심 요건

- 「중소기업기본법」상 중소기업의 대표자이며 「중소기업창업 지원법」상 창업기업 대표자일 것
- 모집공고일 기준 창업 3년 이내일 것
  - 신청 가능 창업일 범위: 2023-07-10 ~ 2026-07-10
  - 법인은 법인등기사항전부증명서의 회사설립연월일 기준
  - 법인사업자는 사업 개시와 사업자등록을 완료해야 함
- 공고 마감일 기준 본점이 비수도권에 소재할 것
- 공고 마감일로부터 최근 2년(2024-08-10 ~ 2026-08-10) 내 인정 투자기관으로부터 총 1천만원 이상 투자를 받았을 것
- 공동·각자대표인 경우 대표자 전원이 신청자격을 충족하고 신청 제외 사유에 해당하지 않을 것
- 다수의 개인·법인 사업자를 보유한 경우 창업여부 기준표에 따른 관계기업·동종업종 창업 판정을 통과할 것
- 2026년도 중앙정부·공공기관 창업사업화 지원사업과 협약기간이 중복되지 않을 것
- 총사업비의 30% 이상을 자기부담해야 하며, 현금 10% 이상과 현물 20% 이하 구조를 감당할 수 있을 것

지원 내용은 사업화 자금 평균 9천만원, 최대 1억원과 후속 투자유치·역량 강화 프로그램이며 협약기간은 8개월 이내다.

## Go/No-Go 판정 규칙

이번 차수의 Go는 아래 네 가지가 모두 원본으로 확인될 때만 가능하다.

1. 확정된 신청 사업자의 창업일이 2023-07-10 이후다.
2. 2026-08-10 기준 본점이 비수도권이며 주소만 빌린 형태가 아니라 실제 사업 운영 근거가 있다.
3. 2024-08-10 이후 인정 투자기관의 인정 가능한 투자 1천만원 이상이 이미 집행됐고 계약·입금·주주·등기 증빙이 일치한다.
4. 기존 수혜 및 2026년 창업사업화 협약 중복 등 신청 제외 사유가 없다.

현재는 네 항목 모두 원본 확인이 되지 않았고 투자 요건은 미충족으로 간주해야 하므로 **No-Go**다. 8월 10일 전에 단순 본점 이전만 하는 것은 투자 요건을 해결하지 못하며, 지원사업만을 위한 형식적 이전은 실재성·사후관리 리스크가 커 권장하지 않는다.

## 다음 차수 대비 액션

### P0 — 2026-08-04까지 사실 확정

1. 대표자가 신청 주체의 사업자등록증과 최근 발급 법인등기사항전부증명서를 확인한다.
2. 모든 투자계약·입금·주주명부·증자등기를 모아 `투자일 / 투자자 / 기관유형 / 금액 / 신주 여부 / 증빙` 원장으로 만든다.
3. K-Startup에서 기존 Pre-TIPS/TIPS 및 2026년 창업사업화 협약 이력을 내려받는다.
4. 투자 증빙이 실제로 존재하는 경우에만 로우파트너스 또는 창업진흥원에 투자 인정 여부를 서면 질의한다.

### P1 — 다음 모집 전 구조 보완

1. 투자 요건이 없다면 인정 투자기관과의 투자유치 트랙을 먼저 진행한다. 지원사업 마감을 이유로 소급 계약이나 형식적 입금을 만들지 않는다.
2. 비수도권 거점이 사업상 타당한 경우 고객개발, 채용, 운영비와 함께 실제 이전 계획을 세우고 등기·사업자등록·임대차·근무 증빙을 일치시킨다.
3. 주식회사 다운랩, 주식회사 프린도, 개인/예비창업자 문서가 혼재한 상태를 정리하고 제품·특허·계약·지원사업의 권리주체를 하나로 확정한다.
4. 자기부담금과 8개월 실행예산을 별도로 확보한다.

### P2 — 신청서 준비

1. 문제: 임차인과 임대인 간 정보 비대칭, 개인정보 과다 제출, 계약 전 신뢰 판단 비용.
2. 해결: 동의 기반 자료 검증, 선택 공개, 양방향 레퍼런스, 주택·계약 전 확인 리포트.
3. 8개월 KPI: 검증된 베타 사용자, 리포트 생성·공유, 매칭 전환, 유료 의향, 개인정보 최소수집 및 동의 로그.
4. 자금: 제품 검증, 보안·법무, 지식재산권, 고객 획득 실험 중심으로 배분하고 대표자가 승인한 실제 수치만 사용한다.
