## flyctl 없이 운영 비밀을 넣는 길

키를 받았는데 `flyctl` 토큰이 만료돼 있었다. `flyctl auth login`은 브라우저 인증이라
비대화형 셸에서 안 된다. 대표님께 두 줄을 부탁드렸지만 `!` 셸도 비대화형이라
같은 오류가 났다.

**Actions에는 이미 `FLY_API_TOKEN`이 있다.** 그 경로를 썼다.

1. `gh secret set PUBLIC_DATA_API_KEY` — 저장소 비밀로 넣는다
2. `.github/workflows/fly-sync-secret.yml` — 비밀을 Fly로 옮기는 workflow_dispatch
3. 실행

값은 로그에 찍히지 않는다. 이름만 입력받고 값은 `secrets`에서 읽으며,
허용 목록에 없는 이름은 거부한다. **앞으로 다른 비밀도 이 경로로 넣을 수 있다.**

## 추측으로 짠 코드는 전부 틀렸다

키가 오기 전에 정책뉴스 연동을 미리 짜뒀는데, 실제로 호출해보니 하나도 안 맞았다.

| 내가 짠 것 | 실제 |
| --- | --- |
| `policyNewsList` | `policyNewsList2` |
| JSON | XML |
| 날짜 없이 조회 | `startDate`/`endDate` 필수, **최대 3일** |
| 일반 날짜 | `MM/DD/YYYY` 미국식 |
| `URLSearchParams`에 키 | 키가 **이미 URL 인코딩**돼 있어 이중 인코딩으로 인증 실패 |

부딪혀보지 않았으면 전부 조용히 실패했을 것이다. 응답 필드가 문서에 없는 API는
미리 짜두는 의미가 없다.

## 정책뉴스 다듬기

- 제목에 `&middot;`, 부제에 `<br>`이 섞여 온다. 본문뿐 아니라 제목·부제에도 정제를 건다
- **본문까지 훑으니 "2027년 예산" 기사가 걸렸다.** 본문에 '월세'가 한 번 나왔을 뿐이다.
  기사의 주제는 제목에 있다 — 제목과 부제로만 판단한다
- **농지 임대차**는 '임대차'가 들어 있어도 집 이야기가 아니다. 제외어를 뒀다
- 15개 구간을 병렬로 던졌더니 5개가 끊겼다. 순차로 부르고 목표 건수를 채우면 멈춘다
- 21일로는 2건뿐이었다. 정책 발표는 매일 나오지 않는다. 45일로 넓혔다

출처표시를 화면에 넣었다. 공공누리 제1유형이라 장식이 아니라 이용 조건이다.

## 실거래가 — 시세를 찾아 올 필요가 없어졌다

`/check`의 가장 큰 마찰이 "매매 시세를 네이버에서 찾아 와야 한다"는 것이었다.

```
주소로 지역 찾기 → 단지 이름 → 실제 거래 목록 → 누르면 시세 칸 채워짐
```

**우리가 시세를 정해 주지 않는다.** 국토부에 신고된 거래를 늘어놓고
면적·층·날짜·준공년도를 다 보여준 뒤 사용자가 고른다. 하나만 골라
"시세입니다"라고 말하는 순간 그건 추정이 된다. 그 구분이 이 제품의 전제다.

**법정동코드 문제는 없었다.** 다음 우편번호 API가 주는 `bcode` 앞 5자리가
그대로 조회 코드다. 코드표를 들고 다닐 필요가 없었다.

검증: 강남구 "래미안" 150건. 프로덕션에서도 같은 값이 나온다.

## 같은 실수를 세 번 했다

`git add -A`로 **남의 작업을 함께 커밋**했다. 이 워크트리는 여러 에이전트가 동시에 쓴다.

1. 루트의 임시 `.py`/`.json` 100여 개
2. 그걸 치우며 규칙을 넓게 잡아 **`.eslintrc.json`이 추적에서 빠짐** → CI lint 정지
3. `.paperclip-scratch/`와 **다른 에이전트가 편집 중이던 `e2e/onboarding.spec.ts`**
   → `await` 누락으로 Type Check 정지

세 번째에서 하나 배웠다. `properties` 테스트가 깨져 보여서 내 탓인 줄 알았는데,
`git stash`로 기준선을 확인하니 **워크트리에 섞인 남의 편집** 때문이었다.
내 변경 탓이라고 단정했으면 엉뚱한 곳을 팠다.

기억에 적었다. **커밋 전에 `git status`를 보고 내 파일만 이름으로 지정한다.**
