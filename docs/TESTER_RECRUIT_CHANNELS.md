## 1. Testers Community 앱 — 여기부터

```
https://play.google.com/store/apps/details?id=com.testerscommunity
```

`12 Testers - Testers Community` / Duho Corp / 5만+ 다운로드 / 평점 4.3 (리뷰 27개)

**개발자끼리 서로 테스트해주는 앱이다.** 남의 앱을 깔고 열어주면 크레딧이 쌓이고,
그 크레딧으로 내 앱 링크를 올린다.

2.0의 **Packs** 방식이 핵심이다.

- 개발자 **16명**이 한 팩이 되어 **16일** 동안 서로의 앱을 매일 연다
- 12명 14일 요건보다 여유가 있다
- **3일 연속 안 열면 팩에서 퇴출된다.** 이게 있어서 중간 이탈이 적다

구글이 보는 건 설치 숫자가 아니라 **꾸준히 열었는지**다. 그래서 이 방식이 맞는다.

**대신 대표님도 15개 앱을 매일 열어야 한다.** 16일 동안. 그게 비용이다.

하실 일

1. 안드로이드 폰에 위 앱 설치
2. 가입 후 다른 앱들을 테스트해 크레딧 확보
3. 입주해의 **비공개 테스트 링크**를 등록
4. Pack에 들어가 16일 진행
