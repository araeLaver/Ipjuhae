# 어디에 무슨 글을 올릴 것인가

확정판. 문안 원본은 `docs/TESTER_RECRUIT.md`, 일자별 목표는 `docs/TESTER_RECRUIT_PLAN.md`.
이 파일은 **오늘 당장 어디에 무엇을 올리는지**만 적는다.

## 먼저 — 내가 확인한 것과 확인 못 한 것

확인한 것

- 비공개 테스트 트랙이 **활성**이고 참여 링크가 지금 작동한다
- 콘솔의 현재 참여자 수는 **1명**이다
- 크몽에 "비공개 테스트 12~20명 설치지원" 상품이 실제로 판매 중이다
- OKKY에 같은 주제의 개발자 글이 있다

확인 못 한 것

- **특정 네이버 카페 이름과 게시 허용 여부.** 검색으로 확정되지 않았다.
  카페는 대부분 가입 등급 제한이 있고 홍보성 글을 삭제한다. 이름을 지어내지 않는다
- 특정 텔레그램·디스코드 교환방, 특정 서브레딧 이름. 존재한다는 일반적 언급은 있으나
  구체적 방 이름을 확인하지 못했다

그래서 아래 순서는 **문지기가 없는 채널부터** 간다. 승인을 기다리는 채널은 뒤로 뺐다.

## 1. 카카오톡 지인 — 오늘 바로

**가장 먼저, 가장 많이 여기서 나온다.** 단체방에 한 번 던지지 말고 **개별로** 보낸다.
단체방은 아무도 자기 일이라고 생각하지 않는다.

보낼 문안은 `TESTER_RECRUIT.md`의 **C**.

보내기 전에 걸러야 할 것

- 아이폰만 쓰는 사람은 참여가 안 된다. 보내지 않는다
- 안드로이드 + 구글 계정 로그인 상태여야 한다

보낸 뒤 **안내문**(TESTER_RECRUIT.md 하단)을 한 번 더 보낸다. 링크만 던지면 절반이 끊긴다.

## 2. 카카오 오픈채팅 — 부동산·자취

카카오톡 앱에서 오픈채팅 검색으로 바로 들어간다. **네이버 카페와 달리 등급 제한이 없다.**

검색어

```
전세          자취          부동산 정보
1인가구        이사          청년 주거
```

**들어가자마자 링크를 던지지 않는다.** 방마다 홍보 금지 규칙이 있고, 어기면 바로 강퇴다.

1. 들어가서 공지와 최근 대화를 먼저 본다
2. 홍보 금지면 방장에게 먼저 묻는다
3. 허용되면 문안 **B**를 올린다

B는 광고가 아니라 도움 제안으로 읽히게 썼다. `/check` 웹 링크를 먼저 두어
앱 설치 없이도 확인할 수 있게 한 것이 그 이유다.

## 3. 카카오 오픈채팅 — 안드로이드 개발

검색어

```
안드로이드 개발      앱 개발       플레이스토어
비공개 테스트        인디 개발자
```

여기는 **같은 처지**라 사정을 설명할 필요가 없다. 문안 **A**.

주의. A는 "수용 가능 인원을 확인한 뒤 개별 확정"으로 써 있다.
**무제한으로 받아주겠다고 약속하지 않는다.** 상대 앱도 14일을 유지해야 하고,
실기기와 계정이 그만큼 필요하다. 감당할 수 있는 수만 확약한다.

## 4. 개발자 게시판

- OKKY (https://okky.kr) — 같은 주제 글이 실재한다
- 그 외 이용 중인 개발자 커뮤니티

문안 **A**.

## 5. 본인 SNS 3채널

인스타·스레드·X. 프로필 문구와 UTM 링크는 이미 `/check`로 바꿔뒀다
(`marketing/sns/posts/00-profiles.md`).

**팔로워가 없어 지금 도달은 거의 없다.** 그래도 올린다. 이유 두 가지.

1. 프로필에 글이 0건이면 링크를 타고 온 사람이 신뢰하지 않는다
2. 구글 프로덕션 신청서에 "어떻게 모았나"를 쓸 때 근거가 된다

문안 **B**를 채널 길이에 맞춰 줄여 쓴다.

## 6. 네이버 카페 — 확인 후에만

카페는 대부분 **가입 즉시 글쓰기가 안 된다.** 등급을 올려야 하고,
홍보성 글은 규칙으로 금지된 곳이 많다. 삭제되면 시간만 버린다.

올리기 전에 반드시 확인할 것

- 가입 등급 조건과 현재 내 등급
- 홍보·외부링크 규칙
- 비슷한 글이 남아 있는지 (삭제됐으면 이 카페는 안 된다)

통과한 곳에만 문안 **B**.

## 7. 크몽 유료 — 마지막

부족분만. 자력으로 9명 미만일 때만 검토한다.

문제는 돈이 아니라 **프로덕션 신청서**다. 구글이 "테스터를 어떻게 모았고
어떤 피드백을 받았는지"를 서술형으로 묻는다. 숫자만 채우고 실사용이 없으면
거절될 수 있고, 거절되면 보완해서 다시 신청하는 동안 참여를 푼 사람이 생긴다.

그래서 1~4번으로 먼저 채우고, 모자란 인원만 메운다.

## 두 링크를 헷갈리면 안 된다

```
써야 하는 것 (12명에 카운트)
https://play.google.com/apps/testing/com.ipjuhae.app

쓰면 안 되는 것 (카운트 안 됨)
https://play.google.com/apps/internaltest/4701706480338113732
```

두 번째를 보내면 그 사람은 설치해도 **숫자가 안 올라간다.**
복붙할 때마다 `apps/testing`인지 확인한다.
