## 추가 작업 (같은 날 2차): 서비스 미리보기 /preview

대표 지적: "서비스 미리보기(→/home)에 들어가면 메뉴가 안 보이고, 로그인 후 화면을 구경하려면 회원가입해야 한다."
- 원인: `Header`는 비로그인 시 `navLinks = []`로 메뉴를 숨기고, 메뉴 페이지들(/messages 등)은 API 401 시 /login으로 리다이렉트.
- 해결: **가입 없이 둘러보는 전용 화면 `/preview` 신설** (`components/preview/service-preview.tsx`). 로그인 후 메뉴 7종(프로필·Trust Card/인증/열람 기록/메시지/신뢰센터/거래/커뮤니티)을 실제 앱 헤더 구조 그대로 탭으로 전환하며 합성 예시 데이터로 구경. 상단에 미리보기 배너 + "사전 신청" CTA + "매물 검색 홈(/home)" 링크, 하단에 신청 CTA. noindex.
- 랜딩의 "서비스 미리보기" 진입점 2곳(헤더/푸터) `/home` → `/preview` 교체.
- 실제 페이지들을 게스트에 개방(빈 상태 노출/API 게스트 허용)하는 방안은 페이지·API 전반 수정이라 이번엔 보류 — 오픈 후 과제.
- 검증: typecheck·442테스트·build 통과, `/preview` 라우트 빌드 산출 확인, 배포 후 라이브 확인.
