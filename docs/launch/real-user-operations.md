# 실제 사용자 모집과 질문 운영

## 공개 모집문 — 게시할 때 사용할 원고

전월세 계약을 앞두고 보증금과 집값을 어떻게 비교해야 할지 막막하신가요?
입주해에서 가입 없이 보증금 위험 신호를 점검하고, 후보 집을 비교하며 계약 전 확인할 항목을 정리해 보세요.

바로 이용: https://www.ipjuhae.com/check?from=friend
질문 남기기: https://www.ipjuhae.com/community#ask
휴대폰 홈 화면에 추가: https://www.ipjuhae.com/install

계산 결과는 입력값에 따른 참고 정보이며 안전이나 보증 가입을 확정하지 않습니다.
질문에는 주소, 연락처, 계약서 원본 등 개인정보를 올리지 마세요.
사용 중 막힌 점이나 필요한 기능을 질문 게시판에 남겨 주세요.

## 운영자가 매일 처리할 일

1. 관리자 계정으로 `/admin/community`에서 오래된 답변 대기 질문부터 확인한다.
2. 질문 내용에 개인정보가 있으면 기존 관리 기능으로 숨김·정리한다.
3. 질문 상세 화면에서 운영자 계정으로 답변한다. 공개 상태의 운영자 댓글이 있어야 답변 있음으로 표시된다.
4. 답변 댓글을 숨기거나 삭제하면 대기 상태로 돌아오는지 확인한다.
5. 정책소식의 최근 수집 시각과 실패 여부를 확인한다. 화면 접속 성공만으로 수집 성공을 판단하지 않는다.
6. 관리자 활성화 지표와 실제 질문을 함께 확인한다. 방문, 점검 시작, 다음 행동, 질문, 운영자 답변을 구분한다.

담당자와 확인 시간은 운영자가 지정해야 한다. 지정 전에는 답변 시간을 약속하지 않는다.
답변은 자동으로 생성·게시하지 않는다. 답변 있음 표시는 문제 해결이나 법률 검토 완료를 의미하지 않는다.

## 첫 모집 실행과 기록

- 대상: 현재 집을 찾거나 계약을 앞둔 사람. 실제 이용 대상자에게 위 원고와 링크를 안내한다.
- 채널: 운영자가 허용한 지인·기존 커뮤니티·자체 채널. 수신자와 게시 위치가 정해지기 전에는 외부 발송하지 않는다.
- 첫 목표: 실제 대상자 10명의 점검 이용과 막힌 점 수집. 목표치이며 현재 이용자 수가 아니다.
- 기록: 안내 날짜, 채널, 안내 인원, 점검 시작·다음 행동 수, 신규 질문 수, 미답변 수, 반복 문제.
- 다음 회차: 이용이 막힌 지점을 수정한 뒤 동일 사용자에게 다시 확인을 요청한다.

구현 전 공개 게시판 조회에서는 운영 글 18건, 사용자 질문 0건이었다. 방문·가입 수는 이 조회로 알 수 없다.
이 문서는 모집 준비물이다. 외부 게시·발송이나 실제 사용자 확보 실적을 의미하지 않는다.

## 사용자에게 제공되는 재방문 경로

질문 등록 후 링크가 같은 브라우저에 최대 20개 저장된다. `/community#follow-up`에서 답변 상태를 확인한다.
기기 목록을 지워도 서버의 질문·댓글은 삭제되지 않는다. 역할 제한 질문은 적절한 계정으로 로그인해야 조회된다.
보증금 점검 공유 버튼은 공개 진입 링크만 복사하며 입력 금액과 저장 후보를 포함하지 않는다.
웹 이용은 즉시 가능하다. Google Play 테스트 참여와 스토어 정식 출시는 별개이며 정식 출시를 주장하지 않는다.
