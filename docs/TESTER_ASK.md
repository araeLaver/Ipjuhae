# 테스터 부탁 문구 — 복붙용

링크는 하나만 씁니다.

```
https://www.ipjuhae.com/tester
```

이 주소를 열면 설명과 참여 버튼이 한 화면에 있습니다. 구글 링크를 직접 보내지
마세요. 그 화면은 맥락 없이 열리면 무엇인지 알 수 없어 그냥 닫힙니다.

## 다시 확인한 사실 — 부탁이 생각보다 가볍다

Play Console 문구는 `12명 이상의 테스터가 비공개 테스트 **참여를 선택**` 입니다.
**카운터가 세는 것은 옵트인입니다.** 링크를 열고 「테스터 되기」를 누르면
그 순간 숫자가 올라갑니다.

설치와 실사용은 별개로 필요합니다 — 구글이 승인 심사에서 참여가 실제로
있었는지 보기 때문입니다. 다만 **부탁할 때는 "버튼 한 번"으로 말하는 편이 낫습니다.**
"설치하고 2주 써주세요"라고 하면 그 무게 때문에 첫 버튼마저 안 누릅니다.

## 지금 상태

| 목록에 등록된 사람 | 6명 |

**이메일이 없어서 막힌 게 아닙니다.** 5명이 링크를 누르지 않았습니다.
새 사람을 찾기 전에 이미 등록된 분들께 먼저 보내는 게 빠릅니다.

## A. 짧게 (카톡·DM)

```
전세 보증금이 안전한지 계산해주는 앱 만들었어.
정식 출시하려면 테스터 12명이 필요한데 버튼 한 번만 눌러주면 돼.

https://www.ipjuhae.com/tester

안드로이드만 돼. 개인정보 안 받고, 2주만 유지해주면 끝이야.
```

## B. 오픈채팅·커뮤니티

```
전세 계약 전에 보증금 안전한지 확인하는 앱을 만들었습니다.

등기부 을구의 근저당과 시세를 넣으면 집이 경매로 넘어갔을 때
얼마가 남는지까지 계산해 줍니다. 국토교통부 실거래가를 붙여서
시세는 직접 안 찾으셔도 됩니다.

웹에서 먼저 보실 수 있습니다
https://www.ipjuhae.com/check

앱은 정식 출시 전이라 테스터로만 설치됩니다. 구글이 개인 개발자에게
테스터 12명을 요구해서 그 조건을 채우는 중입니다.

https://www.ipjuhae.com/tester

버튼 한 번이면 됩니다. 개인정보는 받지 않습니다.
```

## C. 개발자 상호 테스트

```
[상호 테스트] 전세 보증금 점검 앱

입주해라는 앱입니다. 등기부와 시세 숫자를 넣으면 보증금이 안전한지
계산해 줍니다. 국토부 실거래가 API를 붙여뒀습니다.

https://www.ipjuhae.com/tester

상호 테스트 합니다. 다만 무제한 당일 설치는 약속드리지 않습니다.
수용 가능 인원을 확인한 뒤 개별로 확정해 드리고, 확정된 건은
설치일부터 14일 유지합니다. 링크 남겨주시면 회신드리겠습니다.
```

## D. 이미 목록에 있는 분께 (가장 먼저 보낼 것)

```
전에 테스터로 등록해 두었던 건이 있는데, 아직 참여 버튼을 누르지
않으신 것 같습니다. 이것만 눌러주시면 됩니다.

https://www.ipjuhae.com/tester

버튼 한 번이고, 개인정보는 받지 않습니다.
안 되시면 말씀만 주셔도 괜찮습니다.
```

## 보내고 나서

참여자 수는 Play Console 대시보드에서 봅니다.

```
프로덕션 액세스 → 현재 참여를 선택한 테스터 N명
```

누른 사람만 올라갑니다. 보낸 사람 수가 아니라 이 숫자가 실적입니다.

12번째가 들어온 날부터 14일입니다. 한 명이 중간에 해제하면 그분의 기간만
새로 시작하고 나머지는 유지됩니다 — 그래서 12명 턱걸이가 아니라 여유를 둡니다.
