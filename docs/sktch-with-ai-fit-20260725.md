# SKTCH with AI Rentme 신청 적합성 판정

작성일: 2026-07-25  
대상: Rentme(입주해)  
결론: **Conditional Go — 2026-08-04까지 보드 확인값이 모두 긍정일 때만 신청서 작성으로 전환**

## 1. 판정 요약

Rentme는 `자유 제안` 또는 `Full-Stack AI의 AI Agent & 서비스` 분야로 지원할 수 있다. 공공데이터를 바탕으로 임대 거래·지역·생활권 정보를 설명하고, 사용자가 동의한 범위에서만 정보를 반영하는 `주거 설명 AI 및 신뢰 리포트 workflow`는 공모의 AI 서비스 범위와 SK텔레콤의 B2C 고객 접점·B2B/B2G AI 협업 방향에 연결할 수 있다.

다만 공식 공고의 최소 요건인 **2인 이상 스타트업** 여부와 2026-11-02부터 약 6개월간 프로그램에 실제 참여할 담당자, 신청 주체, 공개 가능한 자료 범위가 보드에서 확인되지 않았다. 따라서 현재는 제출 Go가 아니라 **조건부 Go**다. 아래 필수 확인값 중 하나라도 충족하지 못하면 이번 회차는 No-Go로 전환한다.

## 2. 공식 공고 확인 결과

- 모집기간: 2026-07-21 ~ 2026-08-18
- 참가대상: 2인 이상의 스타트업
- 공모분야:
  - Full-Stack AI의 서비스와 기술: AI DC Infra & Solution, AI 모델, AI Agent & 서비스, 제조 AI 등
  - 통신서비스를 위한 AI 서비스와 기술: 고객 친화 상품 재설계, 앱·웹·매장·고객센터 혁신, Autonomous Network, B2B/B2G AI 협업 Solution
  - 자유 제안: AI 관련 혁신 서비스와 기술
- 프로그램기간: 2026-11-02부터 약 6개월
- 심사: 1차 서류 평가 → 2차 동영상 PT → 3차 인터뷰, 최종 발표 예정일 2026-10-30
- 선정기준: 기술·서비스 우수성, SKT 협업 가능성, 성장성, 팀의 열정과 역량
- 혜택: 전문가 멘토링·교육, 프로그램 기간 사무공간, SKT 협업·사업화, MWC·SK AI SUMMIT 등 전시, VC·유관기관 IR
- 접수: SKTCH 회원가입 후 공고 하단 `지원하기`
- 정보 제한:
  - 외부 공개 가능한 정보만 기재
  - 영업비밀·기술자료 등 민감정보 기재 금지
  - 개인정보 동의서를 제출한 인원 외 제3자 개인정보 기재 금지
  - 허위·과장 또는 타인 권리 침해 시 심사 제외·선정 취소 가능
- AI 심사역이 평가에 참여하지만 결과는 참고자료이며 최종 평가는 심사위원이 수행

공개 공고 페이지에는 로그인 후 신청 화면의 개별 질문과 첨부파일 형식·용량이 노출되지 않는다. 계정 소유자가 `지원하기` 화면에 진입한 뒤 입력항목을 캡처하거나 텍스트로 전달해야 최종 제출자료 목록을 확정할 수 있다.

## 3. Rentme 협업가설

### 권장 제안명

`공공데이터 기반 주거 설명 AI와 동의 기반 신뢰 리포트`

### 고객 문제

- 전월세 이용자는 실거래가, 지역·생활권, 매물·계약 조건을 여러 출처에서 따로 확인해야 한다.
- 임대인과 임차인은 신뢰를 확인하려고 과도한 원본 개인정보·증빙을 교환하기 쉽다.
- 기존 검색·매칭은 결과를 보여주지만, 어떤 데이터와 조건 때문에 해당 설명·추천이 나왔는지 이해하기 어렵다.

### Rentme 제안

- 전월세 실거래가, 법정동 코드, 공공임대주택, 교통·생활 인프라 등 공개 데이터를 구조화한다.
- 사용자가 선택한 조건에 따라 지역·거래·생활권을 근거와 함께 설명하는 AI 리포트를 생성한다.
- 개인 정보는 명시적 동의 범위에서 최소한으로 사용하고, 원본 증빙 자체가 아니라 검증 상태·요약 결과만 제한적으로 공유한다.
- AI 결과에는 출처, 기준시점, 불확실성, 재확인 필요 항목을 표시해 설명 가능성을 높인다.

### SKT 협업가설

1. **B2C 고객 접점**: T world 앱·웹 또는 생활 서비스 접점에서 이사·주거 탐색 고객에게 지역·생활권 설명 기능을 제공하는 PoC.
2. **B2B/B2G Solution**: 통신 기반 생활권 지표는 SKT가 적법하게 제공 가능한 집계·비식별 데이터 범위가 확인될 때만 결합해 지역 수요 설명의 정확도를 검증.
3. **AI 인프라·사업 고도화**: SKT의 AI 모델·Agent 역량과 Rentme의 주거 도메인 데이터 schema·평가 rubric을 결합해 설명 품질, 근거 충실도, hallucination 비율을 측정.

통신 데이터 사용권한이나 SKT 내부 데이터 접근을 이미 확보한 것처럼 쓰지 않는다. 이는 선발 후 협의가 필요한 **협업가설**로만 제시한다.

## 4. 신청 적합성

| 항목 | 판정 | 근거 또는 병목 |
|---|---|---|
| AI 공모분야 | 적합 | AI Agent & 서비스 또는 자유 제안으로 설명 가능 |
| SKT 협업 가능성 | 중상 | B2C 생활 접점 및 B2B/B2G 주거 설명 PoC 가설이 있으나 SKT 데이터·채널 협의는 미확정 |
| 기술·서비스 우수성 | 조건부 | 동작하는 MVP와 공공데이터 schema, 평가 결과를 공개 가능한 범위로 제시해야 함 |
| 성장성 | 적합 가능 | 전월세 정보 비대칭과 개인정보 과다교환 문제는 확장 가능한 주거 workflow로 설명 가능 |
| 2인 이상 팀 | 미확인·필수 | 대표 포함 실제 참여인원 2명 이상과 역할 증빙 필요 |
| 6개월 참여 | 미확인·필수 | 2026-11-02부터 멘토링·PT·인터뷰·프로그램 수행 가능 담당자 필요 |
| 신청 주체 | 미확인 | 팀/개인사업자/법인 중 실제 신청 명의와 대표자 확인 필요 |
| 공개 가능 자료 | 미확인 | MVP 화면, 지표, 팀 이력, IR 자료의 외부 공개 승인 필요 |

## 5. 보드 필수 확인값

1. 신청 주체: 팀, 개인사업자, 법인 중 실제 명의
2. 대표자명과 신청서에 공개 가능한 연락처·이메일
3. 대표 포함 2인 이상 실제 팀원 성명, 역할, 참여 상태
4. 2026-11-02부터 약 6개월간 프로그램 참여 가능한 대표·실무 담당자
5. 2차 동영상 PT와 3차 인터뷰 대응 가능 여부
6. SKTCH 계정 보유 여부 및 계정 소유자
7. 외부 공개 가능한 MVP URL 또는 화면, 사용자·매물·거래 데이터는 모두 mock/synthetic로 대체 가능한지
8. 공개 가능한 traction 수치, 고객 인터뷰 수, 테스트 결과가 있는지
9. 사업소개서 또는 IR 자료 첨부 허용 범위
10. 최종 제출 권한자와 제출 전 보드 승인 필요 여부

## 6. 제출자료 체크리스트

공개 공고 기준으로 먼저 준비할 자료:

- 1페이지 사업 요약: 문제, 고객, 해결방법, AI 역할, 차별점
- 팀 소개: 2인 이상 역할·경력·실행 책임
- 제품 자료: 개인정보 없는 mock 화면 또는 공개 가능한 demo
- AI 기술 메모: 입력 데이터, 처리 흐름, 근거 표시, 품질평가, human review
- SKT 협업 PoC 1페이지: 대상 고객, SKT 접점, 8~12주 실험범위, KPI
- 시장·성장성: 초기 고객가설, 확장경로, 수익모델
- 6개월 참여계획: 대표·실무 담당자, 주요 milestone
- 필요 시 사업소개서/IR 자료와 짧은 demo 동영상
- 로그인 후 신청 화면에서 확인할 항목: 공통질문 전체, 필수 첨부, 파일형식·용량, 개인정보 동의 대상자, 임시저장 가능 여부

## 7. 안전한 제출 범위

포함 가능:

- 공개 공공데이터 출처명과 sample schema
- synthetic/mock 사용자·매물·계약 event
- 비식별 화면과 집계형 테스트 지표
- 공개 가능한 기술구성도와 AI 품질평가 방식
- SKT 협업 전제와 검증할 가설

제외:

- 주민등록번호, 연락처, 주소, 소득·신용·재직 원본 등 개인정보
- 동의서를 내지 않은 고객·인터뷰 참여자·팀원의 개인정보
- 실사용자 원본 증빙, DB dump, access token, API key
- 미출원 핵심 알고리즘·영업비밀·보안 취약점
- 확보하지 않은 고객·매출·파트너십·데이터 권리를 보유한 것처럼 보이는 표현

## 8. Go/No-Go gate

- **Go 전환**: 2026-08-04까지 2인 이상 팀, 신청 주체, 6개월 참여 담당자, SKTCH 계정, 공개자료 범위, 최종 제출권한자가 모두 확인됨.
- **No-Go 전환**: 팀이 1인이거나 6개월 참여가 불가능함, 신청 주체를 확정할 수 없음, 공개 가능한 MVP·팀 자료가 없음, 또는 보드 승인 없이 개인정보·민감 기술을 제출해야만 경쟁력을 설명할 수 있음.
- **권장 일정**:
  - 08-04: 보드 확인값·신청 화면 항목 확정
  - 08-07: 1차 문안과 mock 자료 완성
  - 08-10: 동영상 PT용 3분 script·화면 초안
  - 08-12: 내부 사실성·개인정보 검토
  - 08-14: 최종 입력 및 보드 승인
  - 08-17: 제출 완료 목표. 공식 마감일 당일 제출은 피함
