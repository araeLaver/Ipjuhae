- 원칙: 외부 제출, 이메일 발송, 계정 로그인, 개인정보 입력, 파일 업로드, 결제는 보드 승인 전 실행하지 않음

## 결론

오늘은 신규 공고를 넓게 추가하기보다 2026-08-14 마감인 `공공데이터 활용기업 AI연계 맞춤형 성장 지원사업`의 비식별 신청서 골격을 먼저 만드는 것이 가장 실행 가치가 높다. 공식 공고는 공공데이터·AI 활용 기업뿐 아니라 예비창업자도 대상으로 하며, 이메일 접수 방식이다. 보드 확인이 필요한 신청 주체·대표자·연락처는 placeholder로 남기고, 제품·데이터·AI 활용 범위는 현재 저장소 근거로 작성할 수 있다.

## 우선순위 판단

### 1. 공공데이터 활용기업 AI연계 맞춤형 성장 지원사업

Rentme의 현재 제품과 가장 가까운 범위는 `전월세 실거래가·법정동·공공임대주택·교통·생활 인프라를 결합한 지역·거래·생활권 설명 AI`다. 개인 신용평가, 임차인 자동 선별, 계약 안전 보장으로 읽힐 표현은 제외한다.

- 공식 확인: 행정안전부·NIA 사업, 신청기간 2026-07-15~2026-08-14, 공공데이터·AI 활용 기업 또는 예비창업자 대상, 이메일 접수.
- 필요한 자료: 활용 공공데이터 목록, 데이터 정제·라벨링·품질관리 방식, 개인정보 없는 mock data와 sample schema, 현재 MVP 화면, 희망 지원분야 1개.
- 오늘 실행: 제품 설명, 문제정의, 공공데이터 활용 구조, AI 적용 범위, 기대성과를 먼저 작성하고 기업·대표자 정보만 보드 확인 대기로 남긴다.

### 2. 중소기업 AI훈련확산센터 참여기업 모집

Rentme에는 `매물·프로필 데이터 품질관리 workflow`를 우선 컨설팅 과제로 추천한다. 다만 지역, 사업자, 상시근로자 수 요건을 확인하기 전에는 실제 접수로 전환하지 않는다.

- 기대효과: AI 맞춤 컨설팅 비용 지원, 전담 코치, 도입 로드맵과 후속 자문.
- 필요한 자료: 사업장 소재지, 사업자등록증, 상시근로자 수, 중소기업 또는 AI 스타트업 증빙, 현재 애로와 목표 지표.
- 다음 행동: 기존 자격 확인 이슈의 보드 답변이 들어오면 공식 접수처의 잔여 예산과 접수 가능 여부를 재확인한다.

### 3. K-Startup 스타트업 원스톱 지원센터

공식 페이지는 전국 예비창업자와 창업기업 중 소상공인이 아닌 기술창업 기업을 대상으로 안내한다. 개인정보·데이터, 규제·인허가, 계약·거래, 지식재산·브랜드 상담이 Rentme의 출시 전 위험과 직접 맞는다.

- 기대효과: 동의 기반 프로필 공개, 민감정보 최소수집, 중개업·신용평가 오인 방지, 계약·면책 문구 검토.
- 필요한 자료: 1페이지 제품 소개, 실제 사용자 정보가 없는 화면, 질문 목록, 신청 주체와 계정.
- 다음 행동: 개인정보·데이터 상담을 1순위로 두고, `중개업 오인`과 `신용평가 오인`은 규제·인허가 질문으로 분리한다.

### 4. 마이데이터 전문가 상시자문

원스톱 법률지원과 중복을 줄이고 `수집 근거`, `제3자 제공`, `철회 후 처리`, `보유기간`, `검증 결과 표현`의 데이터 구조 질문에만 사용한다.

- 기대효과: 서비스의 동의·제공·철회 흐름에 대한 법·제도 및 기술 자문.
- 필요한 자료: 개인정보 없는 서비스 흐름, 데이터 항목표, 동의·철회 mock 화면, 질문 5개.
- 다음 행동: 원스톱 상담 결과 또는 범위 확인 뒤 보완 상담으로 전환한다.
