# 임대차 계약 리스크 스캔·신뢰 리포트 1주 고객검증 패키지

작성 기준일: 2026-09-01  
용도: 내부 검토 및 보드 승인 전 고객개발 준비  
경계: 실제 연락, 개인정보 수집, 유료 결제, 법률 판단은 수행하지 않는다.

## 1. 검증할 가치제안

사용자가 계약서와 공개·본인제공 자료를 바탕으로 **확인할 위험 신호, 그 근거, 다음 질문**을 짧은 리포트로 받는 서비스다. 법률적 유·무효나 거래 안전을 판정하지 않고, 계약 전 확인 누락을 줄이는 의사결정 보조 도구로 한정한다.

초기 제품 문구:

> 계약서를 대신 판단하지 않습니다. 입력 자료에서 확인이 필요한 항목과 질문을 근거와 함께 정리합니다. 최종 판단은 공인중개사·변호사·보증기관 등 적격 전문가에게 확인하세요.

## 2. 고객군별 핵심 가설과 가격 가설

| 고객군 | 가장 급한 문제 | 가치 가설 | 구매 순간 | 가격 가설 | 이번 주 판정 질문 |
|---|---|---|---|---|---|
| 임차인 | 등기·특약·보증 조건을 함께 보기 어렵고 무엇을 물어야 할지 모름 | 5분 내 위험 신호와 질문 목록을 받으면 계약 전 불안을 줄이고 확인 행동을 늘린다 | 가계약 전, 계약서 초안 수령 직후 | 기본 9,900원 / 등기·보증 체크 포함 19,900원 | 10명 중 4명 이상이 9,900원 이상 구매의향을 보이는가 |
| 임대인 | 안전한 거래 의사를 증명할 표준 형식이 없고 반복 설명 비용이 큼 | 민감정보를 공개하지 않는 서류 완비도·응답성 중심 신뢰 리포트가 문의 품질을 높인다 | 매물 등록·중개 의뢰 전 | 건당 19,900원 또는 월 39,000원 | 5명 중 2명 이상이 공개 가능한 항목을 선택하고 19,900원 이상 의향을 보이는가 |
| 공인중개사 | 확인·설명 준비와 반복 문의 대응에 시간이 들고 누락 위험이 있음 | 초안 체크리스트와 고객 질문지가 건당 15분 이상을 절감하되 전문가의 확인·설명 책임을 침범하지 않는다 | 계약서 초안 작성 및 확인·설명서 준비 시 | 월 49,000원(20건), 월 99,000원(무제한 가설) | 5개 사무소 중 2곳 이상이 월 49,000원 또는 파일럿 참여 의향을 보이는가 |

가격 질문은 “얼마면 사겠는가”보다 다음 순서로 묻는다: 최근 문제 해결 비용과 대안 → 샘플 사용 후 구매 여부 → 9,900원/19,900원/49,000원 중 실제 선택 → 결제를 막는 조건. 이번 실험에서는 결제나 결제정보를 받지 않고 선택만 기록한다.

## 3. 비식별 샘플 리포트 1종

### 샘플 시나리오

- 가상의 다가구주택 전세계약 초안
- 모든 이름·주소·금액·등기번호는 합성값
- 문서 상단에 `DEMO — 실제 계약 판단용 아님` 워터마크

### 리포트 구조

1. **한눈에 보기**
   - 확인 필요 3건, 자료 부족 2건, 일반 안내 2건
   - 단일 “안전 점수”는 표시하지 않는다. 점수는 근거가 다른 위험을 뭉개고 사실상 신용평가로 오인될 수 있다.
2. **입력 자료와 기준 시각**
   - 계약서 초안, 합성 등기 요약, 사용자가 체크한 보증 신청 계획
   - 자료 생성일과 미제출 자료를 명시
3. **위험 신호 카드**
   - 신호명: 선순위 권리관계 추가 확인 필요
   - 발견 근거: 합성 등기 요약의 근저당 항목
   - 왜 확인하는가: 보증금 회수 가능성 판단에 필요한 입력 중 하나
   - 다음 행동: 최신 등기사항증명서와 선순위 임차보증금 확인을 중개인에게 요청
   - 한계: 실제 채권 잔액·주택가액·점유관계 미확인
4. **계약서 질문 카드**
   - “보증 가입 불가 시 계약 해제 및 지급금 반환 조건을 어떻게 정할 것인가?”
   - 법률 문구를 자동 확정하지 않고, 전문가에게 확인할 질문으로만 제시
5. **자료 부족**
   - 건축물대장, 최신 등기사항증명서, 보증기관 사전확인 결과 등
6. **전문가 확인 체크포인트**
   - 공인중개사: 권리관계·거래 또는 이용 제한·확인 근거자료
   - 보증기관: 해당 상품 가입 가능성
   - 변호사: 개별 특약의 법률효과
7. **데이터 처리 안내**
   - 수집 항목, 목적, 보유기간, 삭제 방법, AI 외부 전송 여부를 별도 표기

### 신뢰 리포트 영역의 안전한 초기 범위

포함 후보는 본인 동의 기반의 `제출 서류 종류`, `자료 기준일`, `응답 완료 여부`, `전문가 확인 여부`처럼 검증 가능한 절차 정보다. 임대인의 성실성·신용·사기 가능성, 분쟁 가능성을 점수화하거나 제3자에게 단정하는 표현은 제외한다.

## 4. 인터뷰 질문지

### 공통 도입

1. 최근 임대차 계약을 준비하거나 지원한 시점을 떠올려 달라.
2. 가장 불안하거나 시간이 많이 든 순간은 언제였나?
3. 무엇을 확인했고, 누구에게 물었으며, 시간·비용이 얼마나 들었나?
4. 확인하지 못해 포기하거나 계약을 미룬 적이 있나?

### 임차인 추가 질문

1. 계약서 초안을 받은 뒤 가장 먼저 확인한 세 가지는 무엇인가?
2. 등기, 건축물대장, 보증 가입 조건 중 이해하기 가장 어려운 것은?
3. 샘플에서 처음 행동하게 만드는 카드와 불필요한 카드는?
4. “위험 신호 + 근거 + 다음 질문”이 계약 결정을 어떻게 바꾸는가?
5. 9,900원과 19,900원 중 어느 것을 선택할까? 선택하지 않는 이유는?
6. 문서를 업로드하지 않고 직접 체크하는 방식이면 사용할까?

### 임대인 추가 질문

1. 임차인·중개인에게 반복해서 증명하거나 설명하는 항목은?
2. 공개 가능한 정보와 절대 공개하고 싶지 않은 정보는?
3. 서류 완비도와 응답 기록을 보여주면 문의 품질이나 계약 속도가 달라질까?
4. “신뢰 점수”와 “검증 항목 목록” 중 어느 쪽이 더 공정하다고 느끼나?
5. 건당 19,900원과 월 39,000원 중 선택은? 어떤 성과가 있어야 갱신할까?

### 공인중개사 추가 질문

1. 계약 한 건의 확인·설명 준비와 반복 문의에 각각 몇 분이 드는가?
2. 가장 자주 누락되거나 고객이 오해하는 항목은?
3. 샘플 중 업무 보조가 되는 부분과 책임 경계를 흐리는 부분은?
4. 어떤 근거·로그가 있어야 업무에 사용할 수 있나?
5. 월 49,000원에 20건 처리라면 사용할까? 도입을 막는 조건은?
6. 결과를 고객에게 그대로 전달할지, 중개사가 검토한 뒤 전달할지?

### 종료 질문

- 이 문제를 다음 30일 안에 다시 겪을 가능성은?
- 이 서비스를 추천할 한 사람은 누구인가? 이번 실험에서는 소개나 연락처 제공을 요청하지 않는다.
- 인터뷰에서 빠진 가장 중요한 위험은?

## 5. 모집 문구 초안

### 임차인용

> 전월세 계약서에서 무엇을 확인해야 할지 막막했던 경험을 듣고 있습니다. 가상의 계약서로 만든 1페이지 위험 신호 리포트를 보고 20분간 의견을 주실 분을 찾습니다. 실제 계약서·주소·이름·연락처 등 개인정보는 받지 않으며, 판매나 법률상담이 아닙니다. 참여 방식과 사례 제공 여부는 보드 승인 후 확정합니다.

### 임대인용

> 임차인에게 안전한 거래 준비 상태를 설명하면서 반복 문의나 과도한 정보 공개를 겪은 임대인의 의견을 듣고 있습니다. 개인정보 없이 서류 완비도와 확인 절차만 보여주는 가상 신뢰 리포트를 20분간 검토해 주세요. 실제 서류나 매물정보는 받지 않습니다.

### 공인중개사용

> 계약 전 확인·설명 준비와 고객 문의 대응을 돕는 가상 체크 리포트를 검증하고 있습니다. 공인중개사의 판단과 서명 책임을 대체하지 않는 업무보조 범위를 확인하기 위한 25분 인터뷰입니다. 실제 고객·계약 자료는 받지 않습니다.

## 6. 1주 실험 설계

| 일자 | 내부 작업 | 승인 후에만 가능한 작업 | 산출물 |
|---|---|---|---|
| 1일차 | 가설·스크립트 확정, 합성 샘플 제작, 기록표 준비 | 없음 | 샘플 v1, 인터뷰 노트 템플릿 |
| 2일차 | 보드에 모집 채널·문구·보상안 승인 요청 | 승인된 채널에 모집 문구 게시 | 모집 로그 |
| 3~5일차 | 인터뷰 기록과 즉시 요약 | 임차인 10, 임대인 5, 중개인 5 목표로 비대면 인터뷰 | 고객군별 증거 카드 |
| 5일차 | 가격 선택과 반복 문제 정량화 | 개인정보 없는 후속 의향 선택 수집 | 가격·행동 표 |
| 6일차 | 샘플 v2 제작, 반대 증거와 법률 질문 정리 | 필요 시 3명 재확인 | 변경 전후 비교 |
| 7일차 | Go/Pivot/Stop 판정 | 외부 제출 없음 | 1쪽 의사결정 메모 |

### 기록할 최소 데이터

- 고객군, 최근 계약 경험 시기 구간, 현재 대안, 문제 빈도, 소요시간 구간
- 샘플 이해도 1~5, 가장 유용한 카드, 실제 다음 행동, 가격 선택, 반대 이유
- 이름·전화번호·이메일·주소·실제 계약서·주민등록번호·등기 고유번호는 수집하지 않는다.

### 성공 기준

다음을 모두 충족하면 제한형 MVP로 **Go**한다.

1. 전체 20명 중 12명 이상이 최근 12개월 내 문제를 실제 경험했다.
2. 임차인 10명 중 6명 이상이 샘플 후 구체적 확인 행동을 말하고, 4명 이상이 9,900원 이상을 선택한다.
3. 임대인·중개인 합계 10명 중 4명 이상이 유료 가격 또는 보드 승인 후 파일럿 참여 의향을 보인다.
4. 샘플 핵심 항목 이해도 평균이 4.0/5 이상이고, “법률 판단/안전 보증”으로 오인한 비율이 20% 미만이다.
5. 법률 사전검토에서 합성데이터 기반 내부 데모와 제한형 MVP에 치명적 금지 사유가 확인되지 않는다.

### 전환 기준

- 지불의향은 낮지만 중개인 시간 절감이 건당 15분 이상이면 B2C보다 B2B QA 도구로 전환한다.
- “신뢰 점수” 거부가 30% 이상이면 점수를 폐기하고 검증 항목·자료 기준일만 제공한다.
- 문서 업로드 거부가 40% 이상이면 체크리스트 입력과 사용자 기기 내 마스킹을 우선한다.

### 중단 기준

아래 중 하나면 **Stop** 또는 법률검토 완료까지 중단한다.

- 임차인 구매의향 2명 미만이며 구체적 행동 변화도 4명 미만
- 고객이 결과를 법률 판단이나 안전 보증으로 오인하는 비율 30% 이상
- 개인신용평가업, 유사명칭, 비변호사 법률사무, 공인중개사의 확인·설명 주체성 중 하나라도 현 모델에서 회피 불가능하다는 전문가 의견
- 실제 계약서 수집 없이는 가치가 성립하지 않는데 적법한 수집·보관·삭제 체계를 마련할 자원이 없음

## 7. 법률 사전검토 질문

아래는 법률 결론이 아니라 변호사·개인정보 전문가·관할기관에 확인할 질문이다.

### 개인정보·AI

1. 계약서, 등기자료, 주소, 임대인·임차인 이름은 각각 어떤 개인정보에 해당하며 서비스 제공에 필요한 최소 적법근거는 무엇인가?
2. 주민등록번호가 포함된 문서 업로드를 원천 차단·기기 내 마스킹해야 하는가? 서버가 잠시라도 원본을 받으면 어떤 의무가 생기는가?
3. OCR·LLM 공급자에게 문서를 보내면 위탁과 국외이전 중 무엇에 해당하며 고지·계약·보관 위치·학습 제외 설정은 어떻게 해야 하는가?
4. 원본 즉시 삭제, 추출값 단기 보관, 리포트 장기 보관 각각의 보유기간과 파기 증적은 어떻게 설계해야 하는가?
5. 완전 자동화된 결과가 계약 체결 여부에 중대한 영향을 미칠 경우 개인정보 보호법상 거부·설명·인적 재검토와 기준 공개 의무가 적용되는가?
6. 가명·합성 데이터로 모델을 평가할 때 재식별 위험평가와 별도 보관 의무가 필요한가?

### 신용정보·명칭

1. 임대인의 권리관계, 채무 관련 공개자료, 거래 응답성 등을 결합해 “신뢰”를 산출하면 개인신용정보 또는 개인신용평가에 해당하는가?
2. 결과를 본인에게만 주는 경우와 임차인·중개인·플랫폼에 제공하는 경우 허가·동의 요건이 어떻게 달라지는가?
3. `신뢰 리포트`, `신뢰 점수`, `risk score`가 신용정보법상 유사명칭 금지 또는 무허가 개인신용평가 오인을 일으키는가?
4. 안전한 초기 범위를 서류 존재 여부·검증 일자·본인 선택 공개로 한정하면 규제 성격이 달라지는가?

### 위치정보

1. 계약 대상의 고정 주소나 좌표만 처리하는 것이 위치정보법상 개인위치정보에 해당하는가, 아니면 개인의 이동·현재 위치와 결합될 때만 해당하는가?
2. 생활권·통근 분석에 사용자의 현재 위치나 이동경로를 쓰면 위치기반서비스사업 신고, 동의, 이용·제공사실 기록 의무가 발생하는가?
3. 주소를 법정동·격자 단위로 변환한 뒤 원본을 즉시 삭제하면 적용 범위와 안전조치가 달라지는가?

### 변호사법·공인중개사법·책임

1. 개별 특약의 효력이나 계약 안전성을 유료로 판단하면 비변호사의 법률사무 또는 법률감정에 해당하는가?
2. “확인 질문 생성”과 “법률적 결론”을 구분하는 제품·마케팅·면책 문구의 실질적 기준은 무엇인가?
3. 중개업소용 산출물이 공인중개사법상 개업공인중개사의 확인·설명 업무를 대체하거나 무자격 수행으로 보이지 않으려면 어떤 검토·승인 흐름이 필요한가?
4. 잘못된 누락·표시로 계약 손해가 발생할 때 손해배상 범위, 책임 제한의 유효성, 전문직업배상 또는 사이버보험 필요성은?
5. 공개 등기정보를 자동 수집·재배포할 때 이용약관, 저작권·데이터베이스권, 개인정보 목적 외 이용 제한은 무엇인가?

## 8. 법률 근거 메모와 제품 가드레일

- 개인정보 보호법은 권리·의무에 중대한 영향을 주는 완전 자동화된 결정에 거부·설명 요구, 인적 개입, 기준·절차 공개를 규정한다. 따라서 “자동 승인/거절” 대신 근거 카드와 전문가 확인 경로를 둔다.
- 신용정보법은 허가받지 않은 자의 `개인신용평가`, `신용관리`, `MyData` 등 유사명칭 사용을 제한한다. 초기에는 개인의 신용도·거래 가능성을 점수화하지 않는다.
- 공인중개사법상 확인·설명 주체는 개업공인중개사이며 근거자료 제시와 서면 교부 의무가 있다. 제품은 초안을 만들 수 있어도 최종 검토·설명·서명 흐름을 전문가에게 남긴다.
- 변호사법상 대가를 받고 법률상담·법률관계 문서 작성·감정 등 법률사무를 취급하는 행위는 위험하다. 특약을 확정 작성하거나 효력을 단정하지 않고 질문과 정보 정리에 집중한다.

## 9. 보드 승인 체크리스트

외부 모집 전에 다음만 결정하면 된다.

1. 모집 채널: 기존 지인망, 커뮤니티, 중개업소 중 허용 범위
2. 인터뷰 보상: 무보상 또는 20분 기준 소액 모바일 쿠폰 예산
3. 목표 인원: 20명 전체 실행 또는 임차인 10명 우선 스프린트
4. 녹음 금지 기본값과 익명 메모 보관기간
5. 법률·개인정보 자문 요청 대상과 예산

보드 승인 전에는 이 문서와 합성 샘플만 내부 검토하며 외부 연락·게시·개인정보 수집·결제를 하지 않는다.
