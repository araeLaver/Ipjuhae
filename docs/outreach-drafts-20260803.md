## 공통 소개와 안전선

> Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하고, 임대인과 필요한 정보를 확인한 뒤 대화를 시작하도록 돕는 초기 주거 정보 서비스입니다. 매물 중개, 계약 대리, 신용평가, 자동 선별, 보증 또는 법률 조언은 제공하지 않습니다.

- 실제 사용자 개인정보, 원본 증빙, 운영 DB, credential, 내부 산식과 확인되지 않은 성과 수치를 공유하지 않는다.
- 외부 자료는 mock 계정과 synthetic data만 사용한다.
- `좋은 세입자`, `신뢰점수`, `등급`, `신용 검증`, `안전 보장`, `기관 인증` 표현을 사용하지 않는다.
- 첫 대화는 60초 이내로 끝내고, 상대가 동의할 때만 업무용 연락처 또는 공식 문의 경로를 받는다.
- 공동 pilot, 데이터 연동, 비용, 계약, 로고 사용은 후속 범위로 분리하고 보드 승인 전 약속하지 않는다.

## 공통 준비자료

- 1페이지 제품 소개: 대상 사용자, 문제, 현재 MVP 범위, 비중개·비평가 경계
- 실제 정보가 없는 mock 화면 3장: 공개 범위 설정, 확인 상태, 임대인-임차인 대화 시작
- 20분 질문지 5개와 익명 메모·무녹음 원칙
- 공개 가능한 제품 품질 근거 1장. 사용자·매출·제휴 수치는 확인된 값이 없으면 넣지 않는다.
