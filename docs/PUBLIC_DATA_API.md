# 공공데이터 인증키 신청

두 가지를 붙인다. **키는 하나면 된다.** 공공데이터포털 계정 하나로 여러 API를 신청한다.

| 붙일 것 | 어디에 쓰나 |
| --- | --- |
| 정책브리핑 정책뉴스 | 홈과 `/policy`에 최근 정책 소식 |
| 부동산 전월세·매매 실거래가 | `/check`에서 시세를 직접 안 넣어도 되게 |

실거래가는 추정치가 아니라 **신고된 실제 거래가**다. "시세를 우리가 추정하지 않는다"는
원칙에 어긋나지 않는다. 지금 계산기의 가장 큰 마찰이 "시세를 직접 찾아 넣어야 한다"는
것인데 그게 사라진다.

## 1. 회원가입

https://www.data.go.kr 에서 가입한다. 개인으로 하면 된다.

## 2. 아래 페이지에서 각각 「활용신청」

전부 **무료**다. 정책뉴스는 자동승인이고, 실거래가는 보통 1~2시간 안에 열린다.

| API | 주소 |
| --- | --- |
| 정책브리핑 정책뉴스 | https://www.data.go.kr/data/15095335/openapi.do |
| 아파트 전월세 실거래가 | https://www.data.go.kr/data/15126474/openapi.do |
| 아파트 매매 실거래가 | https://www.data.go.kr/data/15126469/openapi.do |
| 연립·다세대 전월세 | https://www.data.go.kr/data/15126473/openapi.do |
| 단독·다가구 전월세 | https://www.data.go.kr/data/15126472/openapi.do |
| 오피스텔 전월세 | https://www.data.go.kr/data/15126475/openapi.do |

**여섯 개 다 신청하시는 게 낫다.** 사용자가 아파트에만 사는 게 아니다.
다가구는 선순위 보증금 때문에 오히려 더 위험한데, 그 자료가 없으면 그 사람들을 못 돕는다.

신청할 때 활용 목적을 적으라고 한다. 이렇게 쓰면 된다.

```
전세 계약 전 임차인이 보증금의 안전성을 확인할 수 있도록,
해당 지역의 실거래가를 조회해 보여주는 웹 서비스에 사용합니다.
```

## 3. 키 확인

마이페이지 → 개발계정 → 「일반 인증키(Encoding)」와 「일반 인증키(Decoding)」 두 가지가 나온다.
**둘 다** 알려주시면 된다. 서버에서 쓸 때 어느 쪽이 맞는지는 실제로 호출해 보고 정한다.

## 4. 전달 방법

키는 비밀이다. 채팅에 붙여넣지 마시고 아래처럼 넣어주시면 된다.

```
flyctl secrets set PUBLIC_DATA_API_KEY='디코딩키' -a ipjuhae-production
```

로컬 확인용으로는 `.env.local`에 같은 이름으로 넣는다. 이 파일은 저장소에 올라가지 않는다.

## 제한과 조건

| | |
| --- | --- |
| 비용 | 무료 |
| 개발계정 호출 | 1,000회/일 |
| 운영계정 | 활용 사례를 등록하면 상향 가능 |
| 라이선스 | 공공저작물 제1유형 — **출처표시 필수** |

출처표시가 의무다. 화면에 "출처: 대한민국 정책브리핑", "출처: 국토교통부 실거래가"를
반드시 띄운다. 이건 예의가 아니라 조건이다.

호출 1,000회는 많아 보여도 사용자가 시세를 조회할 때마다 나간다. **캐시를 반드시 둔다.**
같은 지역·같은 달 자료는 한 번만 받아서 재사용한다.

## 붙이기 전까지

키가 없으면 관련 화면은 **아예 나타나지 않게** 만든다.
"곧 제공됩니다" 같은 빈 칸을 두지 않는다. 없는 걸 있는 척하지 않는다.

## 주의

- 아파트 전월세는 **동·호 정보가 제공되지 않는다.** 개인정보 보호 때문이다.
  같은 단지 같은 면적의 최근 거래를 보여주는 수준까지가 한계다
- 조회는 **법정동코드 앞 5자리 + 계약년월 6자리** 단위다. 주소를 법정동코드로
  바꾸는 단계가 따로 필요하다
- 실거래가는 **전세가**지 매매 시세가 아니다. 보증금 위험 계산에는 매매 시세가 필요하므로
  매매 실거래가 API도 함께 신청하는 이유가 이것이다

## 발급받은 엔드포인트 (2026-09-22 확인)

키 자체는 여기 적지 않는다. `.env.local`과 Fly secrets에만 둔다.
데이터 포맷은 다섯 개 모두 **XML**이다.

| API | End Point |
| --- | --- |
| 정책브리핑 정책뉴스 | `https://apis.data.go.kr/1371000/policyNewsService2` |
| 아파트 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptRent` |
| 아파트 매매 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade` |
| 연립다세대 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcRHRent` |
| 오피스텔 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcOffiRent` |

단독·다가구 전월세는 아직 신청되지 않았다. 다가구는 선순위 보증금 때문에
가장 위험한 유형이라 나중에라도 받는 편이 좋다.

### 키를 다룰 때

포털이 주는 「일반 인증키(Encoding)」는 이미 URL 인코딩된 문자열이다
(`%2B`, `%2F`, `%3D`가 들어 있다). `URLSearchParams`에 그대로 넣으면
퍼센트 기호가 한 번 더 인코딩돼 인증이 실패한다.
쿼리 문자열을 직접 이어 붙이거나, 디코딩 키를 쓰고 한 번만 인코딩한다.
