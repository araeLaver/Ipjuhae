## 1. 신청서 골격과 핵심 문안

### 1-1. 서비스 개요

Rentme는 임차인이 매물을 검토할 때 여러 기관에 분산된 가격·교통·생활권 정보를 한 화면에서 이해하도록 돕는 주거 의사결정 지원 서비스이다. 신청 과제인 `지역·거래·생활권 설명 AI`는 매물의 시·군·구 또는 법정동 단위 위치를 기준으로 공공데이터를 결합하고, AI가 데이터 출처와 기준시점을 포함한 쉬운 설명으로 변환한다.

현재 저장소에는 매물 구조, 규칙 기반 매칭, 선택적 OpenAI embedding 유사도, 설명문 생성, OCR pipeline이 구현되어 있다. 공공데이터 API의 운영 연동은 **향후 구축 범위**이며, 현재 활용 중인 것으로 표현하지 않는다.

### 1-2. 문제와 필요성

전월세 매물을 비교하는 사용자는 거래 가격, 대중교통, 공공임대 공급, 생활 인프라 데이터를 기관별 화면과 서로 다른 기준으로 찾아야 한다. 데이터 원문은 주소 단위, 갱신 시점, 결측 처리 방식이 달라 비전문 사용자가 직접 해석하기 어렵다. Rentme는 공공데이터를 주소·좌표·기준시점으로 구조화하고, 원문 확인이 가능한 설명을 제공해 탐색 비용과 정보 비대칭을 줄이고자 한다.

### 1-3. 데이터·AI 처리 흐름

1. 사용자가 선택한 매물에서 상세주소를 제외하고 시·군·구, 법정동, 주택유형 등 최소 필드만 추출한다.
2. 법정동코드로 주소를 정규화하고 공공데이터의 join key를 통일한다.
3. 거래·교통·생활권 데이터를 기준시점과 함께 수집하고 중복, 결측, 이상값, 갱신 지연을 점검한다.
4. 지역별 거래 범위, 정류장·역 접근성, 공공임대·생활 인프라 존재 여부 등 설명용 feature를 생성한다.
5. AI에는 구조화된 공공데이터, 기준시점, 출처, 비식별 매물 정보만 전달한다.
6. 생성 결과에는 출처·기준시점·원문 링크와 `정보 이해를 돕는 설명이며 자동 심사·법률 판단이 아님`을 표시한다.

### 1-4. 차별점

- 단순 매물 나열이 아니라 공공데이터의 출처와 기준시점을 보존한 근거 기반 설명을 제공한다.
- 공공데이터와 사용자 동의 데이터를 논리적으로 분리하고 AI prompt에 연락처, 주민등록번호, 원본 증빙, 상세주소를 넣지 않는다.
- 결과를 임차인 합격·탈락, 개인 신용도, 계약 안전성의 확정 판단에 사용하지 않는다.
- 결측 또는 오래된 데이터는 숨기지 않고 `확인 불가` 또는 기준시점을 함께 표시한다.

### 1-5. 지원 필요사항

희망 1순위는 `[BOARD_CONFIRM: AI-Ready 구축/공공데이터 수집 및 정제]`이다. 법정동·좌표 join 품질, API별 갱신·결측 처리, 설명용 feature schema, 출처 표기 UX, AI 사실성 평가셋을 전문가 컨설팅으로 확정하고자 한다. 자체 학습모델 보유를 전제하는 `AI 모델 고도화`는 우선순위로 제시하지 않는다.

### 1-6. 사업화와 로드맵

- 1년차: 전월세 실거래가·법정동코드·교통정보 3종 연동, 비식별 demo와 품질평가 구축
- 2년차: 주택유형·지역·생활 인프라 데이터 확대, 사용자 피드백 기반 설명 품질 개선
- 3년차: 고급 비교 리포트와 주거서비스 사업자용 B2B 분석 리포트 검증

기본 탐색은 무료, 고급 비교 리포트와 임대관리 도구는 구독형 후보로 검증한다. 매출·사용자 수 목표는 대표자가 승인한 값만 입력한다.

## 5. 표현 안전성 점검

| 사용 금지 표현 | 대체 표현 |
| --- | --- |
| `AI가 안전한 집을 판정한다` | `공공데이터 기반 지역 정보를 설명하고 추가 확인 항목을 안내한다` |
| `임차인 신용도·합격 가능성` | `사용자가 입력한 선호조건과 매물 특성의 참고용 비교` |
| `최적 임차인을 자동 선별한다` | `사용자가 매물 정보를 이해하도록 비교 근거를 제공한다` |
| `계약 위험 없음`, `사기 방지 보장` | `계약 전 확인을 돕는 정보이며 권리·법률 검토를 대체하지 않는다` |
| `AI 법률 조언` | `공식 원문과 전문기관 확인 경로 안내` |
| `실시간 정확한 시세` | `표시된 기준시점의 공공데이터를 요약한 참고정보` |
| `개인정보를 활용해 정밀 추천` | `비식별·최소화된 조건과 공공데이터를 활용한 설명` |

공통 고지문:

> 본 결과는 공공데이터와 가상·비식별 입력을 바탕으로 정보 이해를 돕는 참고 설명입니다. 개인에 대한 평가나 자동 선별, 계약 안전성 보증 또는 법률 조언이 아니며, 중요한 결정 전 공식 원문과 전문가 확인이 필요합니다.
