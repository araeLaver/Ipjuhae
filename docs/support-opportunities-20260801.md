## 1. 공공데이터 활용기업 AI연계 맞춤형 성장 지원사업

Rentme의 전월세 실거래가·법정동·공공임대주택·교통·생활 인프라 활용 계획을 `지역·거래·생활권 설명 AI`로 좁히면 현재 제품과 가장 직접적으로 연결된다. 개인 신용평가나 임차인 자동 선별은 범위에서 제외한다.

- 기대효과: 공공데이터의 AI-Ready 전환, 서비스 고도화, 사업화·투자·특허 연계.
- 필요한 자료: 신청 주체와 표기명, 활용 데이터셋 5~8개, 개인정보 없는 demo와 mock data, sample schema, 현재 기술 단계, 희망 지원분야 1개.
- 다음 행동: 기존 보드 확인 이슈에서 신청 주체·공개 범위·지원분야를 2026-08-04까지 확정하고, 2026-08-07까지 신청서 초안을 만든다.
- 중단 기준: 확인값이 2026-08-07까지 없으면 외부 제출 없이 No-Go 또는 차기 회차 준비로 전환한다.

## 2. 중소기업 AI훈련확산센터 참여기업 모집

공식 공고는 서울·인천·경기·강원 소재 중소기업을 대상으로 하며, AI 기반 스타트업은 상시근로자 20인 미만도 가능하다고 명시한다. Rentme에는 `매물·프로필 데이터 품질관리 workflow`를 우선 컨설팅 과제로 추천한다.

- 기대효과: AI 맞춤 컨설팅 비용 100% 지원, 전담 코치, 도입 로드맵, 후속 기술 자문.
- 필요한 자료: 사업장 소재지, 사업자등록증, 상시근로자 수, 중소기업·AI 스타트업 증빙, 현재 데이터 품질 애로와 목표 지표.
- 다음 행동: 기존 자격 확인 이슈에서 사실값을 회수한 뒤 공식 접수처의 잔여 접수 여부를 확인한다.
- 주의: 예산 소진 시 조기 종료될 수 있으며, 예비창업자에게 열려 있다는 근거는 확인되지 않았다.

## 3. 마이데이터 전문가 상시자문

Rentme의 동의 기반 정보 수집·제공, 접근권한, 정정·철회, 데이터 최소화 설계를 출시 전에 검토받는 저비용·고적합 후보로 유지한다.

- 기대효과: 개인정보·데이터 활용 구조와 사업화 모델에 대한 법·제도 및 기술 자문.
- 필요한 자료: 개인정보 없는 서비스 흐름, 데이터 항목표, 동의·철회 흐름, mock 화면, 질문 5개.
- 다음 행동: `수집 근거`, `제3자 제공`, `검증 결과 표현`, `철회 후 처리`, `보유기간`의 다섯 질문으로 고정하고 외부 접수 승인값만 회수한다.

## 4. K-Startup 스타트업 원스톱 지원센터 법률지원

마이데이터 자문이 데이터 이동·활용 구조에 집중한다면, 원스톱 법률지원은 중개업 오인, 신용평가 오인, 계약·면책 문구와 브랜드/IP 질문을 보완하는 용도로 쓴다.

- 기대효과: 규제·인허가, 계약·거래, 지식재산 관련 전문가 검토.
- 필요한 자료: 1페이지 제품 소개, 실제 사용자 정보가 없는 화면, 기존 검토 요약, 중복 제거한 질문 목록.
- 다음 행동: 마이데이터 자문 결과가 나오기 전에는 중복 신청을 피하고, 법률 고유 질문만 별도 정리한다.
