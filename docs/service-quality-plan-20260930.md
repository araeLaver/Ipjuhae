# 입주해 사용성 개선 및 기능 우선순위 — 2026-09-30

## 이번 개선
- 매물 필터의 전체 옵션에 빈 문자열을 전달하던 문제 수정. 실제 Radix Select를 렌더링하는 회귀 테스트 추가.
- 검색창과 필터 버튼에 접근성 이름, 필터 열림 상태 추가.
- 임차인 프로필 미작성 응답에 total=0과 requiresProfile 상태 추가. 매물 없음과 구분해서 안내.
- 매칭 화면에서 프로필 수정과 전체 매물로 이동하는 링크 제공.
- 로그인 만료 시 로그인 후 /matches로 돌아오는 링크 제공.
- 브라우저 저장소 접근 거부가 화면을 중단하지 않도록 처리.
- 잘못된 매칭 응답은 재시도 화면으로 처리.
- 매물 카드에서 월세+관리비 합계 표시. 공과금은 별도임을 명시.

## 다음 기능 제안
아래는 코드와 사용자 흐름을 바탕으로 한 제품 가설이며 사용자 수요가 검증된 결과는 아니다.

| 순위 | 기능 | 해결하는 문제 | 구현 범위 | 성공 지표 |
| --- | --- | --- | --- | --- |
| P1 | 검색 조건 저장 + 신규 매물 알림 | 조건을 반복 입력하고 새 매물을 수동 확인 | 계정별 검색 조건, 신규 매물 이벤트, 알림 빈도·해제, 중복 발송 방지 | 저장 조건에서 매물 조회·문의로 이어지는 비율 |
| P1 | 후보 매물 2~3개 비교 | 보증금·월 고정비·면적·입주일을 여러 화면에서 비교 | 세입자용 매물 찜, 비교 목록, 항목별 표, 거래 종료 표시 | 비교에서 문의로 이어지는 비율 |
| P2 | 문의 상태와 미응답 안내 | 메시지를 보낸 뒤 진행 상황을 알기 어려움 | 전달/읽음/응답 대기 표시, 본인에게만 재확인 알림, 응답 시간 요약 | 첫 답변 시간, 미응답 비율 |
| P2 | 매물 정보 갱신일·신고 경로 | 오래된 정보와 실제 거래 가능 여부의 불확실성 | 갱신일 표시, 임대인 확인 요청, 신고 사유, 운영 검토 | 오래된 매물 비율, 신고 처리 시간 |
| P2 | 방문·계약 확인 체크리스트 | 탐색 뒤 다음 단계에서 확인할 항목을 놓침 | 단계별 본인 체크 기록, 증빙 첨부 선택, 기존 시세·신뢰 화면 연결 | 체크리스트 완료율 |

세입자용 매물 저장·비교와 임대인용 세입자 즐겨찾기는 별도 기능이다. 현재 임대인용 즐겨찾기를 세입자 매물 찜 기능으로 간주하지 않는다.

검색 조건 저장/알림은 Zillow의 공개 검색 가이드에도 나오는 패턴이다. 입주해에서는 먼저 저장 조건과 알림 설정을 만든 뒤 실제 알림을 단계적으로 연결한다.

## 출시 전 확인
- 실제 계정으로 프로필 작성 → 매칭 → 매물 상세 → 문의의 전체 흐름 확인.
- 로그인 만료 후 원래 화면 복귀, 실제 DB 응답, 모바일 화면 확인.
- 매물 검색 요청의 응답 순서 역전과 추가 페이지 로딩 실패 복구는 후속 개선 대상.
- 이번 작업은 로컬 개선이며 운영 배포 및 신규 알림 발송을 실행하지 않았다.
