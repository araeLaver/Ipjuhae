- **다음 성장 레인** — 이번에 만화 아트보드를 택했다. 남은 후보는 셋이고 우선순위 판단은 아래와 같다

  - 공인중개사 직접 접촉 — 전환 트랙. 1명이 세입자 다수를 데려온다. 실행은 전부 사람 손
  - `/risk` 실데이터 연결(국토부 실거래가 API) — 가장 강한 무기지만 API 키 발급이 선행
- 프로덕션 신청 실주입 검증. 로컬에서만 확인했고 실제 신청 데이터를 오염시키지 않으려고
  프로덕션에는 테스트 신청을 넣지 않았다

## 추가 — 만화 형식 전면 교체

대표님 지적: CSS 도형으로 그린 인물(원·사각에 점)이 게시 가능한 품질이 아니다. 맞는 지적이라 폐기했다.

먼저 대안을 실물로 확인했다. AI 이미지 생성(Gamma)으로 일러스트를 뽑아 한글을 얹는 방식은
**품질은 충분했지만** 두 가지가 걸렸다 — 이미지 모델은 한글을 못 써서 말풍선을 맡길 수 없고,
크레딧이 장당 70, 잔여 330(4장)이라 12화에 필요한 840을 댈 수 없다.

그래서 **시각 언어 자체를 바꿨다. 사람을 그리지 않는다.**
HTML/CSS가 압도적으로 잘하는 것 — 타이포그래피와 문서 레이아웃 — 으로 간다.
「지수의 계약」은 이제 **대화 기록 + 등기부·계약서 서류**로 전개된다.

- 지수의 말(앰버, 오른쪽) / 김 소장의 말(흰색+아바타, 왼쪽) / 지수의 속마음(점선 내레이션) / 서류 카드
- 서류 카드는 실제 등기부 칸 구조(【갑구】·【을구】·특약사항)를 따르고 결정적 한 줄에 앰버 형광.
  실제 서류로 오인되지 않게 **「예시」 배지를 항상 붙인다**
- 서류 컷의 항목 구성은 원고에 없는 정보라 생성기의 `DOCS` 표에 둔다
- 서류 카드가 없는 화는 내용이 적어 가운데 정렬하면 휑해서 고르게 편다

원고 파일도 **게시물 단위로 재구성**했다. 공통 디자인 규격을 맨 위에 한 번만 적고(연계성),
화마다는 캡션(인스타·스레드 / X)과 그 화만의 디자인 프롬프트 표를 한 짝으로 뒀다.
기존 45줄짜리 화별 프롬프트 중복이 사라졌다.
