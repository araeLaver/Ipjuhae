Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하고, 임대인·임대관리자가 조건에 맞는 상대와 대화를 시작하도록 돕는 초기 주거 정보 서비스입니다. 매물 중개, 계약 대리, 임차인 신용평가, 자동 합격·탈락 또는 법률 조언을 제공하지 않습니다.

외부 문안에서는 `좋은 세입자`, `신뢰점수`, `등급`, `신용 검증`, `보증`을 사용하지 않는다. 제품 증거는 mock 계정과 synthetic data만 사용하고 실제 사용자 개인정보, 원본 증빙, 운영 DB, credential은 공유하지 않는다.

## 1. 경기 스타트업 서밋 Invest Connect 2차

### 목적과 제안

2026-07-29 15:00 마감 전에 투자사 밋업 단독 신청이 가능한지 최종 판정한다. 입주해는 동의 기반 임대 프로필, 역방향 임대 매칭, 공개 범위·철회 흐름을 갖춘 PropTech MVP로 소개한다. 확인되지 않은 사용자·매출·제휴·투자 수치는 쓰지 않고 현재 단계를 `MVP 구현 및 베타 준비`로 제한한다.

### 필요한 첨부자료

- 공고일 기준 3개월 이내 발급한 사업자등록증
- 대표 서명 동의서·참가 서약서
- 최신 IR PDF와 3페이지 이내 사업요약서
- 개인정보 없는 제품 화면 3~5장
- 공개 승인된 팀 이력, traction, 투자 목적·희망 규모·자금 사용 계획
- 경기스타트업플랫폼 계정과 최종 제출 담당자

### 예상 리스크

- 자격, 대표 서명, 참석 가능 여부, 최종 제출 권한 중 하나라도 미확인하면 접수할 수 없다.
- 기존 IR의 투자금·시장·traction 수치를 재확인 없이 사용하면 허위·과장 위험이 있다.
- 대·중견기업 밋업은 기업별 제안서가 추가로 필요하므로 이번 긴급 범위에서는 제외한다.

### 신청서 복사용 5문장 초안

Rentme는 세입자가 동의 기반 임대 프로필을 만들고 임대인·임대관리자가 조건에 맞는 상대와 대화를 시작하도록 돕는 역방향 임대 매칭 플랫폼입니다. 기존 매물 검색 중심 서비스에서 반복되는 개인정보·증빙 제출 부담과 계약 전 정보 비대칭을 줄이는 것이 목표입니다. 원본 증빙 대신 확인 여부, 유효기간, 공개 범위를 분리하고 사용자가 열람 동의와 철회를 관리하도록 설계했습니다. MVP는 프로필, 세입자 검색, 매물, 매칭, 메시지, 레퍼런스 요청과 확인 리포트 흐름을 포함하며 현재 베타 준비 단계입니다. 투자사 밋업을 통해 초기 시장 진입, 안전한 데이터 운영, 수익모델 검증에 대한 피드백을 받고자 합니다.

### 짧은 콜 스크립트

안녕하세요. Invest Connect 2차 신청을 준비 중인 Rentme 팀입니다. 저희는 동의 기반 임대 프로필과 역방향 임대 매칭 MVP를 개발하고 있습니다. 투자사 밋업 단독 신청 시 IR PDF와 3페이지 사업요약서 외에 제품 화면을 별도 파일로 첨부해도 되는지, 그리고 traction이 없는 베타 준비 기업도 `MVP 구현 및 베타 준비` 상태로 신청 가능한지 확인하고 싶습니다. 외부 제출 전 필요한 서식과 파일 제한도 함께 안내 부탁드립니다.

## 2. 공공데이터 활용기업 AI연계 맞춤형 성장 지원사업

전월세 실거래가, 법정동 코드, 부동산 통계, 교통·생활 인프라 데이터를 활용한 `지역·거래·생활권 설명 AI`가 지원 대상에 맞는지 확인한다. 임차인 평가나 자동 선별이 아니라 공개 데이터 기반 설명과 사용자가 확인할 항목 안내로 한정한다.

### 필요한 첨부자료

- 공고문 양식의 참여신청서
- 활용 공공데이터 목록과 출처
- mock listing, synthetic profile, sample schema
- 개인정보 없는 demo 화면 3장 이하
- 현재 AI 단계, 해결할 기술 문제, 희망 지원 패키지와 기대성과
- `docs/product-quality-evidence-20260727.md`의 외부 공유 가능 요약

### 예상 리스크

- 실제 개인정보나 원본 증빙을 AI 학습·demo 자료처럼 보이게 하면 안 된다.
- `AI 매칭`, `신뢰도 예측`, `세입자 추천`은 신용평가·차별 오인을 키운다.
- 12개 세부분야 중 하나를 고르기 전 현재 데이터와 AI 성숙도를 과장하지 않는다.

### 이메일 초안

안녕하세요. 2026년 공공데이터 활용기업 AI연계 맞춤형 성장 지원사업 운영사무국 담당자님께 문의드립니다.

### 필요한 첨부자료

- 사업자등록증, 중소기업확인서, 국세·지방세 납세증명

- ICT 자산 목록과 현재 보안 통제 요약

- 기업부담금 20%와 VAT 집행 가능 확인
- 운영 DB 원본이 아닌 아키텍처·데이터 흐름 요약

### 예상 리스크

- 사업자·중소기업 자격, 중복 수혜, 지역 구분이 미확인 상태다.

## 4. K-Startup 스타트업 원스톱 지원센터

### 목적과 제안

외부 소개 문구와 MVP 화면이 개인정보·데이터, 부동산 중개, 신용평가, 차별 이슈로 오인될 수 있는 지점을 공식 전문가 상담으로 점검한다.

### 필요한 첨부자료

- 1페이지 제품 소개서
- 실제 사용자 정보가 없는 화면 3장 이하
- 공개 가능한 데이터 흐름 요약
- 기존 법률·특허 검토 중 외부 공유 가능한 요약
- 개인정보 최소화, 중개 오인, 신용평가·차별 오인, 면책 문구 질문

### 예상 리스크

- 온라인 상담 답변은 일반 안내일 수 있으며 최종 법률 의견으로 간주할 수 없다.
- 기존 법무법인 검토와 중복되거나 비밀인 내용을 올리지 않는다.
- 실제 사용자 정보, 원본 증빙, 운영 DB, production secret은 첨부하지 않는다.

### 온라인 상담 초안

제목: 동의 기반 임대 프로필 서비스의 개인정보·중개·신용평가 오인 문구 검토 요청

안녕하세요. Rentme(입주해)는 세입자가 동의한 범위의 임대 프로필과 확인 상태를 정리하고 임대인과 필요한 범위에서 대화하도록 돕는 초기 주거 정보 서비스입니다. 매물 중개, 계약 대리, 임차인 신용평가 또는 자동 선별은 제공하지 않습니다.

외부 소개 문구와 MVP 화면을 공개하기 전에 아래 사항을 확인하고 싶습니다.

1. `신뢰`, `검증`, `추천`, `리포트` 중 임차인 평가나 차별로 오인될 수 있어 피해야 할 표현
2. 사용자가 직접 입력하고 공개 범위를 정한 정보라도 수집·보관·제공 단계에서 추가 고지할 사항
3. 공개 공공데이터 기반 지역·생활권 설명 AI가 신용평가나 법률 조언으로 오인되지 않게 할 제한 문구
4. 부동산 중개 서비스와 구분하기 위해 화면과 약관에 명시할 핵심 기준

실제 사용자 정보가 없는 mock 화면과 1페이지 설명만 첨부할 예정입니다. 검토 가능한 범위와 추가 자료를 안내 부탁드립니다.
