## 1. 원스톱 지원센터 콜·온라인 문의 초안

제목: 입주해 서비스의 상담 분야 및 신청자격 확인 문의

안녕하세요. 임대차 과정에서 자료의 확인 상태와 추가 질문을 정리하는 서비스 입주해를 개발하고 있습니다. 예시 데이터 기반 자료로 서비스 설명을 검토 중이며, 개인정보 처리와 중개 관련 서비스 경계에 관해 적절한 전문가 상담을 받고자 합니다. 현재 사업자 상태에 따라 어떤 신청자격과 증빙이 필요한지, 법률·개인정보 상담 중 어느 분야로 접수하면 되는지 안내 부탁드립니다. 먼저 비기밀 서비스 소개와 질문 목록만 전달하려 합니다. 상담 신청 경로와 필요한 최소 자료를 알려주실 수 있을까요? 감사합니다.

상담 질문: ① 신청자 상태별 이용조건과 증빙 ② 자료 확인 보조·후보 검토 흐름을 설명할 적정 상담 분야 ③ 개인정보를 포함하지 않은 화면 설명만으로 초기 상담 가능한지. 실제 사업자 정보는 보드가 확인해 공식 신청 경로에서 입력한다.

## 2. 특허고객상담센터 콜 초안

안녕하세요. 입주해라는 임대차 정보 확인 보조 서비스를 개발하고 있습니다. 서비스 명칭의 상표 출원과 소프트웨어 관련 특허 출원의 일반 절차를 구분해 안내받고 싶습니다. 공개 가능한 기능 개요만으로 시작할 수 있는 상담 경로와 준비서류, 전문 변리사 상담이 필요한 경우 연결 가능한 공적 안내 경로를 알려주실 수 있을까요? 현재 출원·등록 여부나 권리 귀속이 확인된 것으로 말씀드리는 것은 아니며, 이번 문의에서는 구현 상세나 실제 이용자 자료를 전달하지 않겠습니다.

절차 질문: ① 특허·상표별 공식 절차 자료 ② 신청 주체 확인에 필요한 서류 ③ 전문상담 경로와 이용조건. 비용이 발생하는 절차는 안내만 기록하고 별도 결정한다.

## 3. 프롭테크포럼 이메일 초안

제목: 임대관리·중개 실무자 대상 20분 문제 인터뷰 연결 문의

안녕하세요. 임대차 과정의 자료 확인 상태와 다음 질문을 정리하는 서비스 입주해를 개발하고 있습니다. 임대관리 또는 주거 중개 실무자 2곳과 각 20분씩 인터뷰하며 반복 확인 업무와 설명상의 어려움을 듣고자 합니다. 실제 계약서나 고객정보 없이 예시 상황과 질문지만 사용합니다. 이러한 인터뷰 연결이 가능할지, 어렵다면 적합한 행사나 문의 절차를 안내받을 수 있을까요? 아래의 짧은 서비스 소개와 질문지를 먼저 검토해 주시면 감사하겠습니다.

이 초안은 공식 수신처를 재확인한 뒤에만 사용한다. 발신자 표시와 회신 경로는 실제 발송 계정에서 보드가 확정한다.

## 공통 첨부용 서비스 소개

입주해는 임대차 과정에서 임차인·임대인·주택에 관한 자료 확인 상태와 다음 질문을 정리하는 서비스를 개발하고 있다. 이번 문의 목적은 현장 문제와 적절한 전문상담 경로의 확인이다. 검토에는 예시 데이터와 일반적인 업무 흐름만 사용하며, 개별 계약의 안전성이나 거래 성사를 보장하지 않는다. 공개 데모 주소, 검증 성능, 고객 수, 제휴 실적, 특허 보유 여부는 이번 소개에서 주장하지 않는다.

첫 문의에는 이 소개를 본문에 포함하면 충분하다. 화면·외부 데모는 추가 첨부 없이 시작한다. 상대가 요청하면 보드가 공개 가능 자료를 결정한다.

## 첨부용 20분 인터뷰 질문지

- 0–3분: 자료를 확인하는 일반적인 업무 순서는 무엇인가요? 실제 고객이나 주소는 말하지 않아도 됩니다.
- 3–8분: 가장 자주 다시 요청하는 자료나 반복 질문은 무엇인가요?
- 8–13분: 자료의 출처와 확인 시점을 현재 어떻게 기록하나요?
- 13–17분: ‘확인 전 / 확인 기록 / 전문 문의 필요’라는 표현에서 오해할 부분은 무엇인가요?
- 17–20분: 이런 도구를 검토하기 전에 필요한 정보는 무엇인가요?

인터뷰 목적·자율 참여·메모 동의는 시작 전에 설명한다. 녹음과 실제 문서 수집은 이번 안에 포함하지 않는다. 인터뷰 일정과 사례비는 확정하거나 약속하지 않는다.

## 보드 검토와 후속 처리

Down에게 후보별 진행·보류 결정, 발신자·회신 경로 확정, 기존 연락 이력과 중복 여부 확인을 요청한다. 프롭테크포럼은 수신처 재확인도 필요하다. 기존 K-Startup 관련 작업 [DOW-380](/DOW/issues/DOW-380)의 확인값과 충돌하거나 중복되면 새 신청 대신 해당 작업에 합친다.

권고 순서는 원스톱 자격·분야 문의 → IP 절차 문의 → 연락처 확인 후 포럼 문의다. 사용자가 직접 연락하거나 별도 명시적 실행 지시가 있는 경우에만 발송 단계로 전환한다. 회신 기록은 기관·일시·요지·다음 행동만 남기고 개인 연락처와 증빙 원문은 이 문서에 넣지 않는다.
