# 워크로그 2026-09-20 (2) — 앱에 쓸 것을 넣었다

앱을 받아본 대표님 반응이 "이정도로 뭐가 되냐"였다. 열어보니 맞는 말이었다.

## 무엇이 비었던가

로그인 전에 보이는 탭이 **커뮤니티 하나**였다. 홈, 매물, 메시지, 프로필은 전부
로그인 뒤에 있고, 매물은 프로덕션에 0건이라 들어가도 빈 화면이다.
웹은 화면이 75개인데 앱에서 손에 잡히는 건 게시판 하나였다.

그 게시판도 20건 중 18건이 운영자 글, 댓글 0, 전체 조회 73회였다.
사람이 없으면 게시판이 아니라 블로그다.

맨 위 두 건은 제목 `kxtyqh`, 본문 `hhkthk`인 테스트 글이었다. 오늘 새벽에
올라온 것을 안 치웠다. 앱을 처음 여는 사람이 제일 먼저 보는 게 그거였다.
**지웠다** (soft delete, `deleted_at`).

## 넣은 것

**보증금 위험 점검.** 등기부와 시세에서 읽은 숫자를 넣으면 계산해 준다.

| 넣는 것 | 어디서 |
| --- | --- |
| 매매 시세 | 실거래가, 네이버 부동산 |
| 내 보증금 | 계약하려는 금액 |
| 근저당 채권최고액 | 등기부 을구 |
| 선순위 보증금 | 다가구일 때 앞선 세입자 합계 |

나오는 것은 부채비율, 시세대로 팔릴 때 남는 돈, **경매로 넘어갈 때 남는 돈**,
그리고 지금 해야 할 일이다. 관련 운영자 글로 이어진다.

**시세를 우리가 추정하지 않는다.** 추정한 숫자로 "안전합니다"라고 말하는 순간
이 화면은 도움이 아니라 위험이 된다. 전부 사용자가 직접 확인해 넣는다.

경매 낙찰가율은 70퍼센트로 보수적으로 잡았다. 시세대로 팔린다고 계산하면
"딱 맞음"이 나오는데, 실제로는 그때 이미 돈이 모자란다.

## 빌드 경로를 뚫었다

EAS 무료 빌드가 10월 1일까지 막혀 있다. 오늘 올리려면 로컬 빌드뿐인데
RN은 JDK 17이 필요하고 이 기계엔 25만 있었다.

`brew install --cask temurin@17`은 sudo 비밀번호를 물어서 막혔다.
**Adoptium tar.gz를 `~/.jdks`에 풀어서 우회했다.** sudo가 필요 없다.

```
export JAVA_HOME=~/.jdks/jdk-17.0.20.1+1/Contents/Home
export ANDROID_HOME=~/Library/Android/sdk
eas build --platform android --profile production --local
```

**로컬 빌드는 EAS 무료 할당량을 쓰지 않는다.** 키스토어는 EAS 서버에서
자동으로 내려받으므로 업로드 키가 그대로 유지된다. 12분 걸린다.
