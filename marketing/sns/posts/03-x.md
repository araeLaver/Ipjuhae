# X — 1주차 7건

## X는 스레드와 다르게 쓴다

| | 스레드 | X |
| --- | --- | --- |
| 길이 | 길어도 읽힌다 | **한글 약 140자**가 상한 (X는 한글을 2자로 계산) |
| 긴 글 | 한 게시물에 다 쓴다 | **연속 트윗**으로 쪼갠다 |
| 링크 | 본문에 넣어도 됨 | **본문에 넣으면 도달이 떨어진다 → 답글에 단다** |
| 이미지 | 없어도 됨 | 한 장 붙이면 눈에 띈다. 캐러셀 슬라이드를 재활용 |
| 고정 | 없음 | **고정 트윗이 사실상 프로필 소개** |

그래서 X용은 문장을 줄이고, 정보성 글은 연속 트윗으로 나눴다.

---

## X-1 · 고정 트윗

올린 뒤 **프로필에 고정**한다.

```
임대차 계약할 때 서로를 확인할 방법이 없다는 게 이상해서 만들고 있습니다.

세입자는 성실하다는 걸 증명 못 하고
집주인은 월세를 낼 사람인지 알 수 없고
중개사는 양쪽 말만 듣고 계약서를 씁니다.

셋 다 불안한데 아무도 확인을 못 합니다.
```

**답글로 이어 달 것**

```
사전 신청 페이지를 열었고 지금까지 신청자는 1명입니다. 그 1명이 저는 아닙니다.

ipjuhae.com/?utm_source=x
```

## X-2 · 연속 트윗 · 등기부에서 볼 세 줄 ⚠︎

6개를 이어서 답글로 단다. 1번에 캐러셀 표지(`Main` 아트보드) 이미지를 붙인다.

**1/6**
```
집 보러 가기 전에 등기부등본 한 장만 떼어보세요.
세 줄만 보면 판단이 섭니다.
```

**2/6**
```
① 갑구 — 소유자

계약하려는 사람과 이름이 같은지 봅니다.
대리인이 나왔다면 위임장을 확인하세요.
```

**3/6**
```
② 을구 — 근저당 채권최고액

집주인이 이 집을 담보로 빌린 돈입니다.
경매로 넘어가면 은행이 먼저 가져갑니다.
```

**4/6**
```
③ 신탁 표시

있으면 집주인에게 계약 권한이 없을 수 있습니다.
여기서 멈추고 신탁원부를 확인하세요.

세 개 중에 이게 제일 중요합니다.
```

**5/6**
```
등기부에 안 나오는 것도 있습니다.

먼저 들어온 세입자의 보증금,
집주인이 안 낸 세금.

둘 다 경매에서 내 보증금보다 순위가 앞섭니다.
```

**6/6**
```
"확정일자 받았으니 괜찮다"가 틀리는 이유가 이겁니다.
근저당보다 늦으면 순위가 밀립니다.

봐야 하는 건 확정일자가 아니라 순위입니다.
```

> ⚠︎ 기준선 숫자(근저당 비율 등)를 넣으려면 출처를 확인하고 함께 적을 것.

## X-3 · 배점 공개

```
세입자 점수를 이렇게 나눴습니다.

소득 안정성 30
납부 이력 30
거주 평판 25
본인 인증 15

학력, 직장 이름, 나이는 안 봅니다.
소득도 액수가 아니라 월세 대비 비율만 봅니다.

이 배점, 뭘 빼고 뭘 넣어야 할까요.
```

> 질문으로 끝내면 인용 답글이 붙는다. X에서는 인용이 도달을 가장 크게 늘린다.

## X-4 · 임대인 · 연체 비용 ⚠︎

```
집주인 입장에서 제일 비싼 실수는 공실이 아니라 연체입니다.

공실 한 달은 한 달치로 끝나지만
연체는 명도까지 가면 몇 달에 소송비가 붙습니다.

그런데 세입자를 고를 때 쓸 수 있는 정보는 여전히 "느낌"뿐입니다.
```

> ⚠︎ 구체적 금액을 넣으려면 "가정"임을 명시할 것.

## X-6 · 양방향

가장 짧고, 가장 퍼질 가능성이 높다. 이미지 없이 텍스트만.

```

집주인은 소득과 직장을 묻는데
세입자는 대출이 얼마인지 묻기가 어렵습니다.

돈은 세입자가 더 많이 겁니다. 보증금 전부요.
```
