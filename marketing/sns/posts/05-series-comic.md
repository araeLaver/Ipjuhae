# 연재 만화 「지수의 계약」 12화

한 사람이 집을 구해 도장을 찍기까지. 매 화 위험 하나를 만나고 **끝을 미결로 끊는다.**

「등기부 뜯어보기」 12화의 내용이 그대로 이 이야기 안에 녹아 있다. 설명문이 사건으로 바뀐 것뿐이다.

## 연재 규칙

- 하단 `다음 화 — ...` 줄을 **절대 빼지 않는다.** 이게 연속성을 만든다
- 인물 규칙(지수=원/앰버, 김 소장=사각/브론즈)과 표지 형식을 매 화 그대로 지킨다
- 빠진 번호를 만들지 않는다. 순서대로 올린다
- 이미지가 본체다. 캡션은 이미지가 못 담은 설명만 짧게

## 채널별

| 채널 | 올리는 법 |
| --- | --- |
| 인스타그램 | 4컷 이미지 1장 + 캡션 |
| 스레드 | 4컷 이미지 1장 + 캡션(해시태그 빼고) |
| X | 4컷 이미지 1장 + 짧은 본문 |

## #01 · 너무 싼 집

**이 화가 다루는 것:** —

**4컷**

1. **지수 · 생각** — 보증금 8천? / 이 동네에?
2. **김 소장 · 말** — 운이 좋으시네요. / 오늘 아침에 나온 거예요.
3. **지수 · 생각 (둘이 함께)** — 깨끗한데… / 왜 이렇게 싸지?
4. **지수 · 말** — 잠깐만요. / 등기부 한 번만 / 볼게요.

**인스타·스레드 캡션**

```
지수의 계약 #01 — 너무 싼 집

좋은 이유일 수도 있고, 아닐 수도 있고요.

지수는 일단 등기부를 떼보기로 했습니다.

다음 화 — 소유자 이름이 다르다
```
