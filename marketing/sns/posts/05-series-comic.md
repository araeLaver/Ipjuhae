# 연재 「지수의 계약」 12화

한 사람이 집을 구해 도장을 찍기까지. 매 화 위험 하나를 만나고 **끝을 미결로 끊는다.**

「등기부 뜯어보기」 12화의 내용이 그대로 이 이야기 안에 녹아 있다. 설명문이 사건으로 바뀐 것뿐이다.

## 게시물 한 건의 구성

게시물 = **이미지 1장 + 캡션**. 이미지가 본체고 캡션은 이미지가 못 담은 설명만 짧게 붙인다.
아래 각 화에 캡션(인스타·스레드 / X)과 그 화의 이미지 디자인 프롬프트가 한 짝으로 들어 있다.

| 채널 | 올리는 법 |
| --- | --- |
| 인스타그램 | 이미지 1장 + 캡션 |
| 스레드 | 이미지 1장 + 캡션(해시태그 빼고) |
| X | 이미지 1장 + 짧은 본문 |

## 연재 규칙

- 하단 `다음 화 — ...` 줄을 **절대 빼지 않는다.** 이게 연속성을 만든다
- 각 화 프롬프트의 「연재 고정」 항목을 화마다 바꾸지 않는다. 매번 다르면 연재로 인식되지 않는다
- 빠진 번호를 만들지 않는다. 순서대로 올린다

## 이미지 만드는 법

이미지는 **Claude Design에서 만든다.** 각 화의 「이미지 디자인 프롬프트」 블록을
통째로 복사해 붙여넣으면 된다. 블록 하나가 혼자서 완결되어 있어서 다른 곳을 같이 볼 필요가 없다.

12화를 한 캔버스에서 이어 만들면 형식이 덜 흔들린다. 한 화가 마음에 들게 나오면
그 화를 기준으로 삼고 다음 화 프롬프트를 이어 붙인다.

**흔들리면 안 되는 것은 네 가지뿐이다** — 상단 연재명·회차, 상단 오른쪽 부제,
하단 `다음 화 — ...`, 하단 워드마크. 이게 매 화 같은 자리 같은 크기여야 연재로 읽힌다.

### 저장소에 있는 참고본

`marketing/sns/exports/Comic01~12.png`은 프롬프트대로 렌더한 **참고용**이다.
구도와 글자 위치를 확인하는 용도이고, 실제 게시물은 Claude Design 결과물로 간다.
원고의 4컷을 고친 뒤 참고본을 다시 보고 싶으면:

```bash
node scripts/generate-comic-artboards.mjs   # 원고 → marketing/sns/canvas/ComicNN.dc.html
node scripts/export-sns-artboards.mjs       # 아트보드 → marketing/sns/exports/ComicNN.png
```

서류 카드가 어느 칸의 값인지는 원고에 없는 정보라 각 화 프롬프트 안에 적어뒀다.

