# 연재 「지수의 계약」 12화

한 사람이 집을 구해 도장을 찍기까지. 매 화 위험 하나를 만나고 **끝을 미결로 끊는다.**

「등기부 뜯어보기」 12화의 내용이 그대로 이 이야기 안에 녹아 있다. 설명문이 사건으로 바뀐 것뿐이다.

## 게시물 한 건의 구성

게시물 = **이미지 1장 + 캡션**. 이미지가 본체고 캡션은 이미지가 못 담은 설명만 짧게 붙인다.
아래 각 화에 캡션(인스타·스레드 / X)과 그 화의 이미지 디자인 프롬프트가 한 짝으로 들어 있다.

| 채널 | 올리는 법 |
| --- | --- |
| 인스타그램 | 이미지 1장 + 캡션 |
| 스레드 | 이미지 1장 + 캡션(해시태그 빼고) |
| X | 이미지 1장 + 짧은 본문 |

## 연재 규칙

- 하단 `다음 화 — ...` 줄을 **절대 빼지 않는다.** 이게 연속성을 만든다
- 아래 공통 디자인 규격을 화마다 바꾸지 않는다. 매번 다르면 연재로 인식되지 않는다
- 빠진 번호를 만들지 않는다. 순서대로 올린다

## 공통 디자인 규격 — 12화 전체가 공유한다

**사람을 그리지 않는다.** 이야기는 대화 기록과 서류가 끌고 간다.
HTML/CSS로 인물을 그리면 와이어프레임처럼 보인다. 타이포그래피와 문서 레이아웃으로 간다.

```
규격 1080 × 1350 px. 바탕 딥네이비 #0C2247. 여백 위 60px, 좌우 54px, 아래 54px.
서체 Gothic A1 (없으면 Noto Sans KR). 느낌표 쓰지 말 것.

[바깥 틀 — 매 화 동일]
상단 왼쪽   "지수의 계약" 30px 앰버 #E9A23B  +  "#NN" 52px 흰색 900
상단 오른쪽 그 화의 부제 26px 흰색 60%
가운데      연회색 카드 #EEF1F5, 모서리 26px, 안쪽 여백 34px.
            서류 카드가 있는 화는 세로 가운데 정렬, 없는 화는 고르게 폄
하단 왼쪽   "다음 화 — ..." 28px 앰버 #E9A23B      ← 절대 빼지 말 것
하단 오른쪽 "입주해" 24px 흰색 55%

[카드 안 요소 — 매 화 동일]
주제 칩     카드 맨 위 가운데. 그 화가 다루는 것. 23px, 네이비 55%,
            테두리 2px 네이비 18%, 완전 둥근 모서리, 안쪽 여백 8×22px
지수의 말   오른쪽 정렬. 앰버 #E9A23B 바탕에 먹색 글자 34px 굵게.
            모서리 20/4/20/20px, 안쪽 여백 22×26px, 최대 폭 620px
김 소장의 말 왼쪽 정렬. 흰 바탕 34px 굵게, 모서리 4/20/20/20px.
            왼쪽에 64px 브론즈 #B08D62 사각 아바타("김"), 위에 이름 22px 회색
지수의 속마음 가운데 정렬. 네이비 62% 투명, 30px 굵게.
            위아래에 네이비 22% 2px 점선만 긋고 상자는 만들지 않는다
서류 카드   흰 바탕, 네이비 16% 2px 테두리, 모서리 14px.
            머리줄에 서류 이름(24px 900 네이비)과 「예시」 배지(19px 회색 알약).
            그 아래 항목 이름(200px 폭, 25px 회색) + 값(29px 먹색).
            그 화의 결정적 한 줄만 36px 900 + 앰버 형광 밑줄.
            맨 아래 브론즈 한 줄 메모

도형과 글자만 쓸 것. 사람 일러스트, 이모지, 스톡 이미지, 그라데이션 금지.
```

**아트보드는 손으로 만들지 않는다.** 원고의 4컷을 그대로 읽어 생성한다.

```bash
node scripts/generate-comic-artboards.mjs   # 원고 → marketing/sns/canvas/ComicNN.dc.html
node scripts/export-sns-artboards.mjs       # 아트보드 → marketing/sns/exports/ComicNN.png
```

캡션을 고치면 이미지는 그대로다. **4컷을 고치면 두 명령을 다시 돌린다.**
서류 카드의 항목 구성은 원고에 없는 정보라 생성기의 `DOCS` 표에 있다.
