## 왜 이걸 하고 있나

인스타·스레드에 올려도 반응이 없고 신청이 0에 가까웠는데, 어디서 막히는지 구분할 수단이 없었다.
그래서 (1) 계측을 먼저 깔고 (2) 콘텐츠 종류를 "제품 소개"에서 "임대차 정보"로 바꿨다.

**타깃 비중은 2026-09-06에 한 번 뒤집혔다.** 처음에는 전환이 높은 임대인·중개사를 6:4로 우선했는데,
목표가 조회수·팔로워로 바뀌면서 **세입자 7 : 임대인 3**으로 돌렸다.
조회수는 모수가 전부인데 임대인·중개사는 수가 적기 때문이다.

지금 구조는 두 트랙이다.
- **도달 트랙(세입자, 7)** — 연재 「등기부 뜯어보기」. 조회수·팔로워를 번다
- **전환 트랙(임대인·중개사, 3)** — 연재 「임대인 노트」. 사전 신청을 받는다

큰 계정을 먼저 만들고 그 위에서 전환을 받겠다는 순서다. 임대인 트랙을 없앤 게 아니다.
세입자 콘텐츠는 남들과 겹치지 않게 각도를 하나로 고정했다 — **"집주인도 검증 대상이다"**는 양방향 앵글.

## 게시 이미지는 Claude Design에서 만든다

**이게 기본 경로다.** 각 게시물의 「이미지 디자인 프롬프트」 블록을 통째로 복사해
Claude Design에 붙여넣으면 된다. 블록 하나가 혼자서 완결되어 있어서 다른 곳을 같이 볼 필요가 없다.

프롬프트마다 맨 위에 `[연재 고정]`이 있다. **연재명·회차와 다음 화 예고** 두 가지인데,
이게 화마다 흔들리면 연재로 읽히지 않는다. 나머지는 캔버스에서 자유롭게 바꿔도 된다.

한 화가 마음에 들게 나오면 그 화를 기준으로 삼고 다음 화 프롬프트를 같은 캔버스에 이어 붙인다.

`marketing/sns/exports/`의 PNG는 프롬프트대로 렌더한 **참고본**이다 — 구도와 글자 위치 확인용이고,
실제 게시물은 Claude Design 결과물로 간다. 원고를 고친 뒤 참고본을 다시 뽑으려면:

```bash
node scripts/generate-comic-artboards.mjs   # 만화 원고 → canvas/ComicNN.dc.html
node scripts/export-sns-artboards.mjs       # 아트보드 전체 → exports/*.png
```

## 디자인 캔버스를 다시 만들려면

`marketing/sns/canvas/`의 `.dc.html` 파일을 고친 뒤, Claude Code에서 `/design` 스킬로 다시 씨딩하면 된다.
아트보드 16장(`Main`, `Deungi2~8`, `Landlord1~6`, `ReelsCover1~2`)과 `canvas.json`을 전부 넘겨야 하고,
**기존 캔버스와 같은 URL로 갱신하려면 위 표의 캔버스 URL을 함께 넘겨야 한다.** 안 그러면 별도 캔버스가 새로 생긴다.

디자인 규격
- 캐러셀 슬라이드 1080×1350 (4:5), 패딩 `120px 90px` → 실사용 폭 900px
- 릴스 커버 1080×1920 (9:16), 위 250px·아래 450px은 앱 UI에 가려지므로 비움
- 색: 바탕 네이비 `#0C2247`, 강조 앰버 `#E9A23B`, 글자 흰색
- 서체: Gothic A1 (Pretendard가 웹폰트로 안 올라가서 대체). PNG로 내보내면 시스템 한글 폰트로 떨어질 수 있음
- **한글 제목은 88px을 기본으로.** 96px로 하면 열 글자 넘는 줄이 900px을 넘겨 깨진다. 들여쓰기가 있으면 그만큼 더 줄여야 함

## 계측 — 이미 프로덕션에 반영됨

커밋 `7dbc64f6`, 마이그레이션 041 적용 완료(applied=46 pending=0).

- 랜딩 방문은 `analytics_events`에 `page_view`로 쌓인다 (`properties.path`, `properties.utm_source`)
- 신청자는 `waitlist.utm_source / utm_medium / utm_campaign / referrer_host`에 유입 경로가 남는다

## 지켜야 할 선

- **사용자 수를 부풀리지 않는다.** 현재 사전 신청 1명. 이 서비스는 신뢰를 파는데 한 번 들키면 끝난다
- **차별 소지를 만들지 않는다.** 세입자를 학력·직장·국적·가족구성으로 거르는 이야기는 안 한다.
  제품도 그렇게 설계돼 있고(학력·직장명 안 봄, 소득은 월세 대비 비율만), 그게 차별점이다
- **확인 안 된 숫자를 쓰지 않는다.** 원고에서 등기부 발급 수수료 금액과 "근저당 70%" 기준선을 일부러 뺐다.
  넣으려면 출처를 확인하고 함께 적을 것
- **법률 조언처럼 단정하지 않는다.** "이렇게 하면 안전합니다" 대신 "확인해야 할 항목"으로 쓴다
- 카페·커뮤니티 무단 홍보 금지, 실제 피해자 사례 무단 사용 금지, 팔로워 구매 금지

## 연재 규칙

- 본문 첫 줄을 언제나 `등기부 뜯어보기 #03` 형태로 시작하고, 한 줄 띄고 본문을 쓴다
- 표지 디자인 형식(연재명 위치·번호 크기·색)을 바꾸지 않는다. 매번 다르면 연재로 인식되지 않는다
- **빠진 번호를 만들지 않는다.** 순서대로 올리고, 소재가 막히면 미루지 말고 짧게라도 낸다
- 「만드는 중」과 「단발」에는 번호를 붙이지 않는다 — 일지는 빈 번호가 눈에 띄고, 단발은 번호가 붙으면 무게가 줄어든다
- **매 화 끝에 다음 화를 예고한다.** 그 한 줄이 팔로우 버튼을 누르게 한다
