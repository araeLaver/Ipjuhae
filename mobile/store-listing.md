# 입주해 스토어 등록 자료

제출 직전에 이 파일을 그대로 복사해 쓴다. 문안은 **앱이 지금 실제로 하는 일**만 적는다 —
스토어 설명과 앱이 다르면 반려되고, 반려를 피해도 받은 사람이 바로 지운다.

> **지금 상태**: 프로덕션 매물 0건. 매물 탐색을 앞세우면 빈 화면을 보게 되므로
> 프로필·인증·신뢰 점수를 앞에 두고, 매물은 "초기"라고 정직하게 적는다.

## 앱 이름

- App Store: `입주해 — 임대차 신뢰 프로필`
- Play (30자 제한): `입주해 - 임대차 신뢰 프로필`

## 짧은 설명 (Play 80자)

```
세입자도 집주인도 서로를 확인할 수 있게. 학력·직장 대신 확인 가능한 것으로 신뢰를 만듭니다.
```

## 긴 설명 (Play 4000자 / App Store)

```
임대차 계약은 서로를 모르는 채 시작됩니다.

세입자는 자기가 성실하다는 걸 증명할 방법이 없고, 집주인은 이 사람이 월세를 낼 사람인지 알 방법이 없습니다. 중개사는 양쪽 말만 듣고 계약서를 씁니다. 셋 다 불안한데 아무도 확인을 못 하는 구조입니다.

입주해는 그 확인을 가능하게 만듭니다.

■ 세입자
- 프로필을 만들고 신뢰 점수를 확인합니다
- 재직·소득 등을 인증해 점수를 올립니다 (전부 선택)
- 조건이 맞는 매물을 찾아보고 집주인과 앱 안에서 대화합니다

■ 집주인
- 매물을 등록하고 관심 세입자를 확인합니다
- 문의 전에 상대의 확인된 정보를 봅니다
- 매물별 조회·관심 현황을 봅니다

■ 보지 않는 것
학력, 직장 이름, 나이, 결혼 여부, 국적은 묻지 않습니다. 판단에 도움이 안 되고 차별이 되기 때문입니다. 소득은 액수가 아니라 월세 대비 비율로만 봅니다.

■ 개인정보
필요한 만큼만, 필요한 때만 공개됩니다. 연락처는 앱 안 메시지로 시작해 필요할 때만 교환합니다. 민감한 정보는 암호화·마스킹해 보관하고, 앱 안에서 언제든 계정을 삭제할 수 있습니다.

초기 서비스입니다. 등록된 매물이 아직 많지 않습니다. 프로필과 인증을 먼저 만들어 두시면 매물이 올라올 때 바로 쓰실 수 있습니다. 의견은 support@ipjuhae.com 으로 보내주세요.
```
