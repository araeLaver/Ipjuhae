# 입주해 스토어 등록 자료 초안

## 앱 이름
- **입주해 — 세입자 프로필 기반 부동산 매칭** (Play 30자 제한: "입주해 - 세입자 프로필 부동산 매칭")

## 짧은 설명 (Play 80자)
세입자가 프로필을 만들면 집주인이 먼저 제안하는 역방향 임대 매칭. 신뢰 프로필로 안전하게 시작하세요.

## 긴 설명 (Play 4000자 / App Store)
**집을 찾아다니지 말고, 제안받으세요.**

입주해는 세입자가 자신의 조건(예산·희망지역·입주시기·생활 정보)을 프로필로 정리하면, 조건이 맞는 집주인이 먼저 연락하는 역방향 임대 매칭 서비스입니다.

**세입자라면**
- 프로필 한 번 작성으로 반복되는 문의·방문 줄이기
- 예산과 조건에 맞는 매물 매칭 점수 확인
- 집주인과 앱 안에서 바로 메시지
- 재직·소득 등 인증으로 신뢰도 높이기 (선택)

**집주인이라면**
- 공실 등록 후 조건 맞는 세입자 프로필 탐색
- 관심 세입자 저장·메모
- 문의 전 세입자의 검증된 정보 확인
- 매물별 조회·관심 통계

**안전하게**
- 개인정보는 동의 범위에서만 공개됩니다
- 연락처는 앱 내 메시지로 시작해 필요할 때만 교환
- 민감 정보는 암호화·마스킹 처리됩니다

성남·수도권에서 시작하는 초기 서비스입니다. 의견은 앱 내 문의로 보내주세요.
