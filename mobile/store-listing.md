# 입주해 스토어 등록 자료

제출 직전에 이 파일을 그대로 복사해 쓴다. 문안은 **앱이 지금 실제로 하는 일**만 적는다.
스토어 설명과 앱이 다르면 반려되고, 반려를 피해도 받은 사람이 바로 지운다.

> **2026-09-19 기준**: 앱을 켜면 로그인 없이 커뮤니티가 바로 열린다. 가입하지 않아도
> 글과 댓글을 쓸 수 있고, 운영자가 정리한 글 18편이 들어 있다. 매물은 아직 0건이라
> 앞세우지 않는다.

## 앱 이름

## 짧은 설명 (Play 80자)

```
계약 전에 물어보는 곳. 등기부와 보증금, 혼자 판단하기 어려운 것을 함께 봅니다.
```

## 긴 설명 (Play 4000자 / App Store)

```
전세 계약서에 도장을 찍기 전, 확인해야 할 게 생각보다 많습니다.

등기부 갑구의 소유자가 계약 상대와 같은지, 을구의 근저당이 시세에 비해 얼마인지, 신탁 표시가 있는지. 하나라도 놓치면 보증금이 걸립니다. 그런데 이걸 물어볼 데가 마땅치 않습니다.

입주해 커뮤니티는 계약 전에 물어보는 곳입니다.

가입하지 않아도 됩니다.
계정을 만들지 않아도 글을 읽고, 질문을 남기고, 댓글을 달 수 있습니다. 익명으로 올라갑니다.

입주해가 정리한 글이 있습니다.
등기부 읽는 법 12편, 임대인이 확인할 것 6편. 계약 전에 확인할 순서대로 정리했습니다.

임차인, 임대인, 공인중개사가 함께 씁니다.
한 게시판에서 이야기하고, 글마다 글쓴이의 입장이 표시됩니다. 서로 어떤 걸 걱정하는지 보입니다.

안전하게 쓰도록 했습니다.
주소와 건물명은 적지 않도록 안내합니다. 부적절한 글은 누구나 신고할 수 있고, 신고가 쌓이면 운영자 확인 전에 먼저 비공개 처리됩니다.

지금 만들고 있는 것도 말씀드립니다.
임차인이 소득과 납부 이력을 카드 한 장으로 만들고, 임대인과 중개사가 원본 서류 없이 확인하는 기능을 준비 중입니다. 학력이나 직장 이름은 보지 않습니다.

초기 서비스입니다. 의견은 ipjuhae.official@gmail.com 으로 보내주세요.
```
